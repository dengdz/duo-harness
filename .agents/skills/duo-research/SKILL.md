# duo-harness 参考项目研究

目的：把对参考项目的分析变成持久资产——研究一次、落盘一份，后续会话直接读文件，不重新扫描源项目。分析对象用项目别名指代，别名与路径注册在 `docs/research/index.md` 的项目注册表。当前注册两家：

- **DSH** = deepseek-harness（TypeScript/pnpm monorepo，参考实现主力；2026-09-21 沙箱调研时核正——此前误标 Java）
- **ZCode** = zai-org/ZCode（TS/pnpm monorepo，本地 `/Users/zhangyl/IdeaProjects/ZCode`，含桌面端 / Web / Agent CLI 与 agent 运行时源码）

## 多项目调研（默认两家都看，文档分家）

注册表有多个参考项目时，功能调研**默认两家一起看**；但**文档按项目分家落盘**（2026-09-21 用户裁定，参考权重 ZCode 为主、DSH 为辅）：

- 同一功能在两家各自定位实现、各自落 `docs/research/<别名>/<功能>/`，每家各记自己的源锚点；跨项目对照结论按 domain 规则进 ADR（或主参考项目的「对 duo 的启示」段）
- 既有平铺先例 `docs/research/subagent-派发与提示词对照.md` 已被 ADR-0016/0017 引用，路径稳定保持原位——新惯例只约束新文档
- 用户点名单家、或另一家无对应实现时，走单家流程并在文档注明另一家的情况

## 功能深析流程

1. **锚点核对（按注册表条目类型）**：
   - **git 检出类**（本地 git 仓库，如 DSH / ZCode）：`git -C <本地路径> pull --ff-only`（失败时报告原因，停在 pull——换 merge/rebase 需用户授权），记录 `git rev-parse HEAD` 为版本锚点。
   - **插件缓存类**（非 git 检出，如 mattpocock-skills 的版本目录）：锚点 = 插件版本号；核对 = 版本目录存在、文件数与清单不变（C1-01 即先例——"拉最新"在缓存类上退化为"核对版本未变"）。
   - 分析结论只对锚点负责；锚点漂移时先停下报告。
   完成判据：锚点类型已判定，锚点值（SHA 或版本号）已记录。
2. **查索引**：读 `docs/research/index.md` 的功能条目表。
   - 该功能已有条目且锚点一致 → **直接复用文档**，本次结束（这就是"不重扫"）
   - 锚点落后（源有新提交）→ 对新差异做增量补扫，更新锚点与索引状态
   - 无条目 → 继续下一步
   完成判据：三分支走其一，结论已记录。
3. **定位功能边界**：先派 Explore 子代理摸清该功能在代码里的落点——入口、模块边界、涉及的文件清单；确认"这个功能是哪几块代码"之后再深挖。对照研究时每个项目各定位一轮。
4. **三路深挖**（一个或多个子代理；每条结论必须带 `文件:行号` 出处，读代码核实、README 转述降级为线索）：
   - **架构**：模块划分、核心类与接口、数据流向
   - **代码**：关键实现逻辑、重要方法、依赖关系
   - **细节**：配置项、边界条件、异常处理
5. **落盘三文件**到 `docs/research/<别名>/<功能名>/`：

   | 文件 | 固定结构 |
   |---|---|
   | `架构设计.md` | 源锚点 → 功能一句话 → 模块划分 → 核心类与接口（职责表）→ 数据流向 |
   | `代码说明.md` | 源锚点 → 关键实现逻辑（按流程分节）→ 重要方法（签名 + 做什么 + 位置）→ 依赖关系（依赖谁 / 被谁依赖） |
   | `细节备忘.md` | 源锚点 → 配置项（名 / 默认值 / 作用）→ 边界条件 → 异常处理（类型 / 触发 / 处理）→ 已知坑 |

6. **登记 + 记账**：`docs/research/index.md` 功能条目表加一行（别名 / 功能 / 文档位置 / 锚点 / 状态）；CHANGELOG 记账；提交前 Call the Skill tool with "duo-workflow"，按其提交前核对清单执行。
   完成判据：index 行存在且锚点与文档头一致，CHANGELOG 条目已加。

## 消费规则（写给后续会话）

- 需要参考该功能时**直接读 `docs/research/<别名>/<功能名>/` 三件套**，不重扫源项目
- 索引状态列标"源已更新"时，先做锚点核对再增量补扫
- 分析中确定的"我们要采纳 XXX"按 domain 规则记 ADR：分析文档记事实，ADR 记决策
