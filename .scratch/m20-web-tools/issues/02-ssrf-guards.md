## Checklist

- [ ] URL 字面预检：仅 http/https；内嵌用户名/密码拒绝；长度 ≤2048——结构化错误（区别于内容错误）
- [ ] DNS 解析后校验：非字面量主机名取**全部解析地址**逐一公网判定，任一非公网整体拒绝；IP 字面量直接分类（回环/RFC1918/链路本地/组播/保留段全拒）；**解析器做成构造可注入函数**
- [ ] 重定向改为自动跟随：MANUAL 逐跳处理——每跳重走 URL 预检 + DNS 校验，**强制同源**（scheme+host+port），跨源结构化错误附"直接请求该 URL"指引；跳数上限 5（`maxRedirects` 可配）
- [ ] 错误双轨：策略拒绝类错误与内容错误文案分离，均带模型自纠指引
- [ ] 测试（假 resolver 注入）：多地址集"一内一外整体拒绝"、全内网拒绝、公网放行、字面量内网 IP、重定向链同源跟随/跨源拦截/超跳数
