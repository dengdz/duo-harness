# 04: Markdown 转换器深化

## What to build

转换器从"基础可读"升级为"常用 Markdown 子集全量"（ADR-0021 决策 5）：列表、链接、代码块、强调完整映射，表格降级文本化——纯函数、全量测试、零网络依赖。

## Blocked by

01（替换其基础映射实现）

## Status

ready-for-agent

## Checklist

- [ ] 列表：ul/ol 及嵌套，正确的缩进与序号
- [ ] 链接：`[text](href)` 形态；图片降级为 alt 文本（无 alt 忽略，不产生图片链接噪音）
- [ ] 代码：pre/code 围栏块，保留换行与缩进；行内 code 反引号
- [ ] 强调：strong→`**`、em→`*`
- [ ] 表格降级：逐行文本化（行列关系可读即可，实现形态测试锁定）
- [ ] 转义策略：Markdown 特殊字符的最小转义，避免正文被误解释为格式
- [ ] 行内空白折叠：连续空白/换行规整，不放大 token
- [ ] 纯函数测试全量补齐（含 01 基础映射的回归）
