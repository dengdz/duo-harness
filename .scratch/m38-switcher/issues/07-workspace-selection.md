# 07: 创建会话时选择工作区——桌面壳的项目目录绑定

## What to build

通用工具标准形态（ZCode/Cursor 同款）：**会话绑定工作区目录，创建时可选**。三层落地：①**壳启动时**弹目录选择（记住上次；首次必选、此后可沿用）——选中目录作为本次运行 spawn java 的 **cwd 注入**（后端 Cwd 自然继承，零后端改动），即默认工作区；②**新建会话时可改**：「+ 新话题/新建会话」触发目录选择（壳侧 Electron 目录框）→ 后端建会话端点支持 workspace 参数（`Session.createDeferred` 本就收 cwd 参数——接线扩展非新机制）；③当前会话的工作区在界面可见（标题区或会话条目）。安全口径：目录由用户本机显式选择，档位治理（只读/区内写）随所选目录走——与 CLI `cd` 到任意目录等价，不做白名单。

验收标准：启动选目录 A → 会话的读写/工具操作根在 A；新建会话选目录 B → 新会话根在 B、旧会话仍在 A；重启壳默认带上次工作区。
