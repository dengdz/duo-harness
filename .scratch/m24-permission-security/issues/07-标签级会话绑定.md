# 07: 标签级会话绑定

## What to build

浏览器每标签生成持久 tabId（localStorage）随握手上报；服务端单全局会话字段改 Map 多会话并存（按 tabId）；新标签打开默认新建会话（不弹选择页，互踩隔离优先）；无记录的旧标签等同新标签；resume 仍走面板手动入口（绑定发起标签）；审批/提问卡片按 tabId 路由到所属标签（A 标签的审批不弹到 B 标签）。完整多会话协调仍属 1.0 后——本期只做互踩的前置缓解。

决策依据：ADR-0026 决策五；docs/limitations.md M8#4（销账对象）；BUG-20260914-01 档案；ADR-0024「后台任务时代多标签互踩的前置缓解」定性。

## 设计定稿（2026-09-23 压缩恢复锚，实现照此执行）

### 摸底耦合点（已核实）
- `WebFace.java`（1478 行）：101-103 行 volatile session/agent 单全局；104-107 行 busy/agentRunning 单全局 AtomicBoolean；305 行 bindLock；308-336 行 bindSession/newSession；358 行 currentSession()（被 WebPlugin 5 处以方法引用共享：审计桥、规则 sink、ask_user/计划工具、todo、subagent host——全部「当前执行 turn 的会话」语义）；363-390 行 pushSessionEvent/pushTransientFrame 全局 broadcast；784 行 handleMessage busy CAS；1201 行 handleEvents 回放；428-449 行 fail-closed 全局判定。
- `WebPlugin.java`：182 行 `AuditingAnswerer(face::currentSession, …)` 注册单 WebAnswerer（answerTimeoutMs=10min）；213 行 onSessionChanged 是 `Consumer<Session>`（回调内 setAgent 全局）。
- 卡片路由链：审批/计划卡事件（approval/requested，卡片 id 借 toolCallId 通道）与提问卡事件（tool/call ask_user）都落会话日志 → SSE——**会话事件按 tab 路由即卡片路由**。
- 线程模型（ToolCallingAgent 已核实）：`requiresApproval` 工具永不进并发池（isConcurrentSafe 短路）；ask 语义工具（web_fetch 等）可进池——池为 turn 内新建虚拟线程（`newVirtualThreadPerTaskExecutor`），**InheritableThreadLocal 可跨池继承**。
- app.js token 先例（工单 06）：localStorage duoToken + fetch 包装补 X-Duo-Token 头 + SSE ?token= 查询串 + 隐私模式降级。

### 设计定稿
1. **tabId 通道**：前端 sessionStorage 存 `duoTabId`（**不用 localStorage**——localStorage 同源全标签共享，会让所有标签同 tabId、隔离归零；sessionStorage 每标签一份且刷新不丢，F5 保留会话；隐私模式降级临时 id 记档）。全部 /api 请求 fetch 包装补 `X-Tab-Id` 头；SSE 以 `&tabId=` 查询串（EventSource 不支持自定义头，同 token 双通道口径）。服务端校验 `[0-9a-zA-Z_-]{1,64}`，非法 400；缺失 = 匿名上下文（key ""，兼容 curl/缓存页/既有 53 用例零改造）。
2. **服务端多会话**：`ConcurrentHashMap<String, TabContext> tabs`（TabContext：session/agent volatile + busy/agentRunning AtomicBoolean + sseSubscription + 创建序号 seq）。默认上下文（""）由 start() 传入的初始 session/agent 构成；未知 tabId 首次到达（任一端点/SSE）在 bindLock 内双检创建：newSessionSupplier 建新会话 + 回调建 agent（**新标签默认新建会话；服务端重启后旧标签 tabId 无记录 → 同样新建，即工单「无记录旧标签等同新标签」**）。
3. **turn 归属（InheritableThreadLocal）**：`WebFace.TURN_TAB` 静态 ITL 存 tabId，startAgentTurn（每 turn 专属虚拟线程）入口 set/finally remove；`currentSession()` 改为「ITL turn 会话优先，回退默认上下文」——WebPlugin 5 处 `face::currentSession` 供给方零改动即按 turn 归属（审计桥卡片、规则 sink、todo、subagent 种子全落正确 tab 的会话）。池线程经继承覆盖 ask-on-pool 场景。
4. **SSE 按 tab 路由**：SseClient 加 tabId 字段；监听器 per-tab（`target.addListener((i,ev) → pushSessionEventTo(i,ev,tab))`），broadcast 过滤 `client.tabId`；transient 帧（run/error）同样 per-tab。审批/提问卡片随会话事件自然只达所属标签。
5. **审批挂起归属 + per-tab fail-closed**：WebAnswerer.Pending 加 tabId，构造器挂 `Supplier<String> tabResolver`（WebFace::currentTabId，ask 时刻 ITL 取值——审批/提问/计划三类全精确）；新增包级 `failClosedFor(tabId)` 只拒该 tab 挂起项。removeClient 改按 tab 计数：该 tab 无连接且宽限期后仍无 → failClosedFor（「是否仍有人能看见该审批」的 per-tab 化——B 标签在场不算 A 会话有人看）。failClosedAll 保留（全局停机路径）。
6. **resume 绑定发起标签**：/api/session/switch、/api/session/new 按 X-Tab-Id 只换绑发起 tab；**新增 busy 守卫**（该 tab agentRunning/busy 时 409，防换绑关闭正在写的会话——换绑与重建 agent 是同一动作两面，BUG-20260914-01 教训）。跨标签撞同会话由独占锁天然拦（Session.load 撞锁 409）。
7. **per-tab 其余端点**：message/stop/command（CommandEnv 会话供给与 agentRunning 探针按 tab）、status 占用、sessions current 标记、page/export/attachment-read 全按 tab；/api/answer 不校验 tab（卡片 id 回填，跨 tab 无卡可见即无入口）。
8. **后台任务通知路由**：BackgroundTask.owner 仅呈现位粒度无 tab——路由到创建序号最小的 web tab（确定性），记档局限。
9. **stop()**：关闭全部 tab 会话；**WebPlugin 回调改 `Function<Session, ChatAgent>`**（返回值入 tab.agent；setAgent 保留给默认上下文/测试）。

### 实现顺序
WebAnswerer → WebFace → WebPlugin → app.js → WebFaceTabTest（双 tab 隔离/卡片路由/新标签新建/busy 守卫/fail-closed per-tab）→ 全量 → 四轴 → CHANGELOG + limitations M8#4 销账 → 提交（经确认）→ 验收件（双标签演示）。

## 实现记档（2026-09-23）

- 实现与四轴审查完成，全量 BUILD SUCCESS（935 用例 0 失败，2 既有 skip）。**待用户手动验收后转 done。**
- **localStorage → sessionStorage 改口**（工单原文 localStorage）：localStorage 同源全标签共享，会让所有标签同 tabId、隔离归零；sessionStorage 每标签一份且刷新不丢（F5 保留同会话），隐私模式降级临时 id（同 token 降级口径）。术语表词条已按实现口径更新。
- **匿名上下文**（key ""）：无 tabId 请求（curl/缓存页/既有 53 用例）归 start() 传入的初始会话/agent，行为同单会话时代；未知 tabId 首请求在 bindLock 内双检懒建（新会话 + 回调建 agent），服务端重启后旧 tabId 无记录同样新建——「无记录旧标签等同新标签」。
- **turn 归属用 InheritableThreadLocal**（WebFace.TURN_TAB）：startAgentTurn 每轮专属虚拟线程 set/finally remove；工具并发池与 subagent worker 均为 turn 内新建虚拟线程，ITL 跨创建继承——ask-on-pool（web_fetch 只读档 ask）归属不丢。WebPlugin 5 处 `face::currentSession` 共享供给方（审计桥/规则 sink/ask_user/todo/subagent）零改动落对会话。残留：turn 内 spawn 的长命线程持陈旧值（记档，无实际误落路径）。
- **回调 Consumer → Function**：换绑回调返回新 agent 归标签上下文（原 setAgent 全局单槽即分脑面）；setAgent 保留给匿名上下文与测试。
- **busy 守卫为 CAS 占有式**：/new 与 /switch 在换绑全程持有 busy（finally 释放）——堵「检查通过后、换绑落地前新 turn 潜入写将被 close 的会话」的 TOCTOU（BUG-20260914-01 同源）；顺带覆盖非 busySafe 命令互斥期（CHANGELOG 措辞已含）。
- **后台通知路由**：owner 只有呈现位粒度无 tab——过滤匿名上下文后投创建最早的真实标签（Spec 轴阻断修正：min(seq) 原样写会把通知投进匿名上下文，浏览器永远看不到）；多标签误投为已记档局限（limitations M8#4 残留）。
- **审查修复清单（修 12）**：后台路由过滤、resolveTab 回调失败关 fresh（锁泄漏）、busy CAS 占有式 ×2、failClosedChecks 触发即清 + stop 清表、stop 全局 failClosedAll 兜底、POST 体先排空再解析标签 ×2、tabId 正则预编译常量、Pending 注释归一化口径、测试忙等加时限、断言补消息 ×6、SSE 坏 tabId 用例补齐。
- **记档不修**：标签上下文无淘汰（tabId 客户端可控，令牌门内每新值建会话+持锁，风险可控——limitations M8#4 残留）；resolveTab 懒创建整体持锁含回调（挪锁外会留「上下文在场而 agent 未就位」窗口，首载并发三发下早到消息 503——一致性优先）；failClosedAll 由停机路径消费（不再死代码）。
