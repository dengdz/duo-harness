# 07: 标签级会话绑定

## What to build

浏览器每标签生成持久 tabId（localStorage）随握手上报；服务端单全局会话字段改 Map 多会话并存（按 tabId）；新标签打开默认新建会话（不弹选择页，互踩隔离优先）；无记录的旧标签等同新标签；resume 仍走面板手动入口（绑定发起标签）；审批/提问卡片按 tabId 路由到所属标签（A 标签的审批不弹到 B 标签）。完整多会话协调仍属 1.0 后——本期只做互踩的前置缓解。

决策依据：ADR-0026 决策五；docs/limitations.md M8#4（销账对象）；BUG-20260914-01 档案；ADR-0024「后台任务时代多标签互踩的前置缓解」定性。
