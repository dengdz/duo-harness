# 03: 只读判定器与免审批接线

## What to build

bash 三态只读判定器组件（true/false/undefined，undefined 一律按非只读，fail-closed）：首期约 30 个 allowAnyArg 只读命令 + git 四件套 status/log/diff/show（命令清单实现时逐条核对参数面无写路径，落本工单 Comments 记档）；git 四件套必叠 cwd `.git` 存在性信任分类（防 `git -C` 指向任意仓库逃逸）；管道、`&&`、命令替换、重定向、别名等复合结构一律 undefined；经「运行时 capability 覆盖静态 metadata」seam 接入裁决序（deny 之后、allow 之前），判定 true 即免审批放行不弹卡。

决策依据：ADR-0026 决策二；探测 docs/research/ZCode/交互与呈现/只读命令识别与规则.md（三态聚合 fail-closed、allowAnyArg 分层、git 信任分类）；DSH 无此实现（注记）。
