# 01: 权限规则引擎地基——存储、匹配与裁决序

## What to build

项目级权限规则持久于项目根 `.duo/settings.json` 的 `permissions` 段（duo 首个项目级设置文件写入器，Jackson 直写，写失败降级提示不静默）；会话级规则随会话事件流持久、resume 经投影恢复；`Bash(prefix:*)` 词边界前缀匹配（命令名后须紧跟串尾或空白，`ls:*` 不匹配 `lsof`）；裁决序落 pre-execute 瀑布：deny（查全部命令，恒优先，与 guard 单调否决同构）→ allow（只查非只读命令）→ 既有档位/ask 链；deny 规则本期仅手写（审批卡不产 deny）；`/permission` 扩 `rules list`（项目+会话两级全量、来源署名）与 `rules rm <n>`；项目根以 `.git` 标定（复用技能发现根先例）。

决策依据：ADR-0026 决策一；探测 docs/research/ZCode/网络与数据/存储配置与凭据.md（ZCode settings 型两级持久化参考形态）。
