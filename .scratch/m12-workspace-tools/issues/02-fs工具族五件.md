# 02: fs 工具族五件

## What to build

read / write / edit / glob / grep 五个 DSH 短名工具（workspace 约束、Java 自实现、零外部二进制）——agent 获得真实项目文件操作能力。含读前写闸门（write 覆盖已有与 edit 前校验会话已读）。

## Blocked by

无（可立即开工）

## Status
ready-for-agent

## Checklist
- [ ] read：三帽窗口（2000 行 / 单行 2000 字符 / 总量 50KiB）+ 扫全文件精确总行数 + footer 三态（续读参数/未读尽/读尽）+ 二进制拒读（NUL 嗅探）+ offset 越界报错
- [ ] write：原子替换（同目录临时文件 + ATOMIC_MOVE）+ 读前写闸门（未读拒绝并提示"先 read"；新建豁免）+ 成功回执区分 Created/Updated
- [ ] edit：LF 归一匹配域（CRLF 写回恢复）+ 四态结构化失败（0 命中带路径、多命中带计数与 replace_all 提示、空串、old==new）+ replace_all 支持 + 成功不回显全文
- [ ] glob：PathMatcher glob 语法 + VCS 元数据目录跳过（.git/.svn/.hg/.bzr/.jj）+ 修改时间倒序 + 截断 100 条带未显示计数
- [ ] grep：正则逐行 + include 单 glob（拒取反与逗号列表并给修正建议）+ `路径:行号:文本` 命中输出 + 截断 250 条 + 二进制行跳过
- [ ] 五件套 requiresApproval 声明：read/glob/grep false；write/edit true（档位裁决在策略层，工单 01）
- [ ] 单元矩阵测试（TempDir workspace）：各工具行为 + 闸门三态 + 截断边界
