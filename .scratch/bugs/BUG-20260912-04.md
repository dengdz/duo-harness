# BUG-20260912-04 · 自动继续旧会话时投影 NPE 崩溃（旧格式工具事件无 id）

**Status**: verifying

## 修复与验证

- 改动：`Session.deriveMessages` 对 TOOL_CALL/TOOL_RESULT 的 null toolCallId 跳过；
  `AgentReplMain` REPL 循环逐轮兜底捕获 RuntimeException（错误呈现后可继续）
- 回归测试：SessionTest 新增 `legacyToolEventsWithoutIdAreSkippedInProjection`
  （手写旧格式 JSONL：user + 无 id 的 tool/call + tool/result → 投影仅剩 user）
- 全量 152 用例全绿（session 9）

## 根因（定位）

`deriveMessages` 的 TOOL_CALL 分支直接 `new ToolCall(event.toolCallId(), ...)`，而 ToolCall
紧凑构造器要求 id 非空。旧格式事件（本会话目录里修复前写入的 tool/call 行，无
toolCallId 字段）解析后 id 为 null → NPE。且 NPE 冲出 REPL 循环（AgentReplMain 只
捕获 PluginException），整个进程退出——"错误呈现后可继续"的承诺被击穿。

## 修复方案（计划）

1. `Session.deriveMessages`：TOOL_CALL / TOOL_RESULT 分支对 null toolCallId 跳过
   （旧格式事件无法满足协议关联，跳过优于崩溃）
2. `AgentReplMain`：REPL 循环逐轮兜底捕获 RuntimeException——坏数据不再杀死整个进程
3. 回归测试：SessionTest 增"旧格式工具事件跳过"用例（手写旧格式 JSONL 验证）

## 症状（建档时记录）

- 原样引用：

- 复现方式：会话目录存在**修复前**写入的旧格式 tool/call 事件（无 toolCallId 字段）→ 启动 AgentRepl 自动继续该会话 → 任意输入触发投影 → NPE，整个 REPL 进程退出（BUILD FAILURE）。

## 排查记录

- 假设 1：SessionEvent 解析旧格式行失败 → 验证：parse 对缺失字段已容错（读出 null）→ **排除**
- 假设 2：投影层对 null toolCallId 未设防 → 验证：deriveMessages 的 TOOL_CALL 分支直接 `new ToolCall(event.toolCallId(), ...)`，而 ToolCall 紧凑构造器 `Objects.requireNonNull(id, "id")` → **成立**
