# BUG-20261002-02 · 会话新事件到达后，已翻页加载的更早内容被重置回尾窗

**Status**: done（2026-10-02 M34 工单 03 修复：同会话 tail-snapshot 保留翻页历史 + 哨兵边界；浏览器面回归验证通过）

## 症状（建档时记录）

- 发现于：M33 浏览器实测·批 1（SESS-05/06 分页验证后，/export 命令与一次对话轮到达时复现）
- 原样引用（DOM 实测计数，2026-10-02）：

```
翻页到顶时：  countMsg1=1, countMsg60=1, head="夹具消息 1：…", 占位「已耗尽」
新事件到达后：countMsg1=0, countMsg60=1, head="已确认夹具消息 36。…", 占位「更早还有 71 条 · 向上滚动加载」
```

  - 即：用户滚动分页加载出的 35 条更早消息（夹具消息 1-35）从 DOM 消失，视图整体回退到尾部窗口（50 条消息投影），分页进度清零
  - 截图：`.scratch/m33-browser-audit/evidence/BUG-20261002-02-翻页进度被新事件重置.png`（重置后状态：占位复活 + 头部从消息 36 起）
- 复现方式：打开超尾窗会话（>50 条消息，夹具 60 轮）→ 滚动翻页到顶（占位耗尽、首条在 DOM）→ 任意新事件到达（实测 /export 命令与一次对话轮均可触发）→ 视图重置回尾窗
- 服务端数据无损（协议面 /api/session/export 头尾完整）——纯前端视图态丢失

## 排查记录（定位过程，逐步追加）

- 假设 1：新事件渲染路径走了整窗重渲染（resetForReplay / setTailWindow 全窗替换），未保留 prependEvents 已加载的更早节点 → 验证：app.js 中 setTailWindow(windowEpoch++) 注释「加载期间窗口被整窗替换」与 loadEarlier 的 epoch 防护只护「加载中」竞态，不护「加载完成后」的新事件到达；观察窗口重置与 tailWindow 语义吻合 → 结论：方向成立，具体触发帧（command/done 或 user/message 或 replay 局部重放）待修复批实钉
- 影响面：长会话回看体验（翻页进度反复丢失）；M33 后续批次 SSE-02（回放一致性）、CARDS-15（回放一致性）执行时以此为已知背景

## 根因（定位后填写）

实钉（2026-10-02 M34 工单 03，修正档案假设）：**触发帧 = 同会话 tail-snapshot 重放，非「新事件 append」**——SSE 的 replay/start（mode=tail-snapshot）在首连/刷新/切换/同会话幂等重连时都发（ADR-0013），handle() 对其一律 `resetForReplay()` 无差别清空 #messages——翻页 prependEvents 加载的更早节点与尾窗基线节点在 DOM 无标记区分，整窗清空即分页进度清零。批 1 的「/export + 新事件后重置」实为该重连形态的一次实例（重连何时发生由连接状态决定，与命令卡无因果——批 4 的收窄观察「user/message 轮不触发」实为该轮期间恰无重连）。机制：prependEvents 把全部现有子节点搬入 fragment 后重排（翻页内容与基线内容混排无界标），清空无法只清基线。

## 修复方案（计划，改前填写）

已执行（M34 工单 03）：① prependEvents 插 `#prependedSentinel` 哨兵（每次翻页重插一枚，哨兵之上恒为翻页已加载历史）；② resetForReplay(opts.keepPrepended)——保留哨兵及其以上节点、只清哨兵以下尾窗基线（哨兵缺席时保持全清）；③ handle() 的 tail-snapshot 分支——同会话（frameSession === event.sessionId）传 keepPrepended，换绑/首连全清。

## 修复与验证

- 改动：app.js 三处（prependEvents 哨兵 / resetForReplay keepPrepended / handle 同会话判定）
- 回归测试：浏览器面（M33 口径）——f100 翻页到顶（占位耗尽、首条在 DOM）→ 点击当前会话（幂等切换触发同会话 tail-snapshot）→ 首条仍在 DOM、尾窗完好共存（msgLen 1660）；证据 `.scratch/m34-1.0.1-fixes/evidence/工单03-BUG02-翻页进度保留.png`。语义变更注：换绑/切会话仍全清（他会话历史不得残留，原设计保持）
- 防复发：哨兵边界机制入库；「整窗替换的保留语义」随 resetForReplay 注释在案
