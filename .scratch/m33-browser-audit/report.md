### 观察项（非缺陷，行为澄清与设计边界）

- **O1 空会话不入列**：新话题建的空会话不出现在侧栏，首条消息后入列——列表只承载有内容会话（A1）。
- **O2 occupied 属主语义**：sessions API 的 occupied = 会话文件锁属主在册（打开即持有，不随轮次结束释放），非「运行中」；与独占锁设计一致。
- **O3 侧栏不自动刷新他端新建会话**：curl 起的会话在刷新页面前不入侧栏（批 4 SSE 域复核是否有会话级推送）。
- **O4 Web 斜杠命令集**：compact/title/export 三个；命令结果 toast 呈现不进对话面。
- **O5 busy 拒切**：运行中会话不可切走（409 + 明确文案），串行设计（M19）的自然推论；SESS-12 据此以「拒切安全」达成。
- **O6 执行纪律（自省）**：无 tabId 的协议面 /api/message 会落到服务端 current 会话起真实轮——本批一次 curl 探针误起「Ping」轮，此后协议面探针一律避开 /api/message 或显式带 tabId。
