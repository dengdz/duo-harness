# 02: subagent 模板装配与工具接线

## What to build

部署者获得子 agent 模板制装配：`subagent` 插件 config 定义一套或多套模板（工具清单 + 可选专属提示），严格绑定解析（未知字段/类型点名报错，先例 governance 段解析）；**强制默认过滤**——交互工具（ask_user / exit_plan_mode）与控制面工具不进子模板可用集（模板配置了也过滤，非可绕过）；spawn/fork/send_message/interrupt_agent/list_agents 五件工具**仅在装配了 subagent 模板的实例上注册**（未配置部署零变化）。

## 实现记录

- `agent.subagent` 新包（package-info 已立）：`SubagentTemplate`（record：name/tools/prompt + `FORBIDDEN_TOOLS` 强制排除集 + `allowedTools(registered)` 可用集计算——禁用工具配了也滤除，治理底线是过滤非报错）、`SubagentTemplates`（config 严格绑定解析：未知字段/类型错/重名/空清单一律点名，templates 段缺席即空集）、`SubagentPlugin`（模板空 → 零副作用返回 null；非空 → 经 `registerAgentTools` 机制注册供给清单）。
- 五件工具本体归工单 03/04：供给清单 `AGENT_TOOLS` 目前为空，本体就绪逐项挂入；条件注册机制已用 fake 供给锁定（注册全注册、未配置模板零出现）。
- 测试：SubagentTemplatesTest 11 用例（解析/过滤/查寻）+ SubagentPluginTest 2 用例（真内核装配：无模板零注册断言工具清单与装配前一致、机制注册断言），13 用例全绿；全仓库 compile 零破坏。
