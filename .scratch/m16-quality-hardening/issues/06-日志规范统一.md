### 验收对照表（2026-09-17 备，实测快照）

**验收 1：诊断带级别与 logger 署名**（原为无级别 `[会话标题] xxx` stdout 打印）

```
./mvnw -B -ntp -pl duo-harness-agent -am test -Dtest=SessionTitlesTest -Dsurefire.failIfNoSpecifiedTests=false 2>&1 | grep "dev.duo.harness.agent.SessionTitles"
```

应出现（2 行，含失败用例的异常栈）：

```
[session-title-watch-20260917-164901-7f9e] WARN dev.duo.harness.agent.SessionTitles - 会话标题生成超时，降级截断（会话 20260917-164901-7f9e）
[session-title-watch-20260917-164903-09e3] WARN dev.duo.harness.agent.SessionTitles - 会话标题生成失败，降级截断
```

**验收 2：可级别、可关断**（同一套件，两档对照）

```
# 开 debug：
./mvnw -B -ntp -pl duo-harness-web -am test -Dtest=WebFaceTest -Dsurefire.failIfNoSpecifiedTests=false -DargLine="-Dorg.slf4j.simpleLogger.defaultLogLevel=debug" 2>&1 | grep "DEBUG dev.duo.harness.web.WebFace"
# 默认级（不加 -DargLine）：
./mvnw -B -ntp -pl duo-harness-web -am test -Dtest=WebFaceTest -Dsurefire.failIfNoSpecifiedTests=false 2>&1 | grep -c "DEBUG dev.duo.harness.web.WebFace"
```

应出现（debug 级，4 行量级）与应消失（默认级计数 0）：

```
[] DEBUG dev.duo.harness.web.WebFace - SSE 连接：模式=tail-snapshot，游标=null，事件数=60
[] DEBUG dev.duo.harness.web.WebFace - SSE 连接：模式=incremental，游标=1，事件数=3
```

**验收 3：交互输出不变**（REPL 冒烟；诊断不再混入交互流）

```
printf '/exit\n' | ./mvnw -q -pl duo-harness-example -am package -DskipTests exec:java -Dexec.mainClass=dev.duo.harness.example.agentrepl.AgentReplMain > /tmp/repl-out.txt 2> /tmp/repl-err.txt
# 前台可见提示符后 Ctrl-C 结束保活进程，然后核对：
tail -5 /tmp/repl-out.txt ; grep -c "\[web\]\|\[会话标题\]\|\[上下文治理\]" /tmp/repl-out.txt
```

应出现（启动横幅 / 会话行 / 提示符 / 收尾；未配置时可能先有"会话已被占用"改用新会话的提示）：

```
会话 20260917-xxxxxx-xxxx（工具循环上下文）。/exit 退出，/new 开新话题。
[duo] 插件树已启动，Ctrl-C 停止。
你> === 对话结束 ===
```

且诊断前缀计数为 `0`。**勿用 `| tail -4` 形态**——管道缓冲到进程结束才输出，而 REPL 靠 Ctrl-C 退出，会看不到内容（首轮验收实际踩到）。

**验收 4：绑定齐全 + 全量绿**

```
./mvnw -B -ntp verify 2>&1 | tee /tmp/verify.log | tail -3
grep -c "No SLF4J providers" /tmp/verify.log
```

应为：`BUILD SUCCESS` + 计数 `0`（补齐前为 3——agent/web/cli 测试运行时无绑定）。

**说明**：`exec:java` 为进程内运行（绑 Maven 自带 provider，不受 `-Dorg.slf4j.simpleLogger.*` 控制）；slf4j-simple 行为在 forked 测试 JVM（上面验收 1/2）与 IDEA 直接 Run（真实 JVM，运行时绑定由 example 的 runtime 依赖提供）中可见。
