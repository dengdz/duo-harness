# 05: LLM 流式空闲超时

## What to build

LLM 流式空闲超时（术语：流式空闲超时）——流式响应连续 N 秒无新字节判流已死：尚未交付任何 chunk 时按可重试错误走既有重试链；已交付增量后终止本轮并保留已输出文本（对齐"已交付不重试"的流式安全语义）。provider 半开连接不再永久挂死 agent 循环：CLI 最多 90 秒拿到可重试错误、Web 单飞标志恢复。落点为响应体流的包装委托（单点覆盖直答与工具轮两条读取路径，不改两处逐行循环）。

## Status

ready-for-agent

## Checklist

- [ ] 响应体流包装空闲检测，缺省 90 秒不配也生效
- [ ] `llm.streamIdleTimeoutSeconds` 可配（llm 配置段可选字段）
- [ ] 桩服务用例：发响应头后停发字节 → 超时可重试；已交付增量 → 不重试且已输出保留；60 秒级停顿 → 不误伤思考模型
- [ ] 实测：代理断流模拟后 CLI / Web 恢复可交互
