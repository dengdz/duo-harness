# 03: 子代理审批钉死

## What to build

子代理审批钉死（术语：审批钉死）——子代理调用声明了 requiresApproval 的工具（如 bash）时**确定性拒绝 + 理由回传**，不再挂起等应答：恒否策略对象在子代理装配处注入，子代理工具视图委托前按策略裁决，拒绝文本与管线 DENY 格式一致并附"该步骤交回父代理处理"指引；拒绝作为工具结果进子代理上下文，循环继续、最终回答说明限制。不改动工具域公共 API（管线级调用方判别方案因侵入度否决）；交互工具本已被模板过滤，不在范围。

## Status

ready-for-agent

- [ ] 桩后端用例：拒绝后循环继续、最终回答引用限制
- [ ] 既有子代理测试全绿；CLI 实测含 bash 模板 spawn 不再挂起
