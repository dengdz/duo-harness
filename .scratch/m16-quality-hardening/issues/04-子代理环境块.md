# 04: 子代理环境块

## What to build

子代理 system 追加环境段——工作目录、操作系统平台、当前时间等运行环境事实（ZCode `<env>` 块对照、limitations M15#5）：子代理回答可引用正确的 cwd 与时间，不再对运行环境两眼一抹黑。父 agent 呈现位顺路补时间上下文片段（DSH time-context 同源事实）。

## Status

ready-for-agent

## Checklist

- [ ] 子代理 system 追加环境段，拼装顺序在装配点固定并注释
- [ ] 父呈现位补时间上下文片段（与子代理同源事实）
- [ ] 用例：子代理首轮请求的 system 含环境事实
- [ ] CLI 实测：问子代理"你在哪个目录、现在几点"，回答正确
