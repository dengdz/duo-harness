# 02: FTS5 检索引擎迁移与契约测试

## What to build

跨会话检索引擎从内存倒排索引整体切换到 SQLite FTS5（sqlite-jdbc，全仓首个 SQLite 依赖，ADR-0028 决策一审批留痕）：`SessionQueryService` 接口语义不变（单 query、多词 AND、每会话至多一条最强命中、score/mtime 排序、snippet 就近窗口、线程安全），Web 搜索框与 session_search 工具两入口零感知换引擎。**当前进行中的会话经 live 供数入检索（M21#1 活跃会话盲区消除）**；索引库懒构建、增量刷新不劣于现状、schema 版本不符就地整库重建；中文逐字 AND 与短语加分语义保住；模型 query 字面化（FTS5 查询语法永不执行、SQL 全参数化绑定）。契约测试基类钉住接口语义；内存倒排实现与专属测试退役删除。

决策依据：[ADR-0028](../../../docs/adr/0028-M26会话数据与检索立项决策.md) 决策一；DSH 机制对照见 `docs/research/DSH/网络与数据/会话检索与导出.md`。spec 接缝 1。
