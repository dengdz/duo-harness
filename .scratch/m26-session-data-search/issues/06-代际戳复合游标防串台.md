# 06: 代际戳——复合游标防串台

## What to build

翻页与断线重连的游标从裸整数升级为**「会话 id + 序号」复合游标**（分页 `before` 参数与 SSE `Last-Event-ID` 同语义）；**前后端双侧核对**——请求携会话 id（服务端校验与当前标签页绑定关系）、响应回带会话 id（前端校验不符即整页丢弃、重新对齐到尾部窗口快照）。切换会话或服务重启后，旧游标**明确失效**（返回"游标不属于当前会话"类语义），不再静默从错误位置续播、不再把新会话事件装进旧页面。不引入独立 generation 编号（duo 日志只追加，会话 id 即天然代际边界）；前后端同包发布，协议一步切到位，裸数字游标不再作有效续播凭据。

决策依据：[ADR-0028](../../../docs/adr/0028-M26会话数据与检索立项决策.md)（grill Q10/Q11）；ZCode 对照见 `docs/research/ZCode/Agent循环与会话/投影、恢复与分页.md`；术语见术语表「代际戳」词条。M10/M13 缺口防护记档见 spec Problem Statement。
