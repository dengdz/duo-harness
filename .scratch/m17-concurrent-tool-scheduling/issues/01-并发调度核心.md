# 01: 并发调度核心——安全声明、屏障分组与 model 序成对提交

## What to build

单轮多 tool_calls 端到端并发可用（术语：并发安全 / 独占工具 / 顺序屏障 / model 序提交 / 工具并行池 / 并发度，ADR-0018 决策 1-4）：模型一轮发多个只读调用时并行执行、总耗时接近最慢者；撞独占调用即屏障；无论完成先后，事件与结果严格按 model 序成对提交——事件日志形态与串行时代同构，增量回放 / 尾部窗口 / 投影 / 崩溃闭合零改动。落点：ToolDefinition 接口加带参声明，串行点在 agent 主循环的执行段改造为分组调度，日志写入收敛单点（会话单写者约定保持）。

## Status

ready-for-agent

## Blocked by

无（可立即开工）

## Checklist

- [x] `default boolean isConcurrencySafe(JsonNode args)` 声明 + fail-closed（未覆写 / 判定抛错 / 非严格 true 一律独占）
- [x] 首批标注：read / glob / grep 并发安全；write / edit / bash / ask_user / exit_plan_mode / skill / subagent 五件套独占；MCP 远端工具恒独占
- [x] 屏障调度：按 model 序扫描，连续安全调用成组进虚拟线程滚动池，独占调用排空当前池单独执行再继续；`requiresApproval() == true` 恒不进池
- [x] 并发度 `maxParallelToolCalls` 缺省 10、yml 可配（与 maxIterations 同族装配 config）；=1 即完全串行；超限排队补位不拒绝
- [x] 成对有序提交：tool/call 与 tool/result 按 model 序成对写入，并发轮日志与同等串行轮对照同构；提交收敛单点
- [x] 测试（fake LLM 桩 + 受控 fake 工具）：model 序成对断言；墙钟（并行总耗时显著小于串行和）；屏障互斥（独占工具执行期间无其他工具在飞，探针进出时间戳）
