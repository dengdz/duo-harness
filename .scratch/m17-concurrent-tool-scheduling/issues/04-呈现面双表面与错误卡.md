# 04: 呈现面——todo 双表面、CLI 摘要与迭代上限错误卡

## What to build

用户看得见 agent 的计划与进度、Web 不再无提示停住（ADR-0018 决策 6/7）：Web 会话流工具行显示 todo 摘要（"done/total 已完成 · 活动任务"），输入框上方常驻折叠面板展开为圆圈状态清单（带勾实圆 = 完成、圆环 = 进行中、虚线圆 = 待办，空清单不渲染）；CLI 在 todo_write 调用时打一行计数摘要（跟随既有工具行风格）；agent 达迭代上限返回未完成时，Web 面直推一帧 run/error 错误卡（补 BUG-20260917-03 验收 B 实测缺口：页面无提示地停住）。

## Status

ready-for-agent

## Blocked by

03（消费 todo/write 事件与投影）

## Checklist

- [ ] Web 工具行摘要：todo_write 调用行渲染 done/total 与活动任务内容
- [ ] Web 常驻折叠面板：输入框上方、默认折叠一行进度摘要、展开圆圈状态清单、空清单不渲染
- [ ] CLI 计数摘要行：todo_write 调用时终端一行（"清单已更新：X 待办 / Y 进行中 / Z 已完成"风格）
- [ ] 迭代上限错误卡：completed=false 时 Web 经 /api/message 路径直推 run/error 帧，复现 BUG-20260917-03 场景（页面无提示停住 → 出现错误卡）
- [ ] 测试（WebFace HTTP 交换层 seam）：todo/write 事件到前端的数据通道、run/error 帧下发
- [ ] 手动验收（duo-acceptance）：Web 双表面视觉走查 + CLI 摘要走查（红线 5：UI 改动必须视觉验证后才算完成）
