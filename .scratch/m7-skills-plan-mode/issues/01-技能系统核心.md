# 01: 技能系统核心

**What to build:** agent 获得可复用的能力包机制：SkillRegistry 启动时按四根发现扫描（`.duo/skills` → `.agents/skills` → `~/.duo/skills` → `~/.agents/skills`，同名高优先根胜），解析 SKILL.md 目录包与单文件 `<name>.md`（frontmatter name + description），聚合"名称 — 描述"清单片段注册进 prompt 注册表；`skill` 工具挂进工具域——模型按名调用即返回该技能指令全文（走六段管线）；yml 禁用配置命中者不加载、不进清单。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

## Checklist

- [ ] SkillRegistry（agent 域）：四根扫描 + 优先级覆盖 + 双形态解析（frontmatter 只认 name/description）+ 按名查询
- [ ] 项目根以 .git 标记定位；扫描失败（目录不存在）静默跳过
- [ ] 聚合清单片段（"名称 — 描述" + skill 工具使用说明）注册进 prompt 注册表
- [ ] `skill` ToolDefinition：参数 `name` 必校验；按名返回指令全文（附"请遵循以上技能指令"提示）；未知技能名收敛为 error 结果；走六段管线
- [ ] 禁用配置：装配行 `config: {"disabled": [...]}`，命中者不加载不进清单
- [ ] 测试（SkillRegistry 新 seam）：临时目录夹具——优先级覆盖 / 双形态 / 禁用 / 空根跳过
- [ ] 测试（ChatRequest 捕获 seam）：清单片段进 system 组装
- [ ] 测试（ToolsService seam）：skill 工具按名返回 / 未知名 error
- [ ] 文档同步：CHANGELOG 未发布段记技能系统；词汇表新增"技能 / 发现根"词条
