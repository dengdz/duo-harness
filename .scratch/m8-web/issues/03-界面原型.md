## 实现记录（2026-09-13）

- 产物：`duo-harness-web/prototype.html`——自包含（无外部依赖），双击即可预览；覆盖 9 种界面形态
- 样式 token 全部取自 DSH ui-theme 亮色规格：deepseek-450 品牌蓝 rgb(86,134,254)、deepseek-50 浅蓝底 rgb(237,243,254)、柔光阴影 lv1~lv2、描边分离、大圆角（--radius 16px）、系统字体栈 + 等宽代码字体
- 交互按钮带 hover 态预览（primary 深蓝 / 次选描边）；助手流式含光标动画态示意
- 增补（用户验收反馈）：三列布局加**会话侧栏**（当前高亮 + 修改时间倒序 + 新话题按钮）——DSH ui-sidebar 极简版；内置浏览器截图质检通过（首屏 + 滚动两屏）
- 半交互化（用户定案"做一半"）：HITL 三卡 + 输入框 + 会话侧栏全部可点击——本地视觉流转 + 假响应（审批批准/拒绝、提问回答、计划批准/打回、会话切换高亮）；**不模拟真实 SSE/agent**（那是工单 04/05 实体，交互脚本届时平移复用）
- 工具卡合一（用户验收追问"工具/错误怎么排列"后对齐 DSH ui-tool）：**调用与结果合成一张卡**——工具名 + 状态徽标（✓ 成功 / ✗ 被拒绝 / ⟳ 运行中三色）+ 参数 pre + 结果 details 可折叠（默认收起，成功卡可展开）；错误态红边红底。不再有独立的"工具结果卡"
- 会话模型 v2（用户验收反馈）：**新话题 → 初始空状态（EmptyHero 风格：居中品牌标识 + 标题 + 提示，对话流隐藏，首条消息发出后切入对话流）**；点击历史会话 → 重放该会话假历史并高亮——对齐 DSH EmptyHero 组件形态（fish logo + 标题 + workspace chip + composer 原位）
- 内置浏览器全交互验证：批准 → 假回复上屏；提问选项 → 已回答流转；计划批准 → 事件卡片收束；会话切换 → 对话区假重置。全部通过
- 过程发现（测试工具层）：IAB 自动滚动与点击派发存在竞态（实测位移 122px，点击落在 PRE 上）——Playwright 真实鼠标点击不可靠，**项目测试模式定为 evaluate 原生点击**（可靠且语义等价）；真实用户点击不受影响
- 待办：用户过目 → 冻结 → CSS/结构/交互脚本演进为 /web/index.html（工单 04/05 把假响应替换为真实 SSE/agent 接线）
