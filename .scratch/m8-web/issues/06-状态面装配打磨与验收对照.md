| 场景 | 操作 | 预期 |
|---|---|---|
| 一、页面与状态面 | 浏览器打开打印的地址 | 双区布局：左对话（续接最新会话历史）/ 右插件六态表 + 工具清单（含 mcp__files__* 与 skill） |
| 二、Web 对话 | 输入框发送 `读一下 notes.txt` | 用户消息上屏 → 工具卡片 → 流式回复；会话 JSONL 同步 |
| 三、Web 审批 | `写一个 hello.txt` | 审批卡片出现 → 点批准 → 写入成功；点拒绝 → 模型解释 |
| 四、Web 提问 | `我想存个笔记，先问我存哪` | ask_user 卡片（选项+自由输入）→ 回答后模型继续 |
| 五、断连 fail-closed | 审批卡片出现后关闭页面 | 悬空审批自动拒绝；重开页面模型可见"未获批准" |
| 六、计划模式 | `/plan 整理示例目录` | 指导片段生效 → exit_plan_mode → 页面计划复核卡片 → 批准执行 / 打回反馈 |
