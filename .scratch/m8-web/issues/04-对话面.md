# 04: 对话面——消息发送与流式渲染

**What to build:** 页面输入框提交 → `POST /api/message` → Web 层调用自己装配的 agent（全套 M6/M7 装配：prompt 注册表 + 技能 + AGENTS.md + 计划模式）流式执行 → chunk 与工具调用卡片、工具结果、最终消息经 SSE 实时推送渲染进对话区。含 `/new` 等价能力（页面按钮开新会话）。Web agent 续接最新会话；CLI 与 Web 同时操作同一会话的并发不做（文档约定单入口）。

**Blocked by:** 02, 03（骨架承载 + 蓝图冻结）

**Status:** ready-for-agent

## Checklist

- [ ] `POST /api/message`（JSON body `{text}`）→ 装配 agent.send 异步执行（不阻塞 HTTP 响应，立即 202/Ack）
- [ ] agent 回调（onChunk / onToolCall / onToolResult）经 Session 监听器或直转 SSE 事件推送（assistant/chunk、tool/call、tool/result 形态）
- [ ] 对话区渲染：用户消息即时上屏、助手流式文本逐字追加、工具调用/结果卡片按 SSE 事件出现（样式按工单 03 冻结蓝图）
- [ ] `/new` 等价：页面按钮 → 新会话 + 重建 agent + 对话区清空
- [ ] 测试（mock agent）：POST 后 SSE 收到 chunk 序列与 tool/call、tool/result 事件；消息入会话（SessionTest 先例）
- [ ] 文档同步：CHANGELOG 未发布段记对话面
