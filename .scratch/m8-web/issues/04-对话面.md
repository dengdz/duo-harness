# 04: 对话面——消息发送与流式渲染

**What to build:** 页面输入框提交 → `POST /api/message` → Web 层调用自己装配的 agent（全套 M6/M7 装配：prompt 注册表 + 技能 + AGENTS.md + 计划模式）流式执行 → chunk 与工具调用卡片、工具结果、最终消息经 SSE 实时推送渲染进对话区。含 `/new` 等价能力（页面按钮开新会话）。Web agent 续接最新会话；CLI 与 Web 同时操作同一会话的并发不做（文档约定单入口）。

**Blocked by:** 02, 03（骨架承载 + 蓝图冻结）

**Status:** implemented（2026-09-13，待用户验收）

## Checklist

- [x] `POST /api/message`（JSON body `{text}`）→ 装配 agent.send 异步执行（立即 202；执行中再发 409 单飞串行）
- [x] 事件经 Session 监听器 → SSE 广播（pushEvent 多客户端；tool/call、tool/result、assistant/chunk 形态）
- [x] 对话区渲染：合一工具卡（状态徽标：⟳ 运行中 → ✓ 成功 / ✗ 失败，按 isError 与错误关键词着色）+ 流式文本
- [x] `/new` 等价：`POST /api/session/new` → 新会话 + onNewSession 回调重建 agent + SSE 换绑
- [x] 测试：WebFaceTest 5 例（静态页 / status JSON / POST→事件入会话 / 409 单飞 / /new 新 id）
- [x] 文档同步：CHANGELOG 未发布段记对话面 + run/error 事件

## 实现记录（2026-09-13）

- WebFace 演进：session 可换绑（bindSession 解绑旧订阅）；pushEvent 广播到 sseOutputs 多连接；busy AtomicBoolean 单飞
- WebPlugin 对话装配：RetryingAdapter(OpenAiCompatAdapter(LlmConfig.load())) + ToolCallingAgent(prompts 全套)；/new 经 onNewSession(supplier, onCreated) 重建
- session 域新增 RUN_ERROR 事件类型（errorEvent 工厂）——SSE 直推不落会话
- 包迁移：dev.duo.web → dev.duo.harness.web（与全仓库包约定一致）
- 过程修正：WebPlugin 的 WebFace.start 需 try-catch IOException 转 PluginException；测试 mock 的 session 引用须延迟读取（start 之前构造）
- 已知边界（如实记档）：Web 面只补 assistant/chunk 会话事件，user 消息与 tool 事件由 agent 侧追加（与 CLI 同构）；run/error 不落会话
