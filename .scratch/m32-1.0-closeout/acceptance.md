**判据**（ADR-0016 原文）：「具名候选全部 done 或明示出栈」。

### 二、CI 绿常态

**判据**（ADR-0016 原文）：「CI 绿为常态且无 S 级质量债」。

**证据**：

- **常态绿有据**：累计 124 个 workflow run；2026-10-01 `ci`/main 绿 + `release`/v0.26.0 绿（GitHub Release 在档，jar + sha256 资产齐全——API 实证）。
- **当前破口（2026-10-02T01:56Z 实测）**：同一提交 `a668cd0c`（tag v0.27.0 = 0.27.0 分支头 = main 头，`git rev-parse` 三点同值）三跑不同果——`ci`/0.27.0 分支**绿**、`ci`/main **红**（verify job「构建与全量测试」步失败，run 36953263293）、`release`/v0.27.0 **红**（同名步骤失败，run 36953263315）。后果：**v0.27.0 的 GitHub Release 未发布**（API `Not Found` 实证；v0.26.0 对照在）——tag 在、对外发布物不在。
- **flake 指向（非内容回归）**：同提交异果 + 本地全量测试 BUILD SUCCESS（2026-10-02 11:26，`./mvnw test` 14 模块全绿 2:23，内容 = main + 纯文档改动）。
- **S 级质量债**：review-log 现存记录无未闭合 S 级债（2026-10-02 grep 核对；M27/M28 两轮全仓审查线清账）。

- **闭合执行（2026-10-02，用户重跑）**：两条失败 run 重跑后**同 ID 翻绿**（[ci/main 36953263293](https://github.com/dengdz/duo-harness/actions/runs/36953263293) → success、[release/v0.27.0 36953263315](https://github.com/dengdz/duo-harness/actions/runs/36953263315) → success，API 实证）；v0.27.0 Release 已发布（`duo-harness-0.27.0.jar` 22.4MB + sha256 资产，API 实查）——发版缺口就此补齐；flake 排查已挂 1.0 后菜单（backlog）。

**结论**：**成立**（2026-10-02 闭合）。常态绿 = 累计 124+ runs、10-01 双绿 + 破口当日重跑双绿；唯一一次红（0.27.0 发版当日）经同提交异果 + 本地全量绿定位为间歇性失败，已记档并挂账排查；S 级质量债零未闭合；对外产物两查通过（v0.26.0 / v0.27.0 Release 资产实证）。**盖章（工单 05）前置解除**。
