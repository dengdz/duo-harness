# 03: 会话锁

## What to build

同一会话文件不允许两个进程同时写入：第二个进程打开已被占用的会话时得到明确报错，而不是静默分脑（JSONL 交错追加、两侧上下文分叉，BUG-20260914-01 的结构性根源）。只拒绝、不协作——跨进程写协调等真需求出现再升级。

## Blocked by

无（可立即开工）

## Status
ready-for-agent

## Checklist
- [ ] 会话打开时取得进程级文件锁并持有至会话关闭（session 域增量，不改事件溯源语义）
- [ ] 锁被占时的三处呈现：Web 启动失败并指明被占会话、CLI 打开时明确提示、会话切换返回占用错误
- [ ] 测试：两个 Session 实例争用同一会话文件，后者报错、前者不受影响
- [ ] 单进程正常路径回归绿（既有会话测试不破）
