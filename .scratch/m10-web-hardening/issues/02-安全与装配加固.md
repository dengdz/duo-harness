# 02: 安全与装配加固

## What to build

本机工具的三处防线 + 纯 Web 部署的 HITL 补全：非法会话 id 与超大请求体被直接拒绝、错误响应不再回显内部异常细节；只有 Web 部署（无终端）时，模型的提问与计划呈交照常弹出交互卡片并可作答——HITL 能力不再依赖 CLI 装配在场。

## Blocked by

无（可立即开工）

## Status
ready-for-agent

## Checklist
- [ ] 会话切换 id 按格式白名单校验，路径分隔符与 `..` 一律拒绝（测试含目录穿越用例）
- [ ] POST 请求体设大小上限，超限拒绝（测试覆盖）
- [ ] 404/500 响应体改通用描述，不回显异常消息（异常细节仅服务端控制台）
- [ ] `/api/sessions` 端点测试补齐（M8 零覆盖）
- [ ] WebPlugin 装配链补注册 ask_user 与计划呈交工具（对齐 CLI 装配清单，装配测试断言工具清单）
- [ ] Web 冒烟：纯 Web 装配下提问卡/计划卡弹出并可作答
