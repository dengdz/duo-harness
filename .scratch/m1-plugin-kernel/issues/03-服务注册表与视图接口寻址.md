# 03 — 服务注册表 + 视图接口寻址

## What to build

插件间的服务注入：服务提供者发布具名服务（provide / 服务基类），消费者声明 inject 依赖列表后经 `ctx.as(视图接口)` 取服务——动态代理按方法名解析到字符串服务名。注册表内部 key 从第一天就是 (服务名, 作用域) 二阶结构（isolate 预留，仅全局默认作用域）。服务缺失时注入方进入等待而非报错。完成的判据：发布→注入→视图寻址全链路可用例复现；未声明 inject 读服务得到点名报错（spec 用户故事 9/12/13，接缝 B）。
