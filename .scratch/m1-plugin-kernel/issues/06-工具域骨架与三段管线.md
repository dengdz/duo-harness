# 06 — 工具域骨架 + 三段管线

## What to build

duo-harness-tools 模块：工具域骨架（ToolDefinition 基础字段：name / description / parameters / execute）+ 工具注册表（register 返回 disposer、注册即 effect 随插件回收）+ 三段 waterfall 执行管线（pre-execute 准入可否决 → execute 包裹本体 → post-execute 结果可改写或拦截）。工具域自身以服务形式发布（供视图接口寻址），任何插件可注册工具、可在三段上挂监听。完成的判据：注册的工具经管线执行返回结果；pre-execute 否决阻止执行；post-execute 改写结果——三段语义均可用例锁定（spec 用户故事 16/17/18，输出契约等强化件不在本票）。
