# 06 — 工具域骨架 + 三段管线

## What to build

duo-harness-tools 模块：工具域骨架（ToolDefinition 基础字段：name / description / parameters / execute）+ 工具注册表（register 返回 disposer、注册即 effect 随插件回收）+ 三段 waterfall 执行管线（pre-execute 准入可否决 → execute 包裹本体 → post-execute 结果可改写或拦截）。工具域自身以服务形式发布（供视图接口寻址），任何插件可注册工具、可在三段上挂监听。完成的判据：注册的工具经管线执行返回结果；pre-execute 否决阻止执行；post-execute 改写结果——三段语义均可用例锁定（spec 用户故事 16/17/18，输出契约等强化件不在本票）。

## Comments

- 实现修正：ToolsServiceImpl 不继承 Service 基类——发布时机由 ToolsPlugin.apply 掌握（provide 返回注销器即 apply 清理职责）；初版"构造即发布 + apply 再 provide"造成双重注册（测试抓到）。
- register 契约取显式形参 register(registrant, definition)：注册即注册方作用域 effect 的硬契约不依赖调用方处理返回值；ocr 发现的顺序泄漏（先入表后挂 effect，销毁竞态残留）已修——先挂 effect 再入表，重名时补偿摘除。
- 工具异常收敛为 error 结果不上抛（对齐 DSH isError 路径）；报错取瀑布包装链的最深 cause。
- pre 否决 = 监听器 deny(reason) 后不调 next（否决含默认放行）；post 治理 = setResult/markError；execute 段 around 语义供超时/重试类监听器挂载（M2 强化件）。
- 76 用例（66 core + 10 tools）三连跑全绿。
