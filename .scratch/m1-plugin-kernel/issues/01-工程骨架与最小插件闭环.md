# 01 — 工程骨架 + 最小插件闭环

## What to build

仓库从零到"第一个插件跑起来"：建立根 pom（JDK 21、dependencyManagement 统一管理 Jackson 依赖）与 duo-harness-core 模块骨架（api 包公开、internal 包藏实现、package-info.java 齐备、测试包镜像）。内核提供最小插件闭环的编程 API：定义插件（apply 入口 + config record 绑定）、编程式加载（ctx.plugin）、可逆 effect 注册与逆序回滚。完成的判据：一个测试插件经编程 API 加载后 apply 运行、其注册的 effect 在插件停止时按注册逆序全部回滚（接缝 B 首批用例）。
