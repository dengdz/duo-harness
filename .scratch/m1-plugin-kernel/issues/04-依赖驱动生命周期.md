# 04 — 依赖驱动生命周期（epoch 状态机）

## What to build

插件实例的六态状态机与 epoch 依赖指纹：PENDING（依赖未全就绪，等待）→ LOADING → ACTIVE / FAILED，依赖消失或 dispose → UNLOADING → DISPOSED。epoch = 依赖实现集合的指纹，指纹变化自动触发重载或停止：依赖全就绪才启动、任一消失自动停止、换实现自动重启。插件 apply/config 失败只使自己进入 FAILED，兄弟插件无感。完成的判据：spec 决策浓缩形状中的状态机全部迁移路径有用例锁定（spec 用户故事 2/3/4/11/19/22/24，接缝 B 的难点票）。
