# 01: 装配测试密闭化——DuoHome 测试注入口与两用例脱本机

## What to build

贡献者在任何机器上跑 `mvn test`，装配用例不再依赖本机 `~/.duo/config.yml`：DuoHome 解析链增加最高优先级的一级——系统属性 `duo.home`（`duo.home` > `DUO_HOME` > 缺省 `~/.duo`），两处经 `LlmConfig.load()` 读真实配置的装配用例改为套件前置设系统属性指向临时目录 + 写入最小 config.yml，套件后置清除。部署者侧 `DUO_HOME` 环境变量语义与优先级完全不变（0.8.0 及之前部署零影响）。

```bash

# 2) 两处装配用例密闭绿（临时 duo home 自足）
mvn -pl duo-harness-web -am test -Dtest=WebPluginAssemblyTest -Dsurefire.failIfNoSpecifiedTests=false
mvn -pl duo-harness-example -am test -Dtest=AgentReplMainTest -Dsurefire.failIfNoSpecifiedTests=false

# 3) 全量（改动波及 core/web/example 三模块，建议整树一遍）
mvn test
```
