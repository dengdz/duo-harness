# 03: 消息窗口单趟化

## What to build

框架维护者获得收敛后的分页定窗计算（ADR-0014 决策 2）：消息窗口三趟遍历（计数 / 定位 / earlier 统计）收敛为单趟——O(max) 下标环形缓冲记最近 maxMessages 条投影消息的位置，一趟完成计数与起点定位；earlier 以 tailStart 为基线（无需另趟统计），唯 tool/result 回折前移起点时按纳入窗口的消息数扣减。窗口边界语义**逐字不变**：消息边界对齐、tool/result 同 id 回折、孤儿结果不动起点、未截断起点固定 0 保留前导非投影事件——既有窗口用例（tailWindow 7 例 + windowBefore 3 例等）零改动全绿即等价证明。

## 实现注记

- 初版按"earlier ≡ tailStart 恒等式"直接返回基线，回折用例红（`tailWindowFoldsToolResultBackToItsCall`：expected 20 got 21）——回折把 TOOL_CALL 纳入窗口使起点前移，earlier 需扣减前移跨越的投影消息数（含调用卡自身）；孤儿结果（找不到同 id 调用）不回折、基线不变。既有回归网当场拦截了恒等式的边界破绽。
- 回折扫描是局部的（从起点向前到同 id 调用，常态相邻即 O(1)），非全量第三趟。
