# 01: 事件驱动主循环与两级收件箱

## What to build

CLI 主循环从阻塞 readLine 改为事件驱动：虚拟线程常驻读 stdin，每行注入 agent 域收件箱；收件箱由 M19 单级升级为两级——`next-step`（step 边界注入当前 turn，CLI 执行期键入的默认去处）与 `next-turn`（turn 收口后生效，承载内部事件与显式排队消息）。端到端行为：CLI 用户在 agent 执行期间键入一行，提示行回显「已插队」，模型在下一步边界即看到该输入（会话日志落普通 user/message）——执行期输入不再被静默当新输入消费。想开全新任务的用户走 02 的暂停。Web 端 busy 注入 202 路径行为不变（既有 seam 演进，向后兼容）。

决策依据：ADR-0025 决策一（事件驱动主循环与两级收件箱）；spec「架构底座」节；探测文档 docs/research/DSH/ZCode 的 Agent循环与状态机.md（收件箱两级与 step 边界消费语义）。收件箱为内存态，不做事件溯源持久化。不引 NIO/jline。
