# 09: 技能热加载

## What to build

用户修改 SKILL.md 或新增/删除技能后，当前会话免重启即生效：watch 监视发现根（含目录创建），变更使技能缓存失效（revision 递增）并重扫描；技能目录消息按内容 sha256 digest 去重——变化才重发、只重发一次（经 prompt 注册表片段刷新）。watch 不可用（如环境限制）降级为启动扫描现状 + 日志警告，不阻断技能发现。

决策依据：ADR-0025 Consequences（grill Q10 搭车项）；limitations M7#2；探测文档 DSH 扩展机制/skills与命令.md（watch + revision + digest 语义，唯一有实现的参考；ZCode 篇无 watch 记录）。
