# 02: Web 斜杠入口

**What to build:** Web 输入框识别斜杠——命中命令在 Web 端执行并回显（结果走既有事件流渲染，刷新/回放后命令历史可见）；未命中的 `/xxx` 报"未知命令 + 可用清单"；适用面不符（如 CLI 专属命令）提示"该命令仅在 X 可用"。斜杠文本从此不再透传进模型历史（M12-03 验收事故销账）。

**Blocked by:** 01（命令注册表地基 + CLI 迁移）

**Status:** ready-for-agent

语义权威：ADR-0020 决策 3/5；spec 实现决策"命令注册表（agent 域）"与"会话事件与投影"节。

- [ ] WebFace 输入路径前置命令解释：命中注册表命令 → 同步执行于 Web 进程内（不占 agent 单飞窗口、不 append user/message）→ 回显结果
- [ ] busySafe 分级：agent 执行中 busySafe 命令照常执行回显；非 busySafe 回应"执行中，需等待空闲"（HTTP 层面语义明确，非无差别 409）
- [ ] 未命中 `/` 前缀输入报"未知命令"附可用命令清单（按发起面过滤适用性）；非本面命令提示"该命令仅在 X 可用"
- [ ] 命令执行的 command/run、command/done 事件经既有 SSE 事件流推送，前端渲染轻量命令行（名 + 结果），刷新/回放可见
- [ ] 技能直调入口在 Web 同样成立（命令未命中 → 技能前缀注入照旧走 agent）——两表一入口顺序双面一致
- [ ] 测试走缝 3 WebFaceTest：斜杠命令执行与回显、未命中报错、适用面提示、执行中 busySafe 行为；前端渲染改动经既有事件流无新端点
