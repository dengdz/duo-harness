# 02: 03-高级·技能编写章交付

## What to build
`docs/03-高级/` 下技能编写章成章（300-600 行）：SKILL.md 结构与五支柱教程化（description 三规则、完成判据与证据先行、检查点阻塞化、领先词与词汇一致、否定收敛）、技能发现与热加载机制、skill 工具调用面、以 duo-* 实例技能为活体参照。读者定位：不翻源码就能写出合规技能的插件开发者。成章即审查即验收。

01, 05（大纲确认；ZCode 研究不阻塞本章但大纲若引用其结论需其先行——以 outline 为准）

ready-for-agent

## Checklist
- [ ] 成章，篇幅 300-600 行，风格对齐既有文档（`> 状态：` 引言块、里程碑+ADR 括注、活体示例、无 frontmatter）
- [ ] 机制侧补齐：发现根、热加载、skill 工具按名加载——以源码实测为准（探索结论进章前关键行抽查）
- [ ] 教程化改写不照搬规范原文——规范是「写作标准」，本章是「怎么写」的操作路径，互链不重复
- [ ] 示例全部活体（.agents/skills 实例技能、真实机制），可复制可对照
- [ ] 内链自查（互链目标存在、相对路径正确——死链闸门被 ADR-0005 关闭，人工兜底）
- [ ] docs 导航与 sidebar 同 diff 补 03-高级条目
- [ ] 提交前两 grep 自检（无调试残留；CHANGELOG 记账实证——文档章为用户可见面则记，纯内部教程口径收口时统一议定）
