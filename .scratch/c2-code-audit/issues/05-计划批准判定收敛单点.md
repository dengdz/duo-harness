# 05: 计划批准判定收敛单点

## What to build
"计划是否被批准"这一业务判定收敛为交互请求类型上的单点方法，计划审批工具与审计回答者两处调用方共用。收敛后，改批准文案或调整选项顺序不会造成审计事件（approval/decided）与真实批准状态相反——审计错记"✓ 已获批准"的隐患消除。

证据锚点：审计报告 P2-C 族第 14 条（两套判据：文案精确匹配 vs options[0] 位置约定）。

验收标准（用户可感）：无论用户以何种形态作答（命中文案/命中位置/打回），审计事件与浏览器计划卡状态始终一致。
