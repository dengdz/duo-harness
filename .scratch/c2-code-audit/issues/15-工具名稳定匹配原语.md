# 15: 工具名稳定匹配原语

## What to build
工具名体系提供去哈希的稳定匹配原语（工具名带命名哈希后缀的形态下按原始名精确匹配）；示例侧安全策略从"前缀匹配"回归精确匹配——工具名哈希化后不再有前缀碰撞误伤面。

证据锚点：审计报告 P2-C 族关联项 + P3 example 组第 13 条（WriteProtectorPlugin 被迫 startsWith，暴露主库 API 缺口）。

验收标准（用户可感）：以目标工具名精确声明的安全策略只命中该工具；新增同名前缀工具不被误伤。
