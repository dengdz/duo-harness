# 11: 附件缩放阶梯参数化收敛

## What to build
附件的规范化管线与请求变体管线共用同一"缩放 + 质量阶梯"参数化重编码实现（尝试次数、质量步长、缩放步长单点定义）；归一化字节预算常量统一引用一处——两条管线的压缩行为不再可能悄悄分叉，调参只改一处。

证据锚点：审计报告 P2-B 族第 10 条（同循环双份、一处常量一处裸写）+ 第 26 条部分（4MB 预算双份）。

验收标准（用户可感）：同一图片经两条管线得到一致的压缩决策；调整压缩策略一次生效。
