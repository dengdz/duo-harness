# 16: 连接状态板生命周期归位

## What to build
连接状态板的耗尽监听改为随插件树生命周期管理（订阅返回注销句柄、消费方挂到自身装配的销毁路径）；长驻进程多轮装配不再累积引用已销毁呈现位的监听——耗尽通知不再重复、不再发给已死呈现位，同进程测试不再互相污染。

证据锚点：审计报告 P2-D 族第 16 条（JVM 静态单例板 + 监听无摘除 API）。

验收标准（用户可感）：Web 多轮换绑/重启会话后，连接耗尽提示恰好送达当前活跃呈现位一次。
