# 17: 防御语义修正批

## What to build
四处防御兜底的语义修正：① workspace 判定中 realpath 失败的兜底从"放行"改为拒绝方向（安全闸门 fail-closed 语义归位，"保守放行"注释同步修正）；② MCP 状态板注册的"吞一切 RuntimeException 当复用"改为按类型判别或先探测；③ CLI 注销指导方法的 javadoc 与行为对齐（声称不阻断实为抛出），与闲置路径内联版合一；④ CLI 权限规则解析把"服务未挂载"与"服务故障"区分——故障时有一行日志可排障。

证据锚点：审计报告 P2-D 族第 19 条 + 第 22-24 条（fail-open 语义倒挂、吞一切、javadoc 相反、混同未挂载）。

验收标准（用户可感）：异常路径下 workspace 区外写不再被免审批放行；a/s 键失灵时日志能区分"未挂载"与"故障"。
