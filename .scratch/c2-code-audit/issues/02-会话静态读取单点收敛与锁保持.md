# 02: 会话文件静态读取单点收敛与锁保持（P1 止血）

## What to build
会话模块对会话 jsonl 文件的全部静态读取（标题读取、权限模式读取、占用探测、全量加载）收敛为单一静态读取入口，入口内置两道防线：活跃会话内存直取（不落盘读）、外部文件读取时"持锁者 fd 不关"（POSIX 锁陷阱防线）。收敛后，Web 侧栏每次刷新会话列表都不再放掉活跃会话的跨进程独占锁——双开保护持续有效。

证据锚点：审计报告 P1-2（titleOf 缺防线；permissionModeOf 已有防线可参照）。

验收标准（用户可感）：Web 面开着（侧栏刷新多次）的同时，另一进程 CLI 试图打开同一活跃会话仍被占用拒绝；占用状态查询与真实锁状态一致。
