# 09: 工具超时单点与管线放宽套用

## What to build
工具模块的等待上限常量（默认 30s / 上限 600s）、管线超时基准、clamp 逻辑收敛为单点；自带协作式超时的长等待工具按既有模式（等待上限 + 放宽余量）套用管线超时覆写——task-output 的"等待上限 600000 毫秒"参数承诺真实可达，不再被默认 120s 管线超时腰斩。

证据锚点：审计报告 P2-A 族第 3 条（task-output 漏套 bash 的管线放宽模式）+ P3 超时/clamp 散落聚类。

验收标准（用户可感）：模型按工具契约传长等待参数（>120s）时端到端可达，收到的不再是管线超时错误。

## Status
ready-for-agent
