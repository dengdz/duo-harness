# 06: 会话标题（精简版）

## What to build

侧栏从裸 id 变可读：首条 user/message 落日志后异步生成一次标题——独立直答小请求（非流式、关 thinking、超时 + 输出上限），以 `title` 事件追加进会话日志（latest-wins 投影）；LLM 失败/超时降级为首条消息前 20 字截断；侧栏显示标题（无标题回退 id）、浏览器标签页同步。不做演进重生成与改名。
