# 02: 历史向上分页

## What to build

滚动到顶部自动加载更早历史：分页端点按事件序号向前取 50 条投影消息的事件区间（携 hasMore 与更早计数），前端滚动到顶触发加载、顶部占位"更早还有 N 条"、加载后视窗位置保持不跳屏、hasMore=false 后占位消失。

## Blocked by

01（尾部窗口快照——复用投影边界映射与快照头帧语义）

## Status
ready-for-agent
