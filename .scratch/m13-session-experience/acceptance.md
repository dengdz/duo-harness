# M13 里程碑验收件（0.8.0）——会话体验：尾部窗口快照与分页范式

> 验收口径（duo-acceptance）：演示与测试两路逐条对照，用户亲手跑过确认才算验收。工单 01-06 已各自完成单类/功能级验证并转 done；本文件是里程碑级收口。

## 启动

```bash
mvn -pl duo-harness-example -am package exec:java \
  -Dexec.mainClass=dev.duo.harness.example.agentrepl.AgentReplMain
```

浏览器打开 `http://127.0.0.1:18080`。**80K 刷新实测与分页验证需要大会话**，先构造（见下）。

## 大会话构造（一次性）

没有天然大会话时拼接（事件行为独立追加行，拼接即合法会话）：

```bash
cd ~/.duo/agent-sessions
newid="20260916-080000-beef"                       # 后缀须 4 位十六进制
for i in $(seq 1 40); do cat 20260915-174057-8567.jsonl; done > "$newid.jsonl"
```

40 份 ≈ 2.6 MB ≈ **800 投影消息 / 38500 事件**，文本量折合约 80K token（4 字符/token 估算口径）——即验收硬指标的量级。刷新页面后侧栏出现该会话。

## 演示路径（Web 面逐条对照）

| # | 验收点 | 操作 | 预期 |
|---|---|---|---|
| 1 | 尾部窗口快照 | 刷新页面 / 切到大会话 | 首屏只回放最近 50 条投影消息，秒开；服务端日志 `模式=tail-snapshot`；头帧携 `hasMore=true` 与更早计数 |
| 2 | 分页占位 | 看对话区顶部 | 占位"更早还有 N 条 · 向上滚动加载"，N = 窗口外投影消息数 |
| 3 | 滚动加载 | 滚动到顶，连续多次 | 每次自动加载一页（50 条），**视窗不跳屏**；计数逐页递减；加载到最早后占位消失 |
| 4 | 小会话不触发 | 切到消息少于 50 条的会话 | 无占位、全量呈现 |
| 5 | 无刷新切换 | 输入框打几个字 → 点侧栏另一会话 | **页面不整页重载**（草稿输入框被清空属预期裁定，BUG-20260916-01）、内容切到目标会话尾部窗口、侧栏高亮与标签页标题跟随 |
| 6 | 切换后发消息 | 发一条消息 | 正常回复（无"执行异常"卡）——分脑回归修复回归点 |
| 7 | ＋新话题 | 点击 | 不重载，直接空态（duo-harness 欢迎页），侧栏出现新会话 |
| 8 | 会话标题 | 在新会话发一条消息，等 1-3 秒 | 侧栏当前项从 id 变为可读标题；浏览器标签页标题实时同步；刷新页面标题仍在（持久化） |
| 9 | 标题回退 | 观察无标题旧会话 | 侧栏照常显示 id |
| 10 | 占用标注 | 双开：第二终端另起一实例（改端口）或观察当前 | 被占会话灰显标"使用中"；当前会话标"当前 · 使用中" |
| 11 | 占用点击语义 | 点被占会话 | 仍明确报错（标注不禁用，0.7.0 语义不变） |
| 12 | 流式刷新回归 | 发"从一数到 100"，数到 ~50 时刷新 | 已输出部分立即可见，续流无缝，收口整段覆盖无重复（BUG-20260915-03） |
| 13 | governance 缺省一致 | 不配 `governance` 段 | 状态面 `0 / 128,000 tokens（… 压缩阈值 102,400 …）`——与 0.7.0 一致 |
| 14 | governance 配段生效 | agent-demo.yml 的 web 行 config 加 `governance: {contextWindowTokens: 32000}` 重启 | 状态面窗口变 `32,000`、压缩阈值 `25,600` |
| 15 | governance 错误点名 | governance 段写未知字段（如 `spillThreshold: 1`）重启 | 插件 FAILED，错误点名具体字段 |
| 16 | 双开 governance 一致性提醒 | 若 web 与 cli 都配段 | 两段互不同步是已知取舍（ADR-0013）——部署时自行保持一致 |
| 17 | 80K 会话刷新 < 2s | 用上面构造的大会话刷新页面，秒表计时 | 首屏（最近 50 条消息）呈现完成 ≤ 2 秒（验收硬指标，spec User Story 22） |

## 测试路径

```bash
mvn -o test          # 先杀 18080 实例避免端口/锁冲突
```

预期：零失败零错误。各模块基线（以 mvn 实跑计数为准，含参数化用例展开）：core 75 / tools 99 / mcp 19 / llm 30 / session 32 / agent 58 / web 38 / cli 16 / example 22。

自动化已覆盖（无需手验）：分页端点窗口数学/hasMore 翻转/越界拒绝/两页连续性、尾部窗口边界映射（回折/前导保留/孤儿结果）、游标增量回放不回归（US8）、标题生成/降级/去重/超时、governance 解析严格绑定、占用探测两态。

前端（app.js）无自动化——以上演示路径即其验收（spec Testing Decisions 明文）。
