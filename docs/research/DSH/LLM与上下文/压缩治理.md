## 机制全貌

契约层 `compaction/` 定义 `ctx.compaction` 与 `compaction/start|summary|end|prune` 四个 log-only 事件（compaction/src/types.ts:24-89）：事件只记锁与摘要输入、不进表面；表面替换由紧随其后的 `user/message`（surfaceOp=replace）完成，**被遮蔽内容永久留日志**，摘要事件记录 rawOutput/provider/model/usage，使一次性请求可从日志+代码重建（types.ts:41-49）。压力端是单例 `ctx.tokenMeter.measure`；触发端有二：每步 `agent/pre-step` 压力检查与 `agent/request-error` 的 `CONTEXT_WINDOW_EXCEEDED` 溢出恢复（compaction-basic/src/index.ts:144-220）。摘要输入=system 头+被遮蔽区派生消息+header tools，压缩指令作最后一条 user 消息，复用上次路由请求的 KV cache 前缀（region.ts:545-564、summarizer.ts:31-66）。压缩前先做 model-free 减量：pruner 裁超长工具结果、spill-policy 落盘超限结果。checkpoint 源标记 `{kind:'plugin',plugin:'compact',compactionId}`（checkpoint.ts:19-42），shadow-price 协议让消费者 O(1) 扣减被替换价格（types.ts:74-89）。

## 关键流程

① **自动**：阈值对路由目标模型 contextWindow（`llm.resolveModelInfo`），thresholdTokens=floor(window×0.8)、retainTokens=floor(window×0.16)（config.ts:20-23,144-147）；达标先 pruner 再 remeasure（index.ts:305-309），选区保留 priced 尾且不切开 tool-call/result 对（region.ts:118-156）。摘要走 `ctx.llm.stream`，provider/model 取 summarizationProvider/Model??最近路由 header??agent options（summarizer.ts:126-141）。落盘顺序：start（锁）→summary→replace 型 user/message（preamble+`<compacted-summary>…</compacted-summary>`）→end（region.ts:211-240,507-510）；摘要不小于原文则拒（region.ts:418-422）；pressure 至多 compactionRetries+1 次。溢出链：prune→selectRange(retain=0)→compactRegion→`{kind:'retry'}`，成功计数+1，assistant/message 或 idle 清零，超 maxOverflowRetries 放行原错误（index.ts:164-220）；摘要失败但已有 durable 替换也算 progress 可重试（index.ts:192-205）。

② **/compact**：command-compact/src/index.ts:67 调 `compactNow`，经 `agent.runMaintenance` 空闲槽执行，非 idle 同步抛 busy→人工文案（compaction-basic index.ts:372-416）；owner=null 独立 marker 对+成功后 flush。

③ **pruner**：8192/4096/1024（tool-result-pruner/src/config.ts:10-14），按 code point 裁中段，固定 marker `[... tool result middle pruned ...]`（config.ts:7）；每次替换=相邻 compaction/prune（影子价）+tool/result replace（index.ts:164-175）。

④ **image-offload**：监听 `IMAGE_OFFLOAD_REQUIRED` 带 `offloadImages` 数量，入口为 agent/request-error 与 compaction/summary-error waterfall（compaction-image-offload/src/index.ts:27-40）；记 `image/offload` 选最老未卸载图，投影标 `offloaded:true`，请求期换占位文本 `[image omitted to fit request image limits; …]`（project-message.ts:23、llm/src/content.ts:107-116）；retry 不耗重试预算。

⑤ **spill**：`maxInlineBytes` 未配置即整体不注册；超限全文 `saveText`（SpillRef=locator+bytes+retrievalHint，spill/src/types.ts:76-80），替换=对半分预算 head/tail 预览+notice `(N bytes omitted. Full formatted result stored at: <locator>. <hint>)`（spill-policy/src/notice.ts:20-22），notice 字节预留进 cap；fail-open：无 owner/无后端/保存失败 warn 后保留原文（spill-policy/src/index.ts:133-156）；跳过 read 防循环。

## 接口与参数要点

- `compactNow(agent, signal, sourceCommandId?): Promise<CompactionResult|null>`（compaction/src/index.ts:155-159）。
- 默认：0.8/0.16/maxTokens 8192/compactionRetries 1/maxOverflowRetries 1/auto true（config.ts:91-95）；modelPolicies 按 provider+model 精确覆盖。
- 校验：retainRatio 与 retainTokens 互斥、retain<threshold、未知 key 即抛（config.ts:185-242,278-282）；手动与自动互斥靠 durable start 锁（region.ts:309-321），手动另要求无 open turn。

## 边界与坑

- 手动与进行中回合串行：runMaintenance 仅 idle 且扣住后续唤醒输入（compaction/src/index.ts:70-79）。
- 被压缩内容不删只遮蔽：shadowedRange 是表面位置 span，替换后 start 可大于 end（types.ts:107-115）。
- 失败熔断：每次尝试恰好一条 end（带 error），失败留 unmatched start 可检测（region.ts:241-252）；pressure 重试超限抛错（index.ts:325-328）；TargetPressureConfigError 每 target 只 warn 一次后继续回合（index.ts:152-159）。
- 稳定性双规则：自动 whole-surface、手动 selected-span，变化抛 SurfaceChangedError 分类 changed（region.ts:431-469）；pruner/spill 配置错误加载期 fail loud（tool-result-pruner config.ts:38-63）。

## 对 duo 的启示

- **pruner 形态**：固定 marker+code point 裁剪+「替换与影子价事件相邻 append」保证确定性重放与 O(1) 对账；duo 修剪可对照引入同构计量事件，并把 head+marker+tail≤threshold 做成加载期校验。
- **image-offload 触发**：由 provider 错误码驱动（route 上报需卸载数量）而非主动预估，决策 durable、占位符按投影统一；duo 可对照补「错误确认→永久遮蔽→重试不耗预算」链路。
- **压缩 checkpoint**：`<compacted-summary>` 标签+preamble+plugin 源标记（compactionId 关联 manual/auto），摘要请求复用路由前缀省 KV cache，summary 事件记 provider/model/usage 保证可重建——duo 压缩点拼接与 manual/auto 事件化可对照补齐可审计字段。
