# 存储配置与凭据（DSH）

> 源锚点：`ddefc45fbc7f8e46dd73185e68295696d1297887`（2026-09-21 本地核验）。M22 探测里程碑工单 20（T-24）产物，五段统一模板。接口参考见 [../模块手册.md](../模块手册.md)。

## 机制全貌

storage hub 是「命名后端注册表 + 可挂数据 form」模型：`BackendRegistry` 按名注册后端，重复名抛 `duplicate-backend`（packages/storage/storage/src/registry.ts:27）；后端可选择性携带 `kv` 等 facet（storage/src/backend.ts:19）。domain form 在其上提供「spec 即唯一事实源」的 KV 域：`defineDomain` 声明 name/version/layout/global/tables，记录 schema 用 zod、插件 Config 用 schemastery（storage-domain/src/spec.ts:5-8）。settings 是四件套：命名 namespace + schema + 组合 base + 用户 YAML 文档，三层解析（schema 默认→base→user）（settings/src/index.ts:740-753）。credentials 与 settings 刻意分离：`.credentials.yaml` 只存凭据、是严格 `CredentialRef→string` 映射，不兼作 env 层，防止非 secret 项被遮蔽（credentials-local/src/index.ts:29-34）；值不入配置文档，wire 面必须 `redactSecrets`（settings/src/index.ts:106-111）。

- 读同步内存、写单链排队：先落盘→改内存→发 `domain/changed`（storage-domain/src/domain.ts:4-8）。
- sqlite=单库文件（`PRAGMA user_version` 校验，storage-sqlite/src/schema.ts:82-85）；json=目录树（single 整单元一文档 / per-record 每记录一文档，tmp+rename 原子写，storage-json/src/atomic.ts:25-34）。

## 关键流程

① **domain**：`defineDomain` 模块加载期校验 name/表名匹配 `UNIT_NAME_RE`、version 非负整数、global schema 不得接受 null（null 是「未写入」哨兵）（spec.ts:107-147）。`open` 流程：already-open→路由 `backend-not-found`→无 kv 抛 `facet-unsupported`→后端 `version-mismatch`/`malformed-medium` 透传→zod 校验失败抛 `invalid-record`，或 `invalidRecords:'backup-and-skip'` 时 backupRecord 移档跳过；存储 global 为 null 则服务 `initial` 不落盘（index.ts:103-175）。句柄归 caller，`close()` 拒新写、排干队列再释放名字（domain.ts:236-244）。

② **settings**：`installSection`（index.ts:472-496）=注册 namespace（base=组合 entry）+setSource+onChange+watch，provider 失联回退 entry。解析链 `resolve`：`schema(mergeLayers(base, section))`，plain object 递归合并、其余整值替换（index.ts:287-295）。写路径 `update/replace/mutate` 每命名空间串行队列，revision 乐观锁抛 `SettingsConflictError`（index.ts:652-689）。live 生效：`publish` 重解析全部 namespace，invalid 段保留 last good 并 warn（index.ts:715-727）；settings-file 用 chokidar 监听文档、文本缓存做自写抑制、reload 失败 warn-keep（settings-file/src/index.ts:238-258, 305-314）。redact：按 schema 走 object/dict/array，`role('secret')` 字段摘除，sidecar `secrets[]` 记 `{path, set}` 供表单渲染只写输入框（redact.ts:50-108）。

③ **credentials**：resolve 链 env（继承环境，只读）→file（托管 yaml）→`.env`（project→user），空串视为未配置（credentials-local/src/index.ts:558-571, 617-625）。写路径：`set/unset/modifyRecord` 在独占操作链内 `withFileLock`（跨进程写锁，waitMs=30s，index.ts:112）→`reconcileFromDisk` 先合并盘上状态→注释保留级 diff→`writeFileAtomic` 0600 原子替换（index.ts:753-787）。热发布：watcher 事件重载后按 diff 逐 key 发 `credentials/reference-updated`/`credentials/record-updated`（index.ts:901-907）。

④ **workspace**：以 `defineDomain({name:'workspace', version:2, ...})` 打开（workspace/src/spec.ts:68-76）。归档=registry-global `archivedSessionIds` 追加，不动 `sessionIds` 槽位，unarchive 即摘除且不查会话存在性（index.ts:243-277）；create/delete 用 `pendingMutation` 标记先落盘的两段写 + 启动恢复（spec.ts:38-41）。

## 接口与参数要点

- `register(ns, schema, {base?, applies?='live', validate?})`；namespace 正则 `/^[a-z][a-z0-9-]*$/`（settings/src/index.ts:20）。
- `KvFacet.open(descriptor)` / `KvUnit.putRecord/deleteRecord/backupRecord?/setGlobal`（storage/src/backend.ts:42-137）。
- 介质位置：`<DSH_HOME>/settings.yaml`（settings-file/src/index.ts:57）、`<DSH_HOME>/.credentials.yaml`（credentials-local/src/index.ts:61），目录 0700、文件 0600。
- `archiveSession/unarchiveSession(sessionId)`（workspace/src/index.ts:243/266）。

## 边界与坑

- 重复后端名/重复 namespace/重复 open 同名域均 fail-loud（registry.ts:27、settings index.ts:426、domain index.ts:104-106）。
- 介质版本不符：sqlite `user_version`、json 单元戳、credentials `version: 1` 布局全拒（schema.ts:82、format.ts:66-69、credentials-local/index.ts:215）。
- 凭据空串值=未配置且拒绝存储「空值」条目（credentials-local/index.ts:282, 643）。
- 只读源遮蔽写拒绝：env 层存在时 set/unset 抛「shadowed」错误（index.ts:794-801）。
- 凭据文件 mode 含 0o077 位直接拒启，提示 chmod 600（index.ts:127-146）；YAML 解析错误只报 code+行列、不引用含密源行（index.ts:159-164）。
- reload 一律 warn-keep 不下线，写入路径 fail-loud 防覆盖手编文档（settings-file/index.ts:216-231）。

## 对 duo 的启示

- **配置热更新形态**：duo `Boot.from(yml)` 一次性加载（热重载遗留限制不可用）。DSH 的 provider/namespace 模型证明可行路径：文档 watcher + 文本缓存自写抑制 + publish 重解析、invalid 段保 last good——duo 可按 namespace 粒度先做只读热发布，无需一次到位。
- **credentials 独立层最小形态**：duo 现仅有 `.env` 密钥不入库红线。DSH 最小集=独立 `<home>/.credentials.yaml`（0600）+ env→file→.env 三层 resolve + 跨进程写锁 + tmp+rename 原子写；「env 层遮蔽时拒写」与「空值即未配置」是防幽灵故障的关键两条。
- **redact 侧车**：duo 日志/诊断面可借鉴 schema 声明 secret 位置 + `{path,set}` sidecar 的结构化脱敏（而非字符串黑名单），跨 wire 面强制执行。
