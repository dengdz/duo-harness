# 会话检索与导出（DSH）

> 源锚点：`ddefc45fbc7f8e46dd73185e68295696d1297887`（2026-09-21 本地核验）。M22 探测里程碑工单 21（T-25）产物，五段统一模板。接口参考见 [../模块手册.md](../模块手册.md)；跨会话引用机制见 [../LLM与上下文/系统提示与上下文工程.md](../LLM与上下文/系统提示与上下文工程.md)。

## 机制全貌

session-query 让模型用**结构化参数 + 字面全文查询**检索历史会话，不暴露裸 SQL：SQL/FTS5 是 sqlite 后端内部实现，模型查询被引号包裹为惰性短语（`packages/session-query/session-query-sqlite/src/query.ts:223`）。五个工具注册于 `packages/session-query/tool-session-query/src/index.ts:65-121`：`session_search`（跨会话，每会话返回最强命中）、`session_event_search`（单会话内检索）、`session_trace`（血缘）、`session_event_trace`（事件替换/引用关系）、`session_event_read`（全量事件+邻窗）。检索目标是「live-preferred 逻辑会话语料」（`session-query/src/types.ts:27-34`，live 内存+persisted 落盘双可用性）。安全边界：cwd 工作区隔离授权（`tool-session-query/src/workspace-access.ts:96-99`）、30s 合作式超时、100 条上限（index.ts:22-25）。deliverables 侧 `present` 工具声明文件级交付（写入 `deliverables/presented` 会话事件，`packages/deliverables/tool-present/src/index.ts:104`），`workspace-changes` 按 turn 用 git 快照自动记录改动（`packages/deliverables/workspace-changes/src/index.ts:143-151`）。

## 关键流程

① **session_search/event_search**：入参为 query + 过滤器（session_ids/时间区间/parent/availability/seq/types/surfaces，`tool-session-query/src/input.ts:45-86`）。执行链：normalizeQuery（空白归一、拒 NUL）→ 构建 filter → `collectPages` 翻页聚合并去重 cursor（`operations.ts:244-277`，超 maxResults 置 capped）。当前会话检索用 turnBoundary 截断至本 step 之前，避免自命中（`operations.ts:128-139`）。sqlite 后端对**派生只读索引**建表：`persisted_sessions`（STRICT 元数据表）+ `persisted_docs` FTS5 虚表（unicode61 分词，session_id/seq/type/time/surface UNINDEXED）（`session-query-sqlite/src/schema.ts:103-139`），live 会话进 TEMP 表（schema.ts:141-169），schema v8 不符即就地重建（schema.ts:66）。查询为参数化 CTE：`MATCH ?` + 过滤 → ROW_NUMBER 按会话分区取最强事件 → LIMIT/OFFSET（`session-query-sqlite/src/index.ts:665-681`）。

② **present**：要求 open turn、文件已存在且为普通文件（fs.stat 校验），单次 1-8 个文件，成功后在 `tools/result` 钩子追加 `deliverables/presented` 事件（tool-present/index.ts:75-107）。**workspace-changes**：turn/start 与 turn/end 各取 git tree 快照，按文件出 numstat 摘要，`workspace/changes` 事件只带 turn 号，摘要与按需 diff 由 `workspaceChanges` 服务在 Session 存续期内供给（workspace-changes/index.ts:94-165）；git 覆盖不到的路径靠文件工具编辑前后的 SHA-1 内容寻址捕获（`capture.ts:38-70`）。

③ **导出**：Host 面 `GET /api/session.export?sessionId=&includeDescendants=`（`packages/session-query/session-log-export/src/index.ts:43`）+ Web `/export` 命令（index.ts:79-86）；流式 ZIP，含根日志 JSONL（`archive.ts:110-136`）、可选子代理 `subagents/<id>/session[.vN].jsonl`、`media/`、`files/` 附件（archive.ts:330-387），fflate 增量压缩、64KiB 高水位背压（archive.ts:396）。

## 接口与参数要点

- 工具入参：query 必填字面文本；过滤器均为枚举化结构（`input.ts:45-86`）。
- 限额：搜索结果默认 100（index.ts:22）；超时默认 30s（index.ts:25）；sqlite 页默认 20/最大 100（session-query-sqlite/src/index.ts:79-81）；摘要 240 码点（index.ts:83）；`session_event_read` 邻窗 before/after ≤50（`session-query/src/config.ts:6`）；绑定变量上限 32766、FTS5 外层谓词预算 14（query.ts:27-30）。
- 表结构：`persisted_sessions(id,version,created_at,cwd,parent_session,seed_length,delegation_depth,agent_preset,revision,generation)`；FTS5 列 text 可查，其余 UNINDEXED（schema.ts:112-137）。

## 边界与坑

- **只读保障**：模型 query 走 `quoteFtsData` 成单短语，FTS 语法永不执行（query.ts:223-225）；SQL 全参数化绑定；库文件以 application_id+白名单表校验拒绝外部库。
- **授权双重检查**：搜索结果逐条 `recordAuthorized`（cwd 相等才收，operations.ts:101），标题读取后再 `assertObservedTargetAuthorized` 防观测期换库（workspace-access.ts:101-109）；无 cwd 的调用方直接拒绝跨会话检索。
- **大结果控制**：collectPages 硬上限 + capped 提示（presentation.ts:75-77）；snippet 以码点截断；翻页 cursor 重复即报错防死循环（operations.ts:268-273）。
- `deliverables/presented`、`workspace/changes` 等扩展事件无语义文本，**不入检索索引**（`session-query/src/extraction.ts:41-43`）——交付声明存在但搜不到；索引与 live 会话一致性靠 generation fingerprint，跨库 FOREIGN 库整体拒绝。

## 对 duo 的启示

1. **SQL/FTS5 查询面 vs duo 内存倒排**：DSH 证明「模型面用结构化参数+字面查询、FTS5 只作内部实现」可同时拿到注入安全与相关性排序。duo 计划转 FTS5 方向正确，但可借鉴 DSH 的 **live+persisted 双表 UNION**（`session-query-sqlite/src/index.ts:797-850`）解决「当前会话未落盘搜不到」的问题，以及 workspace cwd 强制过滤作安全边界。
2. **交付声明增强导出**：duo /export 目前是 markdown/json 转录；DSH 的 `deliverables/presented` 事件把「哪些文件是用户要的最终产出」结构化入会话流，配合 workspace/changes 的 git before/after tree id，导出时可附「交付清单+变更摘要」章节，比纯转录更有价值。
3. **导出工程**：DSH 流式 ZIP（背压、fail-loud 截断保护）适合 duo 在大会话导出时复用；但注意 DSH 检索索引不含交付/变更事件，duo 做 FTS5 时应把交付声明纳入索引以补此缺口。
