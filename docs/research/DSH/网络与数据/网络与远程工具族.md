# 网络与远程工具族（DSH）

> 源锚点：`ddefc45fbc7f8e46dd73185e68295696d1297887`（2026-09-21 本地核验）。M22 探测里程碑工单 19（T-23）产物，五段统一模板。接口参考见 [../模块手册.md](../模块手册.md)；web 域已有专册（duo 仓库 `docs/research/DSH/web工具族/`），本篇不展开。

## 机制全貌

web 域已另册。其余五域在工具目录中的形态：LSP 是唯一「只读精确导航」工具（单工具四操作）；SSH/E2B **不是模型可见工具**，而是 fs/subprocess/sandbox 三条 capability seam 的远程 provider 替身；browser-use/computer-use 是「能力占位」，真正工具由 experimental provider 注入。远程执行三条路同 seam 互换：本地 local provider、SSH helper（packages/ssh/*）、E2B 云沙箱（packages/e2b/*）都实现同一 FileSystem/SubprocessRuntime/SandboxProvider 接口，宿主无感切换。独占 provider 槽的意义：browser/computer 是共享物理资源，全进程只允许一个 provider 占坑，二次注册即抛错，杜绝两套浏览器工具并存。

- LSP seam 封闭四操作，无协议逃生口：lsp/lsp/src/types.ts:17,113
- 独占槽：browser-use/browser-use/src/index.ts:35-45；computer-use/computer-use/src/index.ts:35-45

## 关键流程

① **LSP**：lsp-stdio 插件按 `servers` 表逐项配置命令并注册独立 provider（lsp/lsp-stdio/src/index.ts:56-107,126-186），可执行文件在加载期解析；每 provider 按「规范工作区 targetKey」池化一个 server 进程（index.ts:274,332-339）。initialize 握手：`processId:null`（防跨机误监控）+rootUri+utf-16 协商（instance.ts:110-125,340-350）。四操作统一 transient 生命周期 didOpen→request→didClose（instance.ts:159-177）；findReferences 硬编 `includeDeclaration:true`（instance.ts:198）；abort 发 `$/cancelRequest`，宽限期内未结算即销实例（instance.ts:211-236）。多 server 路由按扩展名选 provider（types.ts:121-129），无匹配抛 LSP_UNAVAILABLE。工具层把 1 基 UTF-16 光标转 0 基，要求会话 workspace cwd（tool-lsp/src/index.ts:183-194）。

② **SSH**：SshConnection 用 OpenSSH 别名 + `ssh -T -M` ControlMaster 连远端（ssh/src/index.ts:258-267），经 stdin/stdout 与私有 Node helper 跑 JSON-RPC；hello 返回 helper 与 PTC bootstrap 的 sha256，与配置不符拒连（index.ts:280-281）。三条路透传本地语义：fs-ssh 全量实现 FileSystem 并把远端错误码映射回 FsError（ssh/fs-ssh/src/index.ts:13-17,97-104）；subprocess-ssh 走 prepare→独立转发流→start 三段（ssh/subprocess-ssh/src/index.ts:114-141），PTY 终端走 control 流+resize/write/signal（index.ts:283-320）；sandbox-ssh 在远端 confine argv（ssh/sandbox-ssh/src/index.ts:13-30）。grants 授权面=helper 暴露的白名单 RPC（fs.*、process.*、terminal.*、executable、sandbox，ssh/src/helper.ts:111-239），流通道按每流 256-bit PSK capability 鉴权（TLS-PSK-AES256-GCM，ssh/src/stream-security.ts:6-25）。

③ **E2B**：仅编译产物。E2BRuntime 构造即建沙箱，超时/析构必删（e2b/lib/types/index.d.ts）；apiKey 缺省读 `E2B_API_KEY` 且不注入沙箱；fs/subprocess 为共享 SDK 句柄上的适配器，参数经 `quoteE2BShellArg` 抗 `/bin/bash -l -c` 注入。

④ **browser/computer-use**：stagehand-native 占槽后注册 stagehand_navigate/tabs/screenshot/act/observe/extract 六工具（experimental/browser-use-stagehand-native/src/index.ts:168-190）；MCP 变体经 per-session MCP server 挂载，浏览器忙时对后到 Agent 用 mask deny 屏蔽工具（experimental/browser-use-runtime/src/mcp.ts:114-118）。computer-use 侧 cua-driver-native 从驱动 `listToolsJson` 目录动态注册 `cua_driver_native__*`（experimental/computer-use-cua-driver-native/src/index.ts:60,92-113）。

## 接口与参数要点

- LSP 工具：operation/file_path/line/character（1 基），maxLocations=100、maxResultChars=16000、timeoutMs=60000（tool-lsp/src/index.ts:50-70）；stdio server 默认 maxMessageBytes=16MB、shutdown=5s、killGrace=2s（lsp-stdio/src/index.ts:49-53）。
- SSH：requestTimeoutMs=30s、maxFrameBytes=64MB、maxPending=128、leaseMs=30s（3s-600s）（ssh/src/index.ts:48-54）；进程/流各限 128（protocol.ts:13-15）。
- E2B：timeoutMs 到期即删沙箱；subprocess-e2b 有 pollMs 轮询。

## 边界与坑

- 光标不在符号上返回空结果，系统提示明示（tool-lsp/src/index.ts:53-54）；无 workspace cwd 抛 LSP_WORKSPACE_REQUIRED。
- SSH helper hash/bootstrapHash 不符即拒连（index.ts:280-281）；**连接不重连**，断开作废全部在途操作（index.ts:46）。
- LSP 传输失败仅静默重试一次（lsp-stdio/src/index.ts:305-312）；helper 拒 danger-full-access 的 sandbox 包装（helper.ts:145）。
- 独占槽同名字重复注册也抛错（browser-use/src/index.ts:36-38）；E2B 仅 lib 产物，源码不可读，维护靠类型。

## 对 duo 的启示

duo 现状：web 工具族（M20）已对齐；无 LSP/远程执行/浏览器操作（backlog 已列 LSP、PTY、跨 harness 委派）。对照三条：

1. **LSP 最小价值=「seam+单工具四操作」**：DSH 把价值收在封闭四操作与 1 基光标/空结果提示，server 管理全在 provider 侧。duo 若做，先落 types seam+tool 层，stdio provider 可后补，成本低收益高（补齐「精确导航」盲区）。
2. **SSH 远程 provider 的 seam 形态值得照抄**：三 provider 是同一 seam 的透传替身，授权收在私有 helper 白名单 RPC+每流 PSK key+hash 校验。duo 的跨 harness 委派后端可复用「连接拥有者+版本化私有协议+远端清理确定性」这套骨架，而非裸 ssh。
3. **browser-use 优先级低**：其核心是独占槽+会话级资源隔离，依赖 Stagehand/CUA 外部驱动，属 experimental；duo 当前无浏览器场景，建议仅登记模式（独占注册槽）不落地实现。
