## 边界条件

- **exact-at-cap 不算截断**：流式读只计被丢弃字节（与 web_fetch 同语义）。
- **恰好填满不算 truncated**；16-bit PNG 转换失败单独报错（read-image.ts:299-304）。
- **目录 symlink 不跟随**（逐段 lstat）；`..` 越界目录查询返空；子树 readdir 失败贡献 0 候选，根不可读整个索引不发。
- **变体缓存并发**：同 variantId 并发共享一次变换（单飞）。
- **Files 失效重传仅一次**；过期刷新裕量 1 小时、Files 解析超时 60s、默认过期 7 天。
- **搜索前 reconcile**：live+持久 fingerprint/revision 差异比对，BEGIN IMMEDIATE 事务写增量；语料换代游标作废（`SESSION_QUERY_STALE_CURSOR`）。
- **@file 索引失效**：任意 tool/result 事件即使索引陈旧（后台重建，不阻塞补全）。
- **导出读前 flush 屏障**；中途失败弄断下载（不给截断包）；错误不回显宿主绝对路径。

## 异常处理

| 场景 | 错误码/表现 | 备注 |
|---|---|---|
| 非视觉模型收图（Host） | `MODEL_DOES_NOT_SUPPORT_IMAGES` | 收 prompt 即拒 |
| 非视觉模型调 read_image | 执行前抛（零 I/O） | `assertImageCapableRoute` |
| 历史有图但路由无视觉 | 投影占位文本（含 sha256）/ Messages 硬报错 | 两适配器口径不同 |
| 图超大小/像素/边长 | `IMAGE_TOO_LARGE` / `IMAGE_TOO_MANY_PIXELS` / `IMAGE_DIMENSION_TOO_LARGE` | 可恢复工具错误 |
| 扩展名与解码不符 | `IMAGE_TYPE_MISMATCH` | 三重验证 |
| 检索未启用 | `SESSION_QUERY_SEARCH_DISABLED` | never 时驱动都不加载 |
| 检索游标过期 | `SESSION_QUERY_STALE_CURSOR` | 语料换代 |
| 超引用预算 | `SESSION_REFERENCE_BUDGET_EXCEEDED` | @session |
| 导出会话不存在 / 服务缺失 | 404 / 500（不回显宿主路径） | |

## 已知坑

1. **附件"永不删除"是无 GC 代码的物理事实**——unreachable 对象持续累积，未来 retention policy 才收（attachment/src/index.ts:73-75）。
2. **read_image 每次成功读都独立计费**——同文件重复读存储去重但不省请求 token。
3. **deepseek available() 恒真式的不对称**在这里不存在，但 **Files API 是 DeepSeek 特有**——通用 OpenAI 兼容端点无此 API，投递方式必须按端点能力配置。
4. **available()/能力检查语义不对称**：deepseek provider 缺 key 推迟到执行期 vs exa 选路期——附件域的对应物是 `inputModalities` 能力闸门（执行前拒）与 Host 收图即拒（两层时机不同）。
5. **exa 无 highlight 丢条目**式的 provider 数据质量问题在 Tavily 搜索侧同样存在（无 highlight 的结果整条丢弃是 DSH 行为）。
6. **邮件地址不触发 @**：grammar 要求 @ 前是行首/空白——自写解析时易漏。
7. **`text()` 的 preserveWhitespace 只看一级父**：`<pre><span><code>` 深嵌套会折叠换行，需 wholeText。
8. **导出无 manifest**：ZIP 内文件布局即约定（media/、files/、subagents/），无索引清单文件。
9. **模型工具检索带 cwd 授权**（跨会话须同 cwd）+ 错误消息 sanitize 防泄漏宿主路径——个人单用户场景可简化，多目录部署不可省。
