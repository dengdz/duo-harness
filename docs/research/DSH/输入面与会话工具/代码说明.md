# DSH 输入面与会话工具代码说明

> 源锚点：`ddefc45fbc7f8e46dd73185e68295696d1297887`（2026-09-20 pull，release 0.1.6-alpha.2）。路径前缀 `packages/` 省略时指该目录下。配套：[架构设计.md](架构设计.md)、[细节备忘.md](细节备忘.md)。

## 关键实现逻辑

### 一、附件库（attachment-local）

1. **准入（admission.ts:49-74）**：`admitEncodedImages`/`admitEncodedFile` 先做规范 base64 校验（防 data URI 杂质），批量过 `maxImagesPerMessage`/`maxMessageImageBytes`/mediaTypes 白名单，再逐个委托 store。
2. **规范化（store.ts:99-124 `prepareImageFile`）**：图片解码 → 长边/像素受限缩放（`normalizedImageMaxPixels` 2048²、`normalizedImageMaxDimension` 8192、`normalizedImageMaxBytes` 4MiB）→ 8-bit sRGB 重编码 → **以规范化字节的 SHA-256 为 attachmentId**（`sha256:<64hex>`）。
3. **发布协议（store.ts:309-388）**：暂存写 `tmp/` → fsync → `link()` 硬链接到 `objects/<2位>/<sha256>` → EEXIST 时重算目标 digest 比对确认同一对象（去重）→ chmod 0400 → 逐级目录 fsync 到 root。文件库另以硬链接做别名 `files/<2位>/<sha256>/<净化文件名>`（file-store.ts:75-83），让模型看到真实文件名结尾。
4. **持久性**：全包无 prune/GC/retention 代码；唯一删除逻辑是清理本次写入自己的 tmp 文件（store.ts:396-404）。注释明示 unreachable 对象留待未来 retention policy（attachment/src/index.ts:73-75）。

### 二、read_image（tool-fs/src/read-image.ts）

1. **注册门**：`inject(['attachments'])`——附件服务缺席则工具不存在（index.ts:70-71）。
2. **闸门**：执行前 `assertImageCapableRoute` 经 `llm.resolveModelInfo` 查 `inputModalities` 不含 `image` 即抛错，不做任何 I/O（119-131）。
3. **读流程（243-275）**：前置参数/大小闸门 → `fs.resolve` + stat（要求常规文件）→ `readBytes(byteCap=min(maxImageBytes, maxMessageImageBytes))` → 无扩展名按魔数嗅探（PNG/JPEG/GIF87a/89a/RIFF+WEBP）→ `attachments.saveImage` **先持久化再返回**。
4. **返回**：文本信封（path/type/content + 降采样建议）+ `image` 块（持久引用）；`isConcurrencySafe: true`（内容寻址写幂等，238-240）。同一文件重复读存储层去重，但每次读都独立进历史、逐请求计费。

### 三、请求变体与投递（llm-deepseek）

1. **变体（attachment-local/src/request-image.ts:26-122）**：variantId = sha256(attachmentId + 目标宽高/字节预算 + 编码参数 + `REQUEST_IMAGE_TRANSFORM_VERSION='request-image-v6'`)；sharp 长边 resize + WebP/JPEG 质量阶梯压到字节目标；缓存 `cache/attachments/request-images/`；同变体并发共享一次变换。目标尺寸由模型目录决定（request-pricing.ts:53-68）。
2. **Files API（common/files-api.ts）**：`POST /files` multipart（purpose=user_data、expires_after）；上传上限 128 MiB、有效期 3600–2,592,000s、配额 10,000 文件/25GiB。`DeepSeekFileStore.ensureUploaded` 以 `scope(baseURL+apiKey)\0variantId` 为键查本地索引 `$DSH_HOME/llm-deepseek/files-v3.json` 命中即不重传；配额满删最旧自有文件重试；file_id 失效仅允许一次失效-重传（request-files.ts:135-141）。
3. **双协议序列化**：Messages = handle 文本 + `{type:image, source:base64|file_id}`（messages/serialize.ts:61-70）；Chat-Completions = 默认 Files、`FileResolutionFailure` 整体回退 base64 data URI（chat-completions/serialize.ts:146-153、adapter.ts:281-318）。
4. **非视觉模型三层降级**：Host 收图即拒（`MODEL_DOES_NOT_SUPPORT_IMAGES`）→ read_image 执行前拒 → 历史已有图时投影确定性占位文本 `[image omitted …; attachment sha256:…]`（llm/src/content.ts:71-77）或 Messages 硬报错。视觉但超请求预算 → 最旧优先持久降级占位（content.ts:226-295）。

### 四、@file 路径提及（file-reference 系）

1. **grammar（file-reference/src/grammar.ts）**：`activeAtToken`——@ 前须行首/空白（邮箱不触发）；引号形式 `@"..."`（可含空格、未闭合也算活跃）+ 裸形式；`formatFileMention`——目录补尾 `/`、含空格才加引号、控制字符路径拒绝生成。
2. **索引（file-reference-local/src/search.ts）**：**路径 only 不读内容**（包头注释）；`maxEntries` 50000 截断遍历；排除目录清单（.git/node_modules/dist/target 等，lib 刻意排除有注释）；目录 symlink 不跟随（逐段 lstat）；越界目录查询返空；子树不可读贡献 0 候选、根不可读整个索引不发；任意 `tool/result` 事件使索引变陈旧后台重建。
3. **指南注入（file-reference-local/src/index.ts:66-78）**：systemPrompt section `context:file-reference`，仅当 agent 有 `read` 工具时才有内容；内容 = "@ 是相对 workspace 的路径；尾 `/` 是目录；要内容调 read；未 read 不得声称已看过"。
4. **装配**：仅 web-app bundle（cordis.patch.yml:78-79）；CLI/TUI 未挂载。

### 五、会话检索（session-query-sqlite）

1. **熄火语义（index.ts:333-344）**：`openAt:'never'` 时 exact reads/标题/lineage 全可用，仅 `searchSessions/searchEvents` 入口即抛 `SESSION_QUERY_SEARCH_DISABLED`，且 **node:sqlite 永不 import**。
2. **schema（schema.ts）**：版本 8 + application_id `0x44534851`，不匹配原地重建；FTS5 `unicode61`；`persisted_docs`（持久）+ `temp.live_docs`（连接级，live 优先遮蔽持久行）。
3. **抽取（session-query/src/extraction.ts:15-85）**：user/assistant 文本、tool/call 名+参数、tool/result 内容+错误码、todo/write、turn 错误；**reasoning 块与未知事件不入索引**。
4. **查询（query.ts）**：整串短语（`quoteFtsData` 包双引号转义内部 `""`）；`highlight()` 标记后裁 snippet（默认 240 code points）；搜索前 reconcile（BEGIN IMMEDIATE 写增量）；游标 = base64url JSON，语料换代抛 `SESSION_QUERY_STALE_CURSOR`。
5. **工具（tool-session-query）**：5 个模型工具（session_search/session_event_search/session_trace/session_event_trace/session_event_read），timeout 30s、maxSearchResults 100；cwd 授权过滤（跨会话须同 cwd）；本会话检索排除当前 step。
6. **导出（session-log-export）**：`/export` 无参数命令 → flush 屏障 → 规范 JSONL（+subagents 后代）+ 引用附件字节 → fflate DEFLATE 流式 ZIP → `GET /api/session.export` 下载（`dsh-session-<id>.zip`）；404/500 错误不回显宿主路径；中途失败弄断下载。

## 依赖关系

- `tool-fs` 的 read-image 依赖 `attachments` 服务（注入式可选存在性）；`tool-session-query` 依赖 `sessionQuery` 服务；`file-reference-local` 不依赖任何 harness 服务（纯 fs + 指南注入）。
- 外部库：sharp（图像）、fflate（ZIP）、node:sqlite（FTS5）——Java 侧对应物见 ADR-0022 依赖决策。
- 测试：fetch-http/tool-web 同款 spec 形态；tool-session-query 有独立 spec（cwd 授权/游标换代）。
