# 本机执行工具族（ZCode）

> 源锚点：`872ad960de7ec172591f7e1952f7849229f94521`（2026-09-21 本地核验）。M22 探测里程碑工单 03（T-07）产物，五段统一模板。接口参考见 [../模块手册.md](../模块手册.md)；管线语义见 [工具注册与执行管线.md](工具注册与执行管线.md)。

## 机制全貌

文件工具族（read/write/edit/glob/grep）与 bash 均为 core 的薄 handler，真实能力在 Port 适配层：FileSystemPort→NodeFileSystemAdapter（ad/fs/index.ts:115，含 WASM ripgrep Worker），ExecutionPort→NodeExecutionAdapter（ad/exec/node-execution-adapter.ts，按 base/run/process/results/lifecycle 分层继承）。handler 只做 schema 解析、路径策略（resolveWorkspacePath）、readFileState 记账与 resultBudget。终端面独立于工具族：packages/services/src/terminal/terminalService.ts 惰性 import node-pty（terminalService.ts:31），属 remote server 服务而非 CLI 工具。

## 关键流程

① **read**：read.ts 按扩展名分发 image/video/pdf，文本走 read-text.ts:31 readTextFileRange；无 limit 时 maxBytes=256KB（ct/tools/read.ts:15），默认 2000 行；token 预算 25k，超限二分找最大前缀（85% 预算，read-text.ts:18,210）给 partialViewNotice 续读提示，带 limit 时直接报错；重复读未变文件返回「Wasted call」stub（read.ts:51）。图片：输入≤20MB、base64≤5MB、边≤2000；PDF：native≤20MB/10 页、pages≤20/请求、extract≤100MB（ct/tools/read-pdf.ts:5-8）。

② **write/edit**：读前写闸门=readFileState（write.ts:278、edit.ts:421），partialView 视为未读；stale 判定用规范化 mtime+size，严格全读再比内容（edit.ts:444）。edit 的 old_string 精确匹配（edit-matchers 有容错策略），多处匹配报 AMBIGUOUS_REPLACE 而非替换第一处（edit.ts:224-230）；空 old_string=新建文件，文件已存在且非空则失败；replacement 用函数替换器规避 `$$/$&`（edit.ts:631）。写经 atomicWrite：临时文件+rename+保留原权限+O_NOFOLLOW（ad/fs/index.ts:700），expectedRevision 不符报 stale_write（index.ts:473）。

③ **bash**：bash.ts:388 组装 request：inline/缓冲 30k（bash.ts:70）、持久化 5GB、后台 persistOutput="always"；timeout 默认 120s/max 600s 可覆盖，cleanupGraceMs=6s（bash-timeout-policy.ts:6）。spawn 前 prepareChildSpawn+shell init snapshot（快照 10s 超时、缓存 30 天，ad/exec/shell-init-snapshot.ts:13）。run_in_background→runBashWithBackgroundLifecycle（ad/exec/node-execution-adapter-lifecycle.ts:102）：explicit 在 started 事件即 commitBackground；**auto_on_timeout 挂前台 deadline=timeout 到点自动转后台**；转后台后 timeoutMs=0 不再杀进程。任务登记在 backgroundTasks（通用 start() lifecycle.ts:23，taskId=exec_uuid）。TaskOutput 轮询 registry 100ms、支持 block/timeout，输出默认保留尾部 32k 字符（env TASK_MAX_OUTPUT_LENGTH，上限 160k，hd/task-output.ts:199）；TaskStop 经 backgroundTaskControlPort.stopBackgroundTask（initiator:"model"，task-stop.ts:47）。杀树：通用 SIGTERM→750ms 升级 SIGKILL（ad/exec/process-tree.ts:3），bash 路径 1500ms（process-tree.ts:5，node-execution-adapter-process.ts:193）。

④ **glob/grep**：glob 为纯 JS 递归 walk（ad/fs/index.ts:393,1708），排除 VCS 目录（.git/.svn/.hg/.bzr/.jj/.sl，index.ts:54），mtime 降序，max 100 条+truncated。grep 默认走 WASM ripgrep 且在 Worker 中执行（index.ts:79,1056，防主 event loop 被占），30s 超时 terminate（index.ts:1037）；Worker 失败→RipgrepRuntimeFailure→JS 纯遍历兜底（index.ts:459）。rg 参数：--no-config --hidden --no-heading --max-columns 500 + VCS glob 排除 + `-U --multiline-dotall`/`-i`/`--json`/`-c`（createRipgrepSearchPlan index.ts:924）。

## 接口与参数要点

- Read(file_path/offset/limit)；Edit(file_path/old_string/new_string/replace_all)；Write(file_path/content)；Glob(pattern/path)；Grep(pattern/path/glob/type/-A/-B/-C/-i/-n/-o/output_mode/head_limit/offset/multiline，handler 超时 30s、maxModelBytes=20k，hd/grep.ts:23,170)；Bash(command/timeout/run_in_background/dangerouslyDisableSandbox)；TaskOutput(task_id/block/timeout)；TaskStop(task_id|shell_id)。
- 限额：grep head_limit 默认 250；glob maxResults=100；edit/write maxModelBytes=100k 策略 truncate；bash inline 30k 取尾、超限落 artifact（session 级）。

## 边界与坑

- Windows 侧按 PATHEXT（.COM/.EXE/.BAT/.CMD）在 PATH 展开 .cmd 候选（ad/exec/windows-executable.ts:3,14）。
- rg 退出码 2 映射为结构化错误：regex 解析错→invalid_pattern、"permission denied"/os error 13→permission_denied（index.ts:1345）；EACCES 会明确上抛而非静默吞掉。
- readTextFile 超 maxBytes 只读前缀并标 truncated（index.ts:176）；mtime 亚毫秒规范化防误判 stale（edit.ts:449）。
- 闲时 turn（offPeakTurn）显式禁止 run_in_background（bash.ts:139）；后台完成后 Bash 会保留项目内 cwd，越界则 reset 并写 stderr 提示（bash.ts:213）。

## 对 duo 的启示

duo 现状=fs 工具族+bash 120s 杀树。对照三点：

1. **run_in_background 全链**——ZCode 超时前先「自动转后台」（120s 前台 deadline→落盘输出+registry+TaskOutput/TaskStop 查询停止面），duo 可把 120s 杀树改为先转后台 job。
2. **搜索引擎**——ZCode 用内嵌 WASM rg 跑 Worker+30s 超时+JS 回退+VCS 排除+mtime 排序，duo 纯 Java 遍历可借鉴 Worker 化+超时终止（+可选打包 rg 二进制）。
3. **输出预算分层**——inline 30k / model 20-100k / 持久化 5GB / task-output 尾窗 32k，duo 单层截断可拆为 inline 预算+落盘 artifact+尾部保留。另：读前写闸门+expectedRevision 乐观锁+原子写（保留权限位）是 write/edit 可直接移植的安全三件套。
