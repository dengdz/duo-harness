## 边界与坑

- rewind/checkpoint 与 activeSessionMessages 的参数顺序敏感（无 branchCut 走 legacy compact-first 语义，hydrator:211-238）。
- row.removed 裁掉整支会使 firstRowId=null（apply.ts:106），分页判顶随之封顶；loadOlder 在途遇截断必须作废防复活已删行（store:981）。
- proxy handoff 不可 forceSnapshot，否则用户已加载 older rows 被替换回尾窗（store:944-948）；ACK(snapshot) 不构成 applied base，防旧 epoch delta 拼接（:630-634）。
- transport 层 desktop/web 零感知（transport.ts:2）；重连自愈是有界退避、耗尽即 status=error 等用户手动 retry（store:46），web 无无限自动重连。

## 对 duo 的启示

duo 现状=M13 尾窗 50 条+向上分页、M10 SSE 游标、M19 压缩点投影。对照三条：

1. duo 尾窗+向上分页可对照 ZCode 游标方案补两道防护：**logEpoch 代际戳**（跨重启丢弃陈旧页）与**在途游标失效检测**（防复活已裁剪行）。
2. 「snapshot 整体替换 / delta 仅衔接 / 断档携水位重订阅由服务端裁决」三规则可直接转译进 duo M10 SSE+M19 压缩点投影：断档不猜、不缓存补偿。
3. 模型恢复「保存意图 vs 执行绑定」分离（create-app.ts:467-473）：duo 恢复会话时应返回原模型意图供 UI 补选，而非静默回落默认模型。
