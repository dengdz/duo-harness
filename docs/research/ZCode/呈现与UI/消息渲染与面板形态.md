## 块五 · 正文文字渲染（markdown 栈）

**渲染栈**【实读】：Streamdown 是 **Vercel 开源库**（`package.json:75` streamdown ^2.5.0），非自研——流式期块级拆分 + remark/unified 管线渲染（marked 仅用于块拆分，remark 系为主，`rehype-sanitize`+`rehype-harden` 在库内做 XSS 首道防线）；四个官方插件 cjk/code/math/mermaid。项目自定义 rehype 插件排在 harden 前把 `file://`/裸文件名规整为本地路径（防误杀，`message.tsx:801-823`），其余协议在渲染层退化为不可点击 span（:1492-1499）。

**React #185 两条设计决策**【实读，注释原文在 `message.tsx:700-706`】：
1. 「只有真实流式输出进入 streaming，历史/完成态内容固定走 static」——生产事故后收敛，完成态长消息复用 streaming 分块缓存会在重挂载时反复同步状态触发 #185；
2. 「渲染 key 不含 mode」（:857-883）——否则流式状态抖动会卸载整棵 markdown 子树，已显示正文重新触发淡入；且正文 `animated={false}` 关流式淡入（重渲染时历史文本整段闪烁）。

**流式容错**：`remend`（独立 npm 包）经 `parseIncompleteMarkdown={streaming}` 仅流式期补全未闭合标记——已知误伤：`./src/**/*` 被当未闭合粗体补出 `**`（:1628-1630 注释）。

**性能手段**【实读】：memo + 逐 prop 比较；预处理链全 useMemo；错误边界降级纯文本 + warn；代码块高亮与 mermaid **延迟到完成态**（流式期 lang 强制 "text" 等宽纯文本，防 async highlighter 与流式更新叠加）；`CodeBlockContainer` 用 `contentVisibility: auto`；无虚拟化（上层懒渲染频繁重挂载正是 #185 诱因）。

**排版细节**【实读，className 锚点】：正文 14px / `leading-[1.75]` / `tracking-wide`，首尾元素去外边距；标题跟随 UI 字号 token（h1 xl / h2 lg / h3+ base，全 semibold）；strong 降一级用 `font-medium`；行内 code = tag 底色圆角 mono；ul 外标记 `marker:text-foreground-subtlest`、ol 内标记防两位编号被气泡截断；表格 `border-separate` + th 常态 subtle 色 + 行 hover、带复制 CSV/下载工具栏（CSV 防公式注入）；引用 = 左 2px 边线 + subtle 色；链接 `text-icon-blue no-underline` 悬停 dotted 下划线，外链实为 button + 右键菜单；图片 ≥2 张连续归并画廊 + 加载 shimmer。

**代码块**【实读】：自研 CodeBlock（derived from vercel/ai-elements）防 #185——「Streamdown 内置 renderer 会在高亮结果与 raw fallback 间反复 setState，保留解析但代码块改走自家稳定渲染器」（:1636-1638）；高亮引擎 `@pierre/diffs` + shiki-wasm（oniguruma 避免巨型 RegExp 占满 V8 code range OOM）；header = 文件图标 + 语言名 + 复制（2s 打勾）+ 换行 toggle；行号默认关。

**CJK 专项**【实读】：`singleTilde` 必须在 remark-gfm 与 cjk 删除线扩展**两处同时关**（后者覆盖前者解析结果，`~text~` 才按 GFM 保留原文，:836-839 注释）；cjk-friendly 修 CJK 与 `**`/`~~` 邻接的强调/删除线失效；`$5-$10`/`$HOME` 预处理防误判 LaTeX；代码块字体显式透传 mono 防 Windows 中文落宋体。

## 块七 · 用户消息

【实读】**不渲染 markdown**——只切 mention chip（file/skill/session/plugin/command），其余文本原样输出（`**` `#` 按字面显示）；右对齐气泡 `rounded-xl rounded-tr-xs border bg-surface px-4 py-3`（小右肩是造型特征），窄容器 max-w-xl；助手行无气泡无底色全宽。附件媒体缩略图行在气泡上方右对齐。长文超 120px 折叠 + 底部渐隐 + 圆形展开按钮。

## 块八 · loading 全景

- **转圈盘点**【实读】：全库 `animate-spin` 约 120 处（第一篇「子代理目录 pane 内唯一」口径需限定作用域成立；工作流/计划目录实际零转圈）。聊天相关：轮尾等待小转圈、composer 发送 pending Spinner、mermaid 渲染中、队列项、上下文用量。
- **扫光家族是运行态主表达**：`.animated-gradient-text`（4s）用于工具卡/思考卡/审批占位/压缩 marker/workflow 卡；`-subtle` 变体（峰值降 subtle）用于重连文案；cua 变体 1s。
- **TTFT（首 token 前）**【实读】：用户消息先入乐观 overlay（ACK 后移除，2s 宽限判定投影已确认——不产生伪造行）；轮尾 `TurnChatLoadingSlot`（`min-h-5` 槽位小转圈）；API 重试第 3 次起换成「重新连接中… n/max」扫光文案；**可见性裁决**（`chatLoadingVisibility.ts`）——权限/提问卡、压缩、行级 pending 任一在场即隐藏轮尾 loading，避免双重进度。
- **没有的**：打字光标（无闪烁竖线；真光标仅终端输出与 workflow 时间线两处）；聊天区骨架屏（会话切换是空白等待，snapshot gate 防旧内容提前落入）；历史加载无可见指示。
- **发送按钮三态**：运行中无草稿 → Stop（secondary 方块实心，Esc 提示）；pending → Spinner 替换箭头；常态 `bg-brand`。

## 块九 · 计划与 todo 面

- **计划目录 = 状态面板「计划」分区**【实读】（非独立页）：过滤 ExitPlanMode 终态行倒序，标题取 markdown 首个 H1；点行开侧栏。计划详情 = **侧栏 tab**（`PlanDetailSidePane.tsx`）：重新提取该工具行 markdown 用 MessageResponse 渲染，**随会话继续实时更新**；markdown 来源是工具调用内容，planFilePath 仅作标签不从磁盘读。
- **计划卡**（聊天内）：限高 `max-h-64` + 单节点渐隐 mask（注释：max-height 与 mask 必须同节点）+ 居中「查看完整计划」胶囊；批准后**形态不变**（有 markdown 仍渲染计划卡），仅无 markdown/失败回退最小输出块；被拒绝的计划保留在目录。

- **plan-guidance 卡** = EnterPlanMode 触发的行卡，markdown 左导线渲染且标题层级全部压暗到 subtlest。
- **死代码/死字段**【实读】：vendored plan.tsx + shimmer 无 import（死代码）；`plansLoading` store 字段无任何 UI 消费（计划目录加载零进度反馈）。

【实读】aside 侧栏（默认 264px 可拖拽，可折成 9px 窄轨）：顶部新建任务整行按钮 + Command Center 搜索入口；列表三种视图 Tab（时间线/Hash 分组/项目 purpose 区，圆角胶囊分段控件 + 滑动 indicator）。
- **行版式**：`rounded-lg` 行（留白 + 圆角态**取代分隔线**，注释明示）；前置 16px 状态槽优先级 error 红点 > unread 蓝点 > loading 转圈 > 空闲灰点；标题**不用省略号**——右缘 1.5rem mask 渐隐 + hover 走马灯滚动；元信息 = 相对时间 + `+N/-N` diff 摘要（无消息数无模型名）；等待交互显示绿色 Badge「输入/权限 ×N」；hover 时元信息让位给操作按钮。

- **右键菜单**：置顶/重命名/归档（二次点击确认，确认态变 destructive）/标记未读/复制路径/查看模型轨迹。
- **标题生成**【实读】：优先 session.title（排除 goal 提醒文本）→ 第一条用户输入 slice(0,80) → 兜底 "New session"；`titleSource` 枚举含 generated（LLM 生成通道协议层存在，producer 在闭源侧）；防闪占位——createSession 无内容时只写库不广播，避免侧栏闪 "New session"。

## 块十二 · 状态面板 / toast / 空态 / 顶栏

- **状态面板**【实读】：悬浮会话右上，双形态——展开 `w-80 max-h-[min(64dvh,32rem)] rounded-2xl bg-popover shadow-md` / 窄屏单行胶囊（宽 ≥1280px 自动展开）；七分区（Git/目标/计划/进程/终端/工作流/子代理）均 Radix Collapsible，标题行 32px chevron hover 才显，分区间 border-t，各区分区限高 `max-h-48`（plan 80）双层兜底滚动；**token 占用不在此面板**（在 composer 工具条）。
- **toast**【实读】：无第三方库命令式 API；位置四档（默认 top-center）；版式 `rounded-2xl bg-toast/60 shadow-lg backdrop-blur-xl`；默认 3s、200ms 过渡、常驻态由 updateToast 切终态重启计时、dedupeKey 去重；无 error variant（错误走横幅/对话框）。
- **空态**【实读】：时段问候语六档（凌晨/早上/…）+ 中央 Logo 水印（浅色线框 + 底部渐隐）；推荐提示词 chips/list 瀑布入场（260ms clip-path 动画，reduced-motion 支持）+ 换一批；workspace 胶囊菜单（搜索 + 打开文件夹 + 远程 + 项目外工作）作为 composer 顶部的 contextHeader。
- **顶栏**【实读】：`h-12 border-b` 整条可拖窗（桌面端）；左 = workspace 路径 HoverCard → 会话标题 truncate → 「…」菜单（置顶/重命名/归档/复制路径）；右 = 共享/终端/侧 pane 开合/帮助。**模型与模式切换不在顶栏，在 composer 工具条**。

## 增量补录 · AssistantPreviewCards 全链路（2026-09-30 实读，锚点 29628c9）
