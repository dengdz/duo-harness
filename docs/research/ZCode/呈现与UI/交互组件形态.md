> 源锚点：`872ad960de7ec172591f7e1952f7849229f94521`（2026-09-29 本地核验，v3.14.0）。M29 工单 05 产物，**形态篇**——机制层（wire 帧/投影 store/分发协议）见 [Web呈现.md](Web呈现.md)，文字渲染/loading 全景/计划与会话面等面板形态见姊妹篇 [消息渲染与面板形态.md](消息渲染与面板形态.md)，本文只讲「长什么样、怎么动」。前端在 `packages/ui/src`，样式主文件 styles.css（2053 行，Tailwind 原子类 + 少量自定义 class）。**duo 侧落点已对照前端现状核实**（app.js §0-§4 分区、theme.css DSH 亮色 token、九类卡片族、render.dispatch 单源分发，2026-09-29）。标注：【实读】= 直读 JSX/样式；【推断】= 从结构/注释推导。

## 块一 · 思考过程折叠

**源码定位**【实读】：核心组件 `components/ai-elements/reasoning.tsx`（Reasoning :90-235 / Trigger :285-420 / Content :427-573，derived from vercel/ai-elements）；消息流接入 `v4/ConversationRowView.tsx` :1587-1620 `ReasoningRowView`——timeline 里的**独立一行**（非嵌助手气泡），与工具卡同列「工作项组容器」（`ConversationTurnGroup.tsx` :378-381，`flex flex-col gap-4`）。

**形态**【实读】：
- **收起 · 流式态**：静态 BrainIcon（`size-4 text-foreground-subtlest`）+「正在思考」`animated-gradient-text font-medium`（扫光）+ `·` + 右侧实时滚动摘要（取流文本最后非空行，超宽左右 16px 渐隐 mask + 视口推底形成旧内容左移）；图标刻意不旋转（注释：长流式里 loader 长期占渲染资源）。
- **收起 · 完成态**：「思考」+ `·` +「持续了几秒/N 秒」（时长在 streaming→complete 边沿一次性结算；收起态不跑 timer）。
- **展开态**：滚动容器 `max-h-60 overflow-auto` + 左导线缩进（`ml-2 border-l pl-3.5`，nested 变体无导线防重复层级）；内容**纯文本** `whitespace-pre-wrap`——刻意不走 Markdown 渲染（性能注释：长思考流式解析会卡）；流式期吸底跟随、离底 >2px 暂停、回底恢复。
- **状态机**：默认收起；streaming→complete 边沿自动折叠（用户手动开合过则永不自动覆盖）；chevron 收起态悬停才浮现（`opacity-0 group-hover:opacity-100`），展开 `rotate-90`；收起动画期内容延迟 300ms 卸载（保 Radix 高度动画变量）。

**CSS**【实读】：`.animated-gradient-text` styles.css :823-842（`background-clip:text` + 4s `gradient-flow` 无限循环 + `will-change`/`translateZ(0)`）；变量四套主题各定义一次；`prefers-reduced-motion: reduce` 全关（:879-883、:1021-1030）。

## 块二 · 分工具类型卡

**分发结构**【实读】：`ToolCallBlocks/resolveRenderer.ts`（173 行）——kind 组卡三分（:58-69）→ 按名分流 9 个未登记工具（:77-116，防掉 raw JSON 兜底）→ node-repl 与通用 MCP 优先（:121-126）→ family switch 16 case（:131-171）→ default `FallbackToolCallBlock`。family 表在 `packages/shared/src/tool-identity.ts`（:7-34 已知工具名 37 个、:32-68 名→family 映射）；专属 renderer 约 33 个（`renderers/` 目录 60 文件）。

**卡壳**【实读】——最大反直觉点：**收起态不是卡片**。壳 = `ToolLayout.tsx`（363 行）+ 标题行 `ToolSummaryRow.tsx`（235 行）：收起 = 无边框无背景的一行文字流（图标 size-4 → 类别词 → 参数摘要 → 徽标 → diff 计数 → chevron，`inline-flex gap-2`）；「卡片感」（`rounded-xl border bg-panel`）是**各卡展开内容区自绘**的，壳不提供。

**运行态表达**【实读，含设计注释原文】（ToolLayout.tsx :139-147）：**不用 spinner**——「旋转 loading 图标会让动画长期占用渲染资源；运行态改由文案扫光和状态文字表达，图标保持静态」——类别词运行中挂 `animated-gradient-text`，静止回落 `text-foreground-subtlest`。

**状态徽标只报忧不报喜**【实读】：状态词统一算出（`tool-call-summary.ts` :38-44，zh 文案：等待中/执行中/已执行/执行失败/已拒绝/已停止），**完成态默认不显示**（`showStatusLabel` 默认 false）；失败态词带 `underline decoration-dotted underline-offset-2`，悬停 tooltip 展示错误 + 复制按钮（ToolLayout :240-302）。

**代表卡**【实读】：
- **read**：单行卡不可展开（`canToggle={false}`）；primary = 文件 chip（类型图标+文件名可点开查看器），secondary = 父目录路径（窄容器隐藏）。
- **edit**：可展开；文件 chip 逗号连排 + diffCount 常显（`+N/-N` 等宽、`text-diff-added/removed`、数字翻页动画）；展开 = inline patch diff，多文件时竖线缩进容器内每文件一个子卡。
- **shell**：可展开；收起 secondary = 命令文本（**sans 字体**与摘要行一致，展开后才 mono）；展开 = 自绘内容盒（`rounded-xl border bg-panel`）内 `$ 命令` + 输出区**5 行上限**（`max-h-[5lh]`，流式吸底/上滚冻结/回底跟随）。
- **search**：单行卡；primary = 一整句摘要（「查找 `<query>`」），刻意不拆字段。
- **todo**：可展开；收起 = 当前进行中步骤 + `已完成数/总数`；展开每步图标按状态——完成 `CircleCheck text-success`、进行中**静态右箭头**（注释：避免与加载动画语义混淆）、待办空心圈；完成文字划线+最浅色。
- **agent（子代理派发）**：单行整行是按钮——BotIcon +「SubAgent」+ **彩色子代理名**（mono、按名字 hash 取 8 色，`lib/subagentColors.ts`）+ 运行中轮播最新子工具摘要 + 状态词；点击开右侧子代理页。产品边界注释（agent.tsx :375-377）：「父对话只保留单行摘要；完整 timeline 统一右侧查看」。
- **Fallback**（未知工具兜底）【实读】`renderers/fallback.tsx` :18-112：通用行卡 + 展开显示 raw JSON `<pre>`（有 inline preview 时隐藏）。

**交互细节**【实读】：折叠状态模块级 Map 持久化（`toolId→boolean`）；收起后 300ms 延迟卸载；`autoOpen` 一次性展开（edit/read 完成后用）；`autoCollapseOnComplete` 运行→完成边沿自动收起（agent 卡用）；chevron 与 reasoning 同款悬停浮现 + 旋转。

## 块三 · 子代理页

**定位**【实读】：**不是路由页也不是对话框**——右侧可调宽面板（`AnimatedSidePanePanel.tsx`，Radix Tabs）里的 tab。入口三处：消息流 agent 卡整行（testId `TID_V4_SUBAGENT_OPEN_SIDE_PANE`）、状态面板运行中子代理列表（每秒刷新耗时 + 取消按钮，`ConversationStatusPanel.tsx` :1316-1445）、子代理目录页（「正在运行 · N / 已结束 · N」两节，状态图标集 running=转圈——该 pane 内唯一，全库盘点见姊妹篇块八）。

**页面形态**【实读】：`SubagentSessionSidePane.tsx` :13-61——整页就是 `<SessionPane sessionId readOnly openTrigger="subagent">`，**与主会话同一个组件**（消息流/工具卡/timeline 全复用）；readOnly = 无输入框、Esc 不触发停止；tab 标题与父会话 agent 卡逐字一致（同一取文案函数）；结构化 tab id（`subagent-session:workspace:root:child`）重复点击幂等聚焦；并行多子代理 = tab 条并排（宽 156px 收缩到 60px、dnd 拖拽排序）+ 失效 tab 自动回收（active 被回收时落目录 tab）；可见性按根会话收窄不跨对话泄漏；嵌套派发再开新 tab。

**运行态区分**【实读】：tab 条上无任何运行指示（图标恒定）；区分在——父会话 agent 卡扫光 + 摘要轮播、状态面板/目录页图标 + 状态词、子代理页内部流式内容本身在动。

## 块四 · 确认交互卡（审批/提问/计划）

**挂载位置**【实读】（与 duo 架构差异最大处）：三卡共用 `v4/V4InteractionDialogs.tsx`——审批（permission）与提问/计划（userInput，按工具名分 AskUserQuestion / ExitPlanMode）都挂在 **timeline 底部 dock**（`SessionPane.tsx` :4541-4553 注释：「必须和 composer 共享 timeline bottom dock」）——会话底部、输入框上方的停靠实卡，非居中 modal、非消息流内嵌。

**审批卡**（`PermissionDialog.tsx`，925 行）【实读】：实卡版式 `rounded-2xl border-border bg-popover shadow-xs p-3`；标题「需要权限」+ 来源徽章（subagent 来源 outline badge）；主体**复用聊天区工具 renderer** 做待审内容预览（`kindLabelOverride="等待确认"`、`isRunning=false`——等待期不显执行中），全部 `canToggle:false`（关键内容不许被折叠藏起）；选项 = `role="listbox"` 全宽行按钮（序号 + label + 描述，选中 `bg-selected`、悬停 `bg-hover`）；键盘：数字 1/2/3 直接应答、Tab/方向 roving、Enter 确认，底部提示行；拒绝反馈 = 无边框 Textarea（5 行后内滚）；主按钮 `bg-brand`。**危险操作无红色强调**（全文件仅响应错误用 destructive）——审批选项视觉等权，靠顺序与文案。

**提问卡**（`ElicitationDialog.tsx`，1161 行）【实读】：同语言实卡（限高 `min(72dvh,42rem)` 内滚）；头部 = 徽章 + 问题全文 + 右上倒计时按钮（点击暂停）+ 多题分页 `‹ n/m ›`；选项行同 listbox 式，多选方形 checkbox（`border-brand bg-brand` + 白勾）；末尾固定自定义输入行（接续编号）；Esc 回上题、Enter 推进；计划审批态默认预选 approve。
**已答态**【实读】：交互卡整体卸载，时间轴回落普通工具卡——提问的痕迹在 `renderers/ask-question.tsx`：「正在询问/已询问」行卡，展开左导线下每题「问题 + 答案」，未答显示「未回答，已自动继续」。**无「已批准/已拒绝」持久徽章**【推断】。

**计划卡**【实读】：`renderers/switch-mode.tsx` :69-145——实卡（`rounded-xl border bg-card`）整卡可点；header = 图标 +「计划」+ 文件路径 + 复制按钮；正文限高 `max-h-64` + 底部渐隐 mask + 遮罩上居中胶囊按钮「查看完整」。

## 对 duo 的落地清单（跨块汇总，已对照前端现状核实）

**可借鉴（落点方向）**：

> 参照来源分工：07 成果卡片的形态由 ADR-0031 grill 裁定 + duo 既有卡片族风格确定，**不以本研究为视觉参照**（ZCode 侧无对应物可抄）；本研究喂 06 思考卡、09/10 走查与后续打磨。

1. **运行态扫光替代 spinner/徽标**——`.animated-gradient-text` 的 CSS 可直接移植（theme.css 增 keyframes + 两个 token；`prefers-reduced-motion` 同步关闭）。落点：思考卡「正在思考」（06 工单）、工具卡运行态（09 走查评审）。duo 现状：`badge-run` 静态徽标。
2. **思考折叠卡形态**（06 工单直接蓝本）：收起 = 图标 +「思考 · N 秒」+ chevron（悬停浮现、展开旋转 90°）；展开 = 左导线缩进 + **纯文本 pre-wrap**（duo 同样不该走 marked 渲染——理由同源：长文本解析成本）；duo 完成态无流式期，扫光仅用于「正在思考」场景暂缺（流式挂 backlog），完成态用静止样式。
3. **折叠动画**：收起后延迟 300ms 卸载 + 高度动画。duo 零依赖（不引 Radix/motion），用原生 `<details>` 或 CSS `grid-template-rows` 过渡等价实现；`userInteracted` 后不自动覆盖的语义一并采纳。
4. **状态报忧不报喜**：完成态淡化状态词（次要位置让给参数摘要）、失败态点线下划线 + tooltip（原生 title 起步）。落点：09 走查评审裁定（涉及 badge-ok/fail 常显惯例的调整）。
5. **子代理面**：tab 条多子代理并存 + 「正在运行/已结束」目录分组 + 彩色子代理名（8 色 hash 可抄 `subagentColors.ts` 思路）。duo 现状 `#subagentDrawer` 单抽屉——tab 化与目录页是增量，09 走查期裁定范围。
6. **审批/提问卡选项行样式**：listbox 式全宽行（序号 + label + 描述、选中 `bg-selected`）、键盘提示行、计划卡限高渐隐 + 「查看完整」。落点：`interactiveCard`/`questionCard` 版式（09 走查）。
7. **未知工具显式兜底**（反向启示）：ZCode 按名分流防掉 raw JSON 兜底卡；duo render.dispatch 链尾无 else **静默丢事件**（deliverable 事件曾是例证）——未知工具已有通用 toolCall 卡兜底，未知事件维持静默为既有口径不翻案，但 09 走查可议「未知事件控制台 warn」开发期可见性。

**不借鉴（及理由）**：

- **Radix/motion/tw-animate-css 依赖**——duo 前端零构建零依赖（marked/purify 例外先例），折叠动画用原生等价。
- **确认卡底部停靠（timeline bottom dock）**——架构级差异：duo 交互卡走消息流 + 事件回放一致性（M24-07 tabId 路由、C2 按 id 回填），改停靠即翻架构，不值。
- **审批结果持久徽章缺失**反而是 ZCode 弱项——duo `approval/decided` 事件已渲染决议结果，保持。
- **多题分页/自动结束倒计时提问**——duo ask_user 单题 + 挂起超时语义不同。
- **暗色主题/多主题变量组**——duo 走查红线「不加暗色」。
- **手机抽屉/移动端适配**——duo 无移动端面。

- 卡壳视觉全在 Tailwind 原子类字符串里，styles.css 无 `tool-summary-*` 规则——抄样式要抄 className 组合，不是抄 CSS 文件。
- `animated-gradient-text` 的变量在四套主题各定义一次（:156/:309/:462/:607），duo 只需亮色一套。
- 手机抽屉形态仅来自 agent.tsx 注释，未实读移动端容器；SessionPane（4834 行）只核读 readOnly 分支。
- 快照仅 2 提交、历史压缩——结论只对锚点 872ad96 负责。

## 附录 · 可直接移植的 CSS 与 duo token 映射（模仿开发用，2026-09-29 实读抄录）

**A1. 运行态扫光**（源 `styles.css:823-842` + keyframes :885-898，原生 CSS 可直抄）：

```css
.animated-gradient-text {
  display: inline-block;
  background: linear-gradient(90deg,
    var(--sweep-strong) 0%, var(--sweep-strong) 34%,
    var(--sweep-soft) 50%,
    var(--sweep-strong) 66%, var(--sweep-strong) 100%);
  background-size: 300% 100%;
  background-clip: text; -webkit-background-clip: text;
  color: transparent; -webkit-text-fill-color: transparent;
  animation: sweep-flow 4s linear infinite;
  will-change: background-position; transform: translateZ(0); backface-visibility: hidden;
}
@keyframes sweep-flow {
  0%   { background-position: 100% 0; }
  50%  { background-position: 0% 0; }
  100% { background-position: 0% 0; }
}
@media (prefers-reduced-motion: reduce) { .animated-gradient-text { animation: none; color: var(--sweep-strong); -webkit-text-fill-color: currentColor; } }
```

（ZCode 原名 `--animated-gradient-text-strong/soft`；duo 落地建议改名 `--sweep-*` 入 theme.css token 区，块二运行态与 06 思考卡「正在思考」共用。reduced-motion 兜底为 ZCode 等价语义——动画关、回落强色。）

**A2. 标题走马灯参数**（源 `TaskTitleOverflowText.tsx:11-16`）：右缘 1.5rem mask 渐隐（`mask-image: linear-gradient(to right, black calc(100% - 1.5rem), transparent)`）+ 滚动 40px/s + 停留 2s + hover 后延迟 1s 启动、间隔空隙 24px。
