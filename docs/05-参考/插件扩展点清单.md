# 插件扩展点清单

> 给第三方插件作者的挂载地图：**哪里能挂、怎么挂、哪里挂不上**。与[术语表](术语表.md)互读（扩展点 / 内核独占面 / 硬连点三词条）；工具的能力语义见[工具目录](工具目录.md)，逐行装配见[插件配置参考](插件配置参考.md)。M27 审查升格为参考文档（ADR-0029），随内核演进对账更新。

## 插件能挂什么——扩展点全清单

### 装载与生命周期

| 扩展点 | 挂接方式 | 说明 |
|---|---|---|
| yml 插件行装载 | `Boot.from(yml)`，行格式 `id / name(FQCN) / config / disabled` | 部署者通道；类须在 classpath（独立 jar 装载属[已知限制](../limitations.md)） |
| 编程挂载 | `ctx.plugin(plugin, rawConfig)`，同步阻塞至 apply 返回 | 宿主/测试通道 |
| 子插件挂载 | 任意插件 apply 内再 `ctx.plugin()` | 销毁级联回滚 |
| config record 绑定 | `configType()` 声明 record | 绑定失败即加载失败（点名插件与字段路径） |
| 依赖声明 | `inject()` / `optionalInject()` | 全就绪才启动、任一消失即停止；可选依赖出现/消失双向自动重载（ADR-0019） |
| 状态快照读取 | `ctx.snapshots()` | 全量插件六态即时视图（状态面数据源） |

### 服务面

| 扩展点 | 挂接方式 | 说明 |
|---|---|---|
| 服务发布 | `ctx.provide(name, instance)` | 同名互斥点名报错；发布即作用域副作用（销毁自动注销 + 唤醒依赖方） |
| 服务消费 | `ctx.as(视图接口)` 动态代理 | 方法名即服务名；读取须先 inject/optionalInject 声明（未声明即拒读） |
| 视图接口自定义 | 插件自带接口 | 第三方视图无需改 core |
| 服务便利基类 | 继承 `Service` 构造即发布 | 形态在册但仓库内部零使用——第三方可选形态 |

### 工具域（主力扩展区）

| 扩展点 | 挂接方式 | 说明 |
|---|---|---|
| 工具注册 | inject "tools" 后 `tools.register(ctx, ToolDefinition)` | 注册即生命周期硬契约（注册方停止工具自动注销） |
| 三段管线挂钩 | `ctx.on("tools/pre-execute" / "tools/execute" / "tools/post-execute", WaterfallListener)` | 洋葱模型，可改写参数/结果、不调 next 即否决 |
| guard 单调否决 | `tools.registerGuard(...)` | 理由即拒绝、无"允许"结果 |
| 审批策略替换 | 发布 "approval" 服务 | 同名互斥、在场即替换（内置三实现互斥先例） |
| 回答者注册 | inject "answers" 后 `answers.register(ctx, answerer)` | 交互 seam 的呈现端（机制与呈现分离，ADR-0008） |

### 命令、提示与内容域

| 扩展点 | 挂接方式 | 说明 |
|---|---|---|
| 斜杠命令注册 | inject "commands" 后 `commands.register(ctx, CommandDefinition)` | 名不带斜杠；busy-safe 与适用呈现位声明（ADR-0020） |
| prompt 片段贡献 | inject "prompts" 后 `register(registrant, fragment)` | 静态片段、随注册作用域摘除；每轮按注册序组装 system |
| 技能发现 | "skills" 服务 + 发现根目录扫描 | 技能是 SKILL.md 非代码（与插件分界见术语表） |
| 内容域服务在场 | memory / agentsMd / attachments / sessionQuery 等服务 | 服务在册 ≠ 被消费——消费接线在装配层（见独占面） |

### 事件面

| 扩展点 | 挂接方式 | 说明 |
|---|---|---|
| 自定义事件五式 | `emit` / `parallel` / `serial`、`bail`（投票）/ `waterfall`（洋葱管线） | 监听器表全树共享；无持久化、无跨进程 |
| 内核状态事件 | `ctx.on("plugin/status", ...)` | 插件状态迁移广播 |
| 工具域事件 | 同三段管线挂钩 | 插件可听面中唯一携带"模型活动"信号的事件 |

## 插件听得到什么——事件面事实

**可听**：`plugin/status`（状态迁移）；`tools/pre-execute` / `tools/execute` / `tools/post-execute`（载荷 ToolExecution 含工具名与结果）；插件间自定义事件（任意通道名）。

**不可听**：全部会话事件（user/assistant 消息、tool/call、todo/write、压缩点等）——只写会话 JSONL + 通知会话私有监听器，不经事件总线；Web SSE 是 HTTP 通道非插件总线。插件最接近"会话活动"的信号是 `tools/post-execute`（有工具调用与结果、无消息文本）。见[已知限制](../limitations.md) M27 节。

## 内核独占面——挂不上的区域

| 独占面 | 现状 | 说明 |
|---|---|---|
| 呈现位身份 | cli/web 常量钉在 agent 域契约 | 第三呈现位无合法身份（headless 在示例模块自造绕行） |
| agent 执行链装配 | 执行链经构造参数链装配（全仓最大装配点为命令注册接线） | 新能力挂进执行链 = 改内核；参数对象化列 M28 |
| agent 循环边界 | turn 起止、收件箱、steer、中断内嵌执行链与呈现位 | goal/调度类插件无 turn 感知与再触发通道（1.0 后挂点设计） |
| 会话事件面 | 会话实例装配期直连、事件不上总线 | 插件无数据源听消息流（见上节与已知限制） |
| WebFace 端点 | 端点集中私有注册 | 插件加不了 HTTP API/页面（拆分列 M28） |
| 前端渲染 | 按工具名字面量分发卡片 | 新工具在 Web 无呈现路径（协议化渲染列 backlog） |
| 装载机制 | 手写 FQCN 行反射装载 | 无目录扫描/jar 级装载/批量自启（1.0 后按需） |
| llm / session 实例 | 装配期构造直连、不走服务注册表 | 插件无法换 provider、拿不到当前会话 |
| 治理与准入内核面 | 治理链内嵌执行链；fail-closed 面归内核 | **设计取向非缺陷**：治理权不外放 |

## 服务名全表

服务名是全局扁平命名空间：harness 保留裸名，第三方服务须加前缀；视图接口方法名与服务名逐字一致。

| 服务名 | 域 | 提供方 | 主要消费方 |
|---|---|---|---|
| tools | tools | ToolsPlugin | HooksPlugin、各工具插件、装配层 |
| answers | tools | InteractionPlugin | CLI / Web（回答者注册） |
| approval | tools | ApprovalPlugin / InteractiveApprovalPlugin / WorkspaceApprovalPlugin 三选一互斥 | 工具执行链 |
| workspace、backgroundTasks | tools | FsToolsPlugin | fs 工具族、装配层 |
| permissionRules | tools | PermissionRulesPlugin | 审批链 |
| connectorStatus | tools | MCP 支撑类（单例板，装配期发布） | CLI 状态行、Web 状态面 |
| prompts | agent | PromptPlugin | 装配层（每轮组装 system） |
| commands | agent | CommandsPlugin | CLI / Web |
| skills | agent | SkillsPlugin | skill 工具、/技能名 直调 |
| memory | agent | MemoryPlugin | 装配层（每轮注入） |
| agentsMd | agent | AgentsMdPlugin | 装配层（每轮现发现现读） |
| fileRefs | agent | Web 插件装配期发布（workspace 在场时，M28 工单 07 服务化） | Web @提及补全 |
| subagents | agent | SubagentPlugin | spawn/fork/send_message 工具族 |
| host | agent | 装配期发布的子代理宿主（M28 工单 05 自 "presenter" 改名——语义归位） | 子代理过程行回传呈现位 |
| attachments | attachment | AttachmentPlugin | read_image、Web 授权读取 |
| sessionQuery | session-query | SessionQueryPlugin | session_search 工具、Web 搜索框 |
| greeting、temp-news | example | 示例插件 | 演示 |

llm 与 Session 无服务名（装配期直连）。模块依赖方向：core ← 基础域（llm / session / attachment）← 功能域（tools / agent / mcp / hooks / session-query）← 呈现位（cli / web）← example——功能域服务"同 classpath 才可消费"，第三方独立交付依赖装载机制的 jar 化演进。
