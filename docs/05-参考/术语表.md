# duo-harness

Java 实现的插件化 AI agent harness：内核是自研轻量插件容器，所有能力（工具 / MCP / 页面 / agent 循环）以插件形式组装。架构参考 DSH（deepseek-harness），研究资产在 `docs/research/DSH/`。

## Language

### 容器内核

**Context（上下文）**:
插件能看到的唯一句柄：服务的寻址入口、生命周期副作用的注册点、事件的监听点。内核的 Context 实例是动态代理；一个实例对应一个插件实例的作用域，子插件获得子 Context。
_Avoid_: 容器、App

**视图接口（View Interface）**:
服务域声明的类型窗口：一组以服务名命名的方法接口。插件经 `ctx.as(XxxView.class)` 取得视图，动态代理按方法名解析到字符串服务名。是 DSH "declare module 类型增强"的 Java 对应物，第三方插件自定义视图无需改核心。
_Avoid_: Context 接口、declare module

**服务（Service）**:
具名能力的提供物。身份 = 字符串服务名，类型由视图接口约定，由服务提供者插件发布到注册表。同一服务名在不同作用域可解析到不同实现。
_Avoid_: 组件、Bean

**服务名（Service Name）**:
服务的字符串身份，全局扁平命名空间。harness 保留裸名（`tools`、`llm`、`sessions`…），第三方服务加前缀。
_Avoid_: 服务 ID

**插件（Plugin）**:
扩展单元：一段声明依赖（inject）并提供 `apply` 入口的代码。插件是描述，加载后才有生命。
_Avoid_: 扩展、模块（模块指 Maven 模块）

**插件实例（Plugin Instance）**:
一次插件加载的运行时实体：持有子 Context、依赖表、副作用栈与生命周期状态。同一插件可多次加载各得一个实例。
_Avoid_: Fiber、插件对象

**inject（依赖声明）**:
插件静态声明的服务名列表，是其启动的前提：全部就绪才启动，任一消失即停止。
_Avoid_: require、dependsOn

**可选依赖（optionalInject）**:
插件声明的"有则用之"服务（`Plugin.optionalInject()`）：与 inject 同一读取纪律（`as()` 视图），唯一差别是缺失不阻塞启动；在场时参与依赖指纹，出现/消失照常触发自动重载——升级↔降级双向对称（ADR-0019）。
_Avoid_: 软依赖、弱依赖、运行时探测（不引入使用点 get 探测）

**effect（可逆副作用）**:
随插件实例生命周期自动回滚的注册物（监听器、子服务、子插件…），回滚按注册逆序。插件卸载即全部 effect 回滚——"拔掉插件"的全部含义。
_Avoid_: 监听注册、资源

### 生命周期

**epoch（依赖指纹）**:
插件实例全部依赖实现的指纹串。指纹变化触发实例自动重载或停止，是免写启动顺序与运行期插拔自动传导的机制核心。

### 事件

**waterfall（瀑布管线）**:
事件分派模式之一：监听器收到 `(参数, next)`，可改写参数、包装返回值或不调 next 直接否决（否决含默认行为）。洋葱模型，工具管线与内部钩子的地基。
_Avoid_: 拦截器链、中间件

**bail（投票）**:
事件分派模式之一：同步顺序询问，首个非空返回值即终止并作为结果。

### 工具域

**workspace**:
agent 的操作根目录绑定：fs 工具与 bash 的路径解析基准与写边界（默认进程 cwd，插件配置可指）。路径包含性判定是可信代码内的策略检查，不是 OS 内核边界（ADR-0012）。
_Avoid_: 沙箱（无 OS 隔离）、工作区（歧义）

**权限预设（Permission Preset）**:
三档打包的路径感知审批策略：`read-only`（读放行，写与 bash 一律 ask）/ `workspace-write`（workspace 内写放行，越界与 bash ask，默认档）/ `danger-full-access`（全放行）。经 REPL `/permission` 命令切运行时态，重启回 yml 缺省（ADR-0012）。
_Avoid_: 沙箱模式（无 OS 隔离）、审批策略（预设是策略的打包非本体）

**权限规则（Permission Rule）**:
工具级的持久审批规则，两级作用域：项目级持久于项目根 `.duo/settings.json` 的 `permissions` 段，会话级随会话事件流持久（resume 恢复）。bash 用 `Bash(prefix:*)` 词边界前缀记法（命令名后须紧跟串尾或空白）；deny 规则仅手写且恒优先（与 guard 单调否决同构），allow 规则产自审批卡「总是允许」；高危根命令生成与运行时双拦——手写 allow 也不生效（ADR-0026）。
_Avoid_: 权限预设（预设是档位打包非规则）、访问控制列表（无身份概念）

**只读命令（Read-only Command）**:
bash 命令的三态只读判定（true/false/undefined，undefined 一律按非只读，fail-closed）：首期约 30 个 allowAnyArg 只读命令 + git 四件套 status/log/diff/show（必叠 cwd `.git` 存在性信任分类，防 `git -C` 逃逸）；管道、命令替换、重定向等复合结构一律不算只读；判定经运行时 capability 覆盖静态 metadata 的 seam 接入审批链，true 即免审批（ADR-0024 排期，ADR-0026 钉口径）。
_Avoid_: 安全命令（只读≠无副作用面）、白名单命令（白名单指 llm.models 模型准入）

**读前写闸门（Read-before-Write Gate）**:
write 覆盖已有文件与 edit 前校验会话已读该文件，未读即拒并提示"先 read 再重试"——防模型盲改真实事故源；新建文件豁免（ADR-0012）。
_Avoid_: 乐观锁、版本校验

**三段管线**:
工具执行的固定 waterfall 阶段序列：pre-execute（准入，可否决）→ execute（around 包裹本体）→ post-execute（结果改写或拦截）。审批、超时、结果治理都作为监听者挂在这三段上，不进工具本体。

**钩子（hook）**:
复用 Claude Code/Codex hooks 配置格式的外部命令扩展：`~/.duo/hooks.json` 按事件名分组（一期仅 PreToolUse / PostToolUse），钩子进程经 stdin 收 JSON 载荷、以退出码与 stdout JSON 表态——exit 2 阻断且 stderr 回给模型，PostToolUse 的"阻断"是结果改写非撤销。失败语义 fail-open（超时/崩溃放行，跟随两家官方）；硬闸门需求由 guard/审批承担。boot yml 装插件行即 opt-in（ADR-0019）。
_Avoid_: 插件（钩子是外部进程，插件是代码）、webhook、生命周期回调（一期仅工具事件）

**并发安全（isConcurrencySafe）**:
工具对单次调用可否并行的声明：接口 default 方法、以本次调用参数判定，仅严格 true 让该调用进并行池；未覆写、判定抛错、非严格 true 一律按独占处理（fail-closed，ADR-0018）。首批仅 read/glob/grep 声明安全。
_Avoid_: 线程安全（指实现内部无共享状态，非调度语义）、无副作用

**独占工具（Exclusive Tool）**:
不与任何其他工具同时执行的调用：或因声明（未通过并发安全判定）、或因审批（requiresApproval 即独占）、或因域内恒定（MCP 远端工具）。以顺序屏障形态单独执行（ADR-0018）。
_Avoid_: 串行工具、阻塞工具

**管线缺省超时（Pipeline Default Timeout）**:
工具域三段管线 execute 段的统一兜底超时（缺省 120s、yml 可配）：超时中断执行并以超时错误作为工具结果回填；工具自身声明（如 bash 的 timeoutMs）优先于缺省，ask_user 豁免（ADR-0018）。
_Avoid_: 请求超时（LLM / MCP 域各自的连接层超时）、看门狗

**后台任务（Background Task）**:
bash 经 run_in_background 显式转入的后台执行：内存注册表持 taskId（进程退出全灭），模型经 task-output（block/timeout/尾窗）与 task-stop 两工具操作；完成通知每任务至多一条（first-wins）——agent 空闲即开新轮、busy 挂收件箱 next-turn 级收口合并消费；暂停不杀后台任务（ADR-0025）。
_Avoid_: 后台进程（泛指）、job（DSH 命名）、守护任务

**spill（输出转存）**:
bash 输出超 inline 预算后的保尾落盘形态：inline 尾窗（默认 30k 字符）保最近输出、全量落盘 spill 文件并回传 spillPath 供模型回读，帽 64MiB、超帽告警不静默；三层预算 yml 可配（ADR-0025）。
_Avoid_: 静默截断（超帽必告警）、上下文治理 spill（同名不同域——治理阈值指上下文溢出）

**忽略判定（ignore filter）**:
glob/grep/@file 补全索引共用的文件忽略判定器：自研 Java 逐级堆叠解析 .gitignore 与 .git/info/exclude（! 反选、**、?、[]、尾 /、前导 /、转义全子集，坏行静默跳过），判定取 .gitignore ∪ 硬编码产物目录 ∪ VCS 元数据目录并集；全局 excludesFile 不做（ADR-0025）。
_Avoid_: 沙箱边界（非安全边界）、ripgrep 捆绑（红线 4 已拒绝）

**config record**:
插件声明的强类型配置载体（Java record），由内核从配置树绑定，绑定失败即加载失败。是插件对外的配置契约。

### MCP 域

**MCP 服务器（MCP Server）**:
按 Model Context Protocol 对外暴露工具的外部进程（如 filesystem server）。duo-harness 经连接使用其工具，自身不实现协议之外的能力。
_Avoid_: MCP 服务（与服务概念混淆）

**MCP 客户端连接（MCP Connection）**:
duo-harness-mcp 与单个 MCP 服务器之间的会话：首连、重连、工具同步都发生在连接上。一个连接对应一个服务器进程。
_Avoid_: 通道、MCP 会话

**工具同步（Tool Sync）**:
把 MCP 服务器暴露的远端工具转换为本地工具并注册进工具域的两阶段过程：先取全量列表校验，再原子换新。同步失败保留旧一代工具继续服务。
_Avoid_: 工具导入、工具拉取

**工具名规范化（Tool Name Normalization）**:
MCP 远端工具名的有损规范化 + 短哈希后缀：展示段非法字符替换为下划线，尾缀哈希对 server 与<b>原始工具名</b>计算（`mcp__{server}__{tool}__{hash8}` 形态）——清洗同形的异名工具哈希必不同，任何服务器组合下名字稳定可预期，废弃「清洗坍缩重名即抛错」旧语义；重连耗尽（GAVE_UP 注销）之上补会话事件通知与状态面标注（ADR-0026）。
_Avoid_: 动态改名（名字随加载顺序漂移的已拒语义）、哈希寻址

**审批策略（Approval Policy）**:
`ask` 决策的裁决者：治理插件或工具声明某次调用需审批时，由它判定放行或拒绝并署名策略来源。M2 提供预设实现（always-deny 默认 / auto-approve 白名单）；交互式审批是未来的一种策略实现，机制与形态分离。
_Avoid_: 权限、许可、授权

**ask（审批请求）**:
pre-execute 的第三种决策（与 allow / deny 并列）：声明"此调用需要审批"而不自行裁决。声明与裁决分离——声明者（治理插件或工具）只置位，裁决由审批策略服务承担；请求无人解析时按"未配置即拒"处理。
_Avoid_: 待审批、挂起

**输出契约（Output Contract）**:
工具经 `output()` 声明的结果 JSON Schema 与执行后的校验行为：结果违约转 error 结果并点名原因（与工具异常同一出口）。本地工具与远端工具（声明 outputSchema 者，同步时带入）同标准；未声明者宽松透传。
_Avoid_: 返回值校验

**guard（单调否决）**:
工具执行前（审批之后、本体之前）的动态否决检查：返回理由即拒绝，没有"允许"结果，后续 guard 与监听器都无法把拒绝翻回允许。guard 随注册作用域销毁自动摘除；与三段管线的可否决监听器是两种能力。
_Avoid_: 拦截器、守卫

**审批钉死（Approval Pinning）**:
子代理工具调用的审批语义恒定化：需审批的调用不由人裁决，而是确定性拒绝并把拒绝理由作为工具结果回传子代理——子代理在最终回答中说明限制、交回父代理处理（ADR-0016）。消除"子代理调需审批工具挂起等应答"的悬置态。
_Avoid_: 审批禁用（策略本身未删，只是子代理面恒否）、静默失败



### LLM 域

**LLM 适配器（LLM Adapter）**:
provider 中立的流式调用契约：stream（直答，chunk 回调）与 streamTurn（agent 循环，聚合为结构化一轮）。换 provider 只换适配器实现，消费方不感知协议差异。
_Avoid_: 客户端、SDK 封装

**思考内容（reasoning content）**:
思考模型（thinking mode）在流式响应 `delta.reasoning_content` 中携带的推理过程：适配器按序捕获，工具调用链中按 provider 要求回传最近一轮。不落会话日志（已知限制清单）。
_Avoid_: 思维链、CoT

**用量（usage）**:
provider 在流式响应末尾报告的真实 token 统计（prompt/completion）：经 `include_usage` 捕获后作为 assistant/message 事件的可选字段落会话日志。治理判定与状态面优先消费真实值，provider 未报时退回本地估算兜底（ADR-0009）。
_Avoid_: 估算值、token 数（歧义）

**上下文占用（Context Occupancy）**:
最近一次响应的 prompt + completion tokens 对模型上下文窗口的占比，近似下一轮请求将携带的上下文大小。治理判定与状态面"占用 N% / 阈值 M%"同源同口径（ADR-0009）。
_Avoid_: 上下文长度、对话长度

**流式空闲超时（Stream Idle Timeout）**:
流式响应连续 N 秒无新字节即判流已死（缺省 90s，`llm.streamIdleTimeoutSeconds` 可配）：首增量前超时按可重试错误走重试链，已交付增量后超时终止本轮并保留已输出——防 provider 半开连接永久挂死 agent 循环（ADR-0016）。
_Avoid_: 连接超时（建连阶段）、读超时（阻塞读上限非空闲间隔）

**模型切换（Model Switch）**:
/model 命令的运行时换模型语义，首期限同 provider（baseUrl 不变换模型名）：可切名以 yml `llm.models` 白名单为准（无参列出+当前，清单外拒切）；会话事件记「保存意图」、执行绑定分离——resume 时意图 ≠ 当前配置模型仅横幅提示不自动切（ADR-0026；跨 provider 路由属 1.0 后菜单）。
_Avoid_: 换 provider（适配器重建，非本期）、静默回落（旧 resume 语义，已废）

**思考等级（Thinking Effort）**:
思考深度的四档归一（off/low/medium/high，缺省 medium）：按 provider 映射——Anthropic thinking+budget、OpenAI 兼容 reasoning_effort、DeepSeek 靠切模型、GLM thinking 开关；不支持即显式降级标注（不静默）；辅助性请求（标题生成等）强制降档；/effort 切档落会话事件、下一 turn 生效（ADR-0026）。
_Avoid_: 思考内容（响应侧推理过程非请求侧档位）、temperature

**provider 声明（Provider）**:
yml `llm.provider` 的四值显式声明（openai-compat 缺省 / anthropic / deepseek / glm）：决定适配器选型（openai-compat 与 anthropic 是仅有的两个协议实现）、鉴权头形态与思考等级映射策略；provider 不再由 baseUrl 隐式表达（ADR-0026 决策七）。
_Avoid_: 模型名（模型是 provider 下的具体条目）、baseUrl（仅是接入点地址）

### 会话域

**会话事件溯源（Session Event Sourcing）**:
会话以不可变事件序列为唯一事实：`append` 是唯一写入原语并同步落 JSONL，读取侧投影出对话消息。崩溃安全、可回放，旧格式文件向后兼容。
_Avoid_: 聊天记录、历史消息表

**投影（Derive Messages）**:
从事件日志推导对话消息视图的纯函数（`deriveMessages`）：user/assistant 消息与工具调用事件按规则入列，流式 chunk 不投影。投影不回写事件。
_Avoid_: 缓存、快照

**事件快照（Event Snapshot）**:
`events()` 返回的调用时刻稳定事件序列：append 时锁内重建的共享不可变列表（CoW），读侧零拷贝返回共享引用——并发隔离与遍历安全语义不变（ADR-0014）。
_Avoid_: 尾部窗口快照（协议层恢复形态，勿混用）

**会话锁（Session Lock）**:
会话文件的进程级单写者检测：打开会话时取得文件锁并持有至关闭，第二个进程打开同一会话即明确报错而非静默双写。防分脑不协作——只拒绝，不协调（M10）。
_Avoid_: 占位（与上下文占用混淆）、分布式锁

**子代理（Subagent）**:
父 agent 经 spawn（全新）/ fork（父历史播种）分解任务的内嵌 agent 实例：独立会话与锁、模板化工具集、禁嵌套（深度 = 1）；控制面（send_message / interrupt / list）归父 agent（ADR-0015）。
_Avoid_: 多 agent 协作、跨进程 agent

**种子边界（Seed Boundary）**:
fork 子会话日志开头"前 N 条来自父日志"的标记：播种段 = 父日志平衡完成轮前缀（半截轮排除），边界之上的消息是继承背景、之下才是子代理自己的行为（ADR-0015）。
_Avoid_: 历史复制、上下文拷贝

**子代理基线（Subagent Baseline）**:
框架维护的子代理固定身份提示：无跨任务记忆、只做交接的一件事、范围外不深挖、结果被截断改精确查询而非重复读取、结论即交付物。子代理 system = 基线 + 模板专属提示——通用纪律归框架一处维护，模板只写角色，任务描述由父 agent 现场生成（ADR-0015）。
_Avoid_: 预制完整提示词、子代理记忆

**合成闭合（Synthetic Closure）**:
崩溃恢复语义：打开会话取锁后探测日志尾部未闭合的 tool/call，追加合成 tool/result（注明"结果因进程中断未知，只可重试只读/幂等操作"）再建快照——日志自包含、投影零特判，子代理会话同路径受益（ADR-0016）。
_Avoid_: 日志修复（非改写历史，是补齐断口）、投影期跳过

### agent 循环

**工具循环（Tool Loop）**:
agent 的核心循环：LLM 自主发起 tool_calls → 工具经三段管线与治理链执行 → 结果以 TOOL 消息回填 → 继续调用直至最终回答或迭代上限。harness 不替模型决策，只执行与治理。
_Avoid_: 自动执行、链式调用

**Function Calling**:
模型发起工具调用的协议机制：请求携带工具清单（ToolSpec），响应返回带 id 的调用请求，结果按 id 关联回填。OpenAI 兼容协议形态。
_Avoid_: 插件调用、API 调用

**迭代上限（Max Iterations）**:
单次 send 允许的最大 LLM 往返轮数（默认 10）：超限返回错误说明而非无限循环，防异常任务烧 token；剩 2 轮时注入 system-reminder 提示模型收敛（上限感知，ADR-0025），达限行为不变。
_Avoid_: 递归深度

**顺序屏障（Sequencing Barrier）**:
工具调度的分组纪律：按 model 序扫描撞到独占调用时，排空当前并行组、独占调用单独执行、之后继续分组——独占调用执行期内不与任何其他工具同飞（DSH 同款，ADR-0018）。
_Avoid_: 互斥锁、同步点

**model 序提交（Model-order Commit）**:
并发执行的结果提交纪律：无论完成先后，tool/call 与 tool/result 严格按模型给定顺序成对写入事件日志——执行并发、提交有序，日志形态与串行时代同构，回放 / 尾窗 / 投影零特判（ADR-0018）。
_Avoid_: 完成序提交（已否决）、有序执行（执行恰是无序的）

**并发度（maxParallelToolCalls）**:
单轮并行池的工具同时在飞上限：缺省 10、yml 可配；配置为 1 即完全串行（兼排障开关）。超限调用排队补位（滚动池），不拒绝（ADR-0018）。
_Avoid_: 线程池大小、并行度

**todo 清单（todo list）**:
agent 的轮内任务分解状态：todo_write 工具全量整表替换（content + status 三态，无 id），`todo/write` 事件落日志（latest-wins 投影、重开恢复）；模型只收计数回显，完整清单只走事件流给呈现位（Web 双表面 + CLI 摘要，ADR-0018）。
_Avoid_: 计划（计划模式的概念）、goal（跨轮目标域，未实现）

**工具并行池（Parallel Tool Pool）**:
单轮内并发安全调用的虚拟线程滚动执行组：以并发度为同时在飞上限，完成一个补位一个；组内结果仍按 model 序成对提交（ADR-0018）。
_Avoid_: 线程池（实现载体非语义）、任务队列

**prompt 注册表（Prompt Registry）**:
agent 域的 "prompts" 服务：插件经 `register(registrant, fragment)` 贡献提示片段，随注册作用域自动摘除；每轮请求按注册序动态组装为最终 system 提示。yml 的 `llm.systemPrompt` 是排在最前的用户指令片段，全部为空才落内置缺省。M7 技能指令段的挂载点。
_Avoid_: 模板引擎、prompt 管理

**prompt 片段（Prompt Fragment）**:
注册进 prompt 注册表的最小提示单元：(source 名, content)。source 标记贡献者身份，便于审计与点名。
_Avoid_: 模板、段（与分节语义混淆）

**交互 seam（Interaction Seam）**:
审批与提问共用的机制层：策略或模型只声明"需要人来答"，实际作答交给已注册的回答者。机制（声明、遍历、fail-closed）与呈现（终端 / Web）分离——随宿主演进只换回答者，不动机制。
_Avoid_: UI 回调、弹窗

**回答者（Answerer）**:
注册进交互服务的呈现端实现：接收交互请求（审批 / 提问），呈现给人并返回回答。AgentRepl 注册 console answerer（M6），Web 面注册 web answerer（M8）。随注册作用域自动摘除。
_Avoid_: 监听器（listener 只观察不作答）、回调

**fail-closed（无答即拒）**:
交互请求没有任何回答者在场、或人未作答（EOF / 中断 / 超时）时，一律按拒绝处理——交互缺失永不等于默许。
_Avoid_: 缺省放行、超时通过

**提问工具（ask_user）**:
模型发起的交互工具：参数含 question 必填文本、可选 options 选项数组与 multiSelect；执行本体即"经交互 seam 等人作答"，回答作为工具结果回填，模型据此继续。问与答复用 tool/call、tool/result 事件留痕。
_Avoid_: 问卷、表单

**斜杠命令（Slash Command）**:
插件代码注册进命令注册表的用户操作（/名字）：同步执行于呈现位进程内、不进模型历史，落 command/run 与 command/done 审计事件；适用呈现位可标记（ANY/CLI/WEB）。与技能的分界 = 技能替用户说话（进历史）、命令操作 harness（不进历史）（ADR-0020）。
_Avoid_: 技能直调（平行机制）、REPL 内置命令（实现位置非概念）

**busy-safe（运行中安全）**:
命令的声明标记：agent 执行（单飞占用）期间可否立即执行。缺省 false（fail-closed——动会话/上下文的命令必须等空闲）；/permission 类 volatile 治理态切档声明 true。非 busy-safe 命令在执行中输入得到明确等待回应（ADR-0020）。
_Avoid_: 线程安全（指执行时机语义非并发原语）、异步命令

**收件箱（Inbox）**:
agent 域的两级输入队列，CLI 与 Web 双呈现位同源：next-step 级在 step 边界注入当前 turn（CLI 执行期键入的默认去处），next-turn 级在当前 turn 收口后生效（后台完成通知等内部事件与显式排队消息）。收件箱是机制不是消息（ADR-0020 立单级，ADR-0025 升两级）。
_Avoid_: 消息队列（实现载体非语义）、命令队列（ZCode 实现细节）、待办

**steer（运行中注入）**:
agent 执行期间用户输入经收件箱边界注入的机制：CLI 执行期键入默认走 next-step 级（step 边界模型即见、提示行回显），内部事件走 next-turn 级收口合并消费——中途纠偏不推倒重来，落普通 user/message、不发明专属事件、不打断飞行中工具组（ADR-0020 立机制，ADR-0025 接通 CLI）。
_Avoid_: 打断/抢占（语义是边界注入）、收件箱消息（收件箱是机制非领域词）

**暂停（协作式中断）**:
运行期发起的协作式中断与恢复：CLI 运行期 Ctrl+C 单击（SIGINT 拦截，不可用降级 /stop 行命令）或 Web 停止按钮触发——当前工具调用终止、已流出文本打 interrupted 标记、未派发工具补合成结果，会话日志可重放无悬空；会话停可恢复态，续接即继续。不做原地冻结；运行期再按退出、空闲单击即退出；不杀后台任务（ADR-0025）。
_Avoid_: 原地冻结（流与工具在飞语义不可控）、终止进程（中断不退出）、打断

**亲和路由（Affinity Routing）**:
回答者路由规则：ask 请求携发起呈现位标记，发起方回答者优先作答，缺席/放弃才轮注册序——"谁发起谁作答"，双开部署下 CLI 审批不再跳 Web 卡片（ADR-0020）。
_Avoid_: 注册序路由（被亲和取代的兜底序）、广播路由（已拒绝）

**审批小队列（Approval Queue）**:
多个待答审批的排队应答形态：逐个呈现带「第 i/N」计数，答完即进下一个；决策枚举 allow/deny/总是允许（项目）/仅本会话四值，CLI 端 y=允许、a=总是允许（项目）、s=仅本会话、n 或空回车=拒绝（行缓冲下「Esc 兜底 deny」的等价物），Web 卡片对应按钮且回填按卡片 ID 关联；高危根命令的卡片不出现总是允许两键；暂停/中断时余项全部合成 deny 移除（ADR-0024 排期，ADR-0025 钉枚举与键位，ADR-0026 扩四值与回填身份）。
_Avoid_: 审批面板（无 TUI）、并行应答



### 技能域

**技能（Skill）**:
SKILL.md 定义的流程能力包：name + description（frontmatter）+ 指令正文。启动时从发现根扫描加载；模型经 skill 工具按名加载指令、用户经 `/技能名` 直调。
_Avoid_: 插件（插件是代码）、命令

**发现根（Discovery Root）**:
技能目录的优先级序：`.duo/skills`（项目）→ `.agents/skills`（项目，行业标准）→ `~/.duo/skills`（用户）→ `~/.agents/skills`（用户），同名高优先根胜。
_Avoid_: 搜索路径、classpath

**技能热加载（skill hot reload）**:
技能目录的运行时生效机制：watch 监视发现根，变更使缓存失效（revision 递增），技能目录消息按内容 sha256 digest 去重——变化才重发、只重发一次；watch 不可用降级为启动扫描 + 日志警告，不阻断发现（ADR-0025，M23 落地）。
_Avoid_: 实时重载（revision/digest 批处理语义）、插件热插拔（插件重载是 epoch 机制）

### 技能写作域

技能写作与改写的用词约束（规范本体见 [技能写作规范](技能写作规范.md)，词条依据 ADR-0027 落地）。

**工单（issue）**:
本地 tracker 中一张可执行的工作卡，三要素 What to build / Blocked by / Status 齐全才算立单。
_Avoid_: ticket（仅引外部系统原文时用）、任务卡

**收口（wrap-up）**:
流程末段的完成核对关口：各环节产物齐全且证据落盘，仅此时输出最终总结（审查语境 = 四轴报告齐全 + 最窄测试全绿）。
_Avoid_: 完成（歧义：覆盖 done 状态与流程结束两义）

**验收（acceptance）**:
用户亲手运行验收件并确认通过（done 的定义）；agent 自跑测试不计入。
_Avoid_: 验证（指 agent 自跑测试/检查）、确认（口语，正文不用）

**完成判据（completion criterion）**:
步骤末尾可判定 done 与 not-done 的条件；强形态要求出示证据（落盘路径、命令输出）。
_Avoid_: 硬判据（历史用词，统一为完成判据）

**上下文指针（context pointer）**:
常驻上下文中命名外部材料及其触达条件的一行——description、AGENTS.md 路由行同为此物；措辞决定触达可靠性。
_Avoid_: 链接、引用（不区分常驻属性）

**领先词（leading word）**:
预训练已有的紧凑概念词，在指针与正文重复出现以锚定一类行为与触发（三件套、最窄测试、收口）。
_Avoid_: 关键词（泛指不锚定行为）

**证据先行（evidence first）**:
完成判据要求出示已落盘路径、命令或输出，不以声称代替出示。
_Avoid_: 留痕（弱化出示动作）

**渐进式披露（progressive disclosure）**:
把仅部分分支需要的参考内容推到指针后按需加载的层级安排（L0/L1/L2 是其完整实现）。
_Avoid_: 渐进式加载、按需加载（结构语境统一用渐进式披露）

### 计划模式

**计划模式（Plan Mode）**:
硬禁的工作形态：激活时挂计划指导片段（先探索再设计、不做修改性操作），状态存于 plan/mode 会话事件（续接恢复）；非白名单工具不注入模型（写/执行类不可见）+ pre-execute deny 兜底，白名单 = 只读 bash 策略表 + 既有只读工具，web_fetch/web_search 维持只读档 ask 语义（ADR-0026 改写引导式旧口径，M7#1 销账）。
_Avoid_: 只读模式、沙箱

**计划呈交（exit_plan_mode）**:
模型完成设计后调用：计划全文经交互 seam 呈交用户复核——批准写 exited 事件并开始执行，打回反馈进结果继续改计划；fail-closed 保持计划模式。
_Avoid_: 确认弹窗

**AGENTS.md 注入**:
用户全局（~/.duo/AGENTS.md）与项目根（.git 定根）的 AGENTS.md 内容按序拼接（64KB 预算截断），注册为 prompt 注册表片段——项目约定对运行时 agent 自动可见。
_Avoid_: 系统提示词模板

### Web 呈现域

**状态面（Status Panel）**:
浏览器右区的系统健康视图：插件六态表（Context.snapshots）+ 工具清单（含 MCP 远端）。SSE 触发实时刷新。
_Avoid_: 仪表盘、管理后台

**SSE 事件流（Event Stream）**:
会话事件到浏览器的单向推送通道（Server-Sent Events）：首连全量快照回放，重连经 Last-Event-ID 游标增量补齐；页面按事件类型渲染消息/工具卡/交互卡。
_Avoid_: WebSocket、轮询

**增量回放（Incremental Replay）**:
SSE 断线重连的补齐机制：事件帧带日志下标作游标（id），浏览器重连自动携带 Last-Event-ID，服务端只发其后事件；游标越界（日志经治理折叠）全量快照兜底——宁可重放不可丢事件（ADR-0010）。
_Avoid_: 断点续传、全量重放

**Web answerer**:
交互 seam 的浏览器呈现位：待答审批/提问/计划经 SSE 推送为交互卡片，点选后 POST 回答完成等待中的请求。无人能答（全部页面关闭且宽限期内无新连接）一律 fail-closed——刷新断旧立新不误杀（ADR-0010）。
_Avoid_: 前端回调

**入口栅栏（Entry Gate）**:
Web 面入站请求的**三级**校验：① 全请求 Host 头白名单（127.0.0.1 / localhost / [::1] 带端口，封死 DNS rebinding）；② 写端点 Origin 同源校验（非空且不同源 403；本地工具无 Origin 放行；GET/SSE 不校 Origin、无副作用由 Host 校验兜底）；③ 鉴权令牌（M24 工单 06，authToken 非 null 时启用——头/查询串常量时间比对，失败 403）（ADR-0016 立①②，ADR-0026 立③）。
_Avoid_: 防火墙、鉴权令牌（第三级是令牌校验本体，见鉴权令牌词条）

**鉴权令牌（Auth Token）**:
Web 面的持有式凭证：启动随机生成、控制台打印带 token 的 URL，浏览器首载后存 localStorage、后续 HTTP/SSE 请求携带；校验失败一律 403（fail-closed）；yml 可显式关闭，关闭时启动横幅警示（ADR-0026）。
_Avoid_: 用户身份（令牌不识别用户）、入口栅栏（Host/Origin 校验，令牌之外的另一级）

**标签会话绑定（Tab Session Binding）**:
浏览器每标签持有持久 tabId（sessionStorage——localStorage 同源全标签共享，会令所有标签同 id、隔离归零；sessionStorage 刷新不丢故 F5 保留同会话），随全部 /api 请求上报（X-Tab-Id 头 + SSE ?tabId= 查询串双通道，同鉴权令牌口径），服务端以 Map 按标签多会话并存：未知 tabId 首请求懒建即新标签默认新建会话（不弹选择页，互踩隔离优先；服务端重启后旧标签等同新标签），resume 仍走面板手动入口（只换绑发起标签）；会话事件与审批/提问卡按标签路由、审批挂起 fail-closed 按标签选择性拒绝（ADR-0026；完整多会话协调仍属 1.0 后）。
_Avoid_: 多会话协调（1.0 后的完整形态）、会话隔离（无 OS 级隔离语义）

### 呈现位域

**呈现位插件（Presenter Plugin）**:
CLI 与 Web 的统一形态：Boot 插件自行装配执行链（adapter → 会话 → agent → 治理）、持有自己的会话（独占锁）并注册自己的回答者—— CliPlugin（终端）与 WebPlugin（浏览器）对称，可经 yml 行独立启停（ADR-0011）。
_Avoid_: 宿主内联装配、入口程序

**启动器（Launcher）**:
`DuoMain` 薄壳：`Boot.from(yml)` + 非守护等待 + shutdown hook 级联 dispose——只负责把插件树跑起来并保活，不含任何业务装配；纯 Web 部署的 JVM 存活与 Ctrl-C 的锁释放都由它保证（ADR-0011）。
_Avoid_: main 入口、宿主

**NDJSON 事件流（headless --json）**:
headless 模式 stdout 的逐行 JSON 事件契约：session/status/thinking/text/tool_call/tool_result/error/final 七类，text/thinking 仅在 assistant/message 提交点发射（commit-point），final 帧无损豁免截断，退出码 = turn 结果（completed→0 否则 1，SIGTERM→0、SIGINT→130）；诊断走 stderr、流内禁交互（审批/提问自动 deny + error 帧）（ADR-0025）。
_Avoid_: 日志（事件是对外契约非记录）、SSE 事件流（Web 呈现通道，勿混用）

### 运行环境

**Duo home（~/.duo）**:
duo-harness 的用户级默认目录：会话、配置等运行时数据统一收在其下（解析优先级：系统属性 `duo.home` 测试注入口 > `DUO_HOME` 环境变量重定向 > 缺省路径）。密钥与个人配置放这里，天然不入仓库。
_Avoid_: 工作目录、安装目录

### 计划域

**C1（插入计划）**:
独立于 M 系列编号的临时重点计划：不发版、不走版本分支，按 L1 链（grill → spec → 工单 → 逐单实现）运行；产出按主题归属正常归档（研究产物入 docs/research/，决策入 docs/adr/）。首个实例 C1 = 技能写作体系改造——mattpocock-skills 全库对比分析与 duo 技能改写（以改写为主，分析为改写依据；计划目录 `.scratch/c1-skill-writing/`）。
_Avoid_: 里程碑（M 系列专属——走版本分支并发版）、热修复（代码缺陷修复）

### 会话体验域

**尾部窗口快照（Tail-window Snapshot）**:
首连、刷新、切换会话三场景统一的内容恢复形态：服务端投影后取尾部 N 条消息整窗下发（携 hasMore），更早历史滚动到顶按页向上加载；SSE 增量游标从快照截止处续接（ADR-0013 取代 ADR-0010 的首连全量语义）。
_Avoid_: 全量回放、翻页重载

**会话标题（Session Title）**:
首条用户消息落日志后由 LLM 生成一次的单行标题：`title` 事件进会话日志（latest-wins 投影），LLM 失败降级为首条消息截断；侧栏与浏览器标签页显示。一次自动生成、不随对话自动演进；可经 /title 命令改名（latest-wins 覆盖，ADR-0013 生成语义 + ADR-0020 改名能力）。
_Avoid_: 会话名

**压缩点（Compaction Point）**:
`context/compacted` 会话事件标记的上下文折叠位置：投影以最后压缩点为准，之前以总结替换、之后照常——手动 /compact 与预算自动触发共用同一事件，刷新/回放天然恢复、不重复总结（ADR-0020）。
_Avoid_: 历史折叠（自动压缩的旧口径）、摘要事件

**microcompact（本地裁剪）**:
对话历史逼近窗口时的免模型本地裁剪：治理计量超微缩阈值（压缩阈值的 0.9 折让与 −2000 buffer 取小）时，把「最近 5 组完整对话之外的可压缩白名单工具结果」替换为占位标记（用户/助手文本不动——早期约束不丢），零模型调用；失败结果（`error` 标志）与携带附件引用的媒体结果豁免；名单落 `context/microcompacted` 事件（JSONL 原文完整——模型视角不可恢复、审计视角可回放）；节省低于 256 token 放弃。姊妹机制见「压缩点」（summary 压缩，microcompact 先于它触发）（ADR-0024 M25 节；工单 04）。
_Avoid_: 本地压缩（与 summary 压缩混淆）、上下文删除

**压缩熔断（compaction fuse）**:
summary 压缩连续失败达阈值（3 次，空摘要同计）即熔断：自动压缩静默暂停、会话照常可用，状态面标注「压缩已熔断」；仅成功压缩清零计数，manual /compact 不受熔断约束（用户显式指令优先）（ADR-0024 M25 节；工单 05）。
_Avoid_: 压缩开关、失败重试上限

**cacheControl 断点（cache control breakpoint）**:
对每轮重复携带的稳定前缀打的 provider 缓存标记：anthropic 形态为 system 按三级划分组块（身份前缀 = yml 用户指令首段、稳定身份 = 静态片段）各打 `cache_control: ephemeral` + 末条消息 content 块打动态段断点，块间 \n\n 还原逐字节等价；openai-compat / glm / deepseek 无断点参数（provider 自动前缀缓存，静默享受）；缓存命中经 usage 透出（TokenUsage.cachedTokens——anthropic cache_read_input_tokens / openai-compat cached_tokens / deepseek prompt_cache_hit_tokens），断点失效自然回源无隐性成本（ADR-0024 M25 节；工单 06）。
_Avoid_: 缓存开关、前缀截断

### web 工具族域

**web 工具族（web tool family）**:
联网能力的模型侧工具集合：`web_fetch`（HTTP 抓取 + HTML→Markdown 转换 + SSRF 三道防线）与 `web_search`（搜索 provider 可配，首发 Tavily）。yml 单插件行 opt-in；search 段未配置时工具不注册，部署自动呈 fetch-only 形态（ADR-0021）。
_Avoid_: 联网插件、网络工具（"网络读"是档位类别词条）

**SSRF（Server-Side Request Forgery）**:
服务端请求伪造：模型被网页内容注入指令后诱骗 fetch 访问回环/内网目标。防线三道——URL 字面预检（仅 http/https、拒内嵌账密、限长）、DNS 全地址集逐一验公网（任一非公网整体拒绝）、重定向强制同源且每跳重校验；连接 pinning 不做，校验后重解析的 TOCTOU 窗口记 limitations（ADR-0021）。
_Avoid_: 防火墙、沙箱（duo 无 OS 级边界，审批为界——ADR-0023 出栈决议）

**网络读（network read）**:
`WorkspacePolicy` 的档位类别：fetch/search 等"出网拉取"工具在 `read-only` 档一律 ask（只读语义不出网边界），`workspace-write` 与 `danger` 档放行；独立于本地读集合。URL 查询串的间接外泄通道为已知边界、不设防（ADR-0021）。
_Avoid_: 只读工具、外联权限

**fetch-only（降级形态）**:
search 段无 provider/key 时的部署形态：`web_search` 不注册、模型工具清单只剩 `web_fetch`。配置驱动注册——工具面随配置伸缩，模型永不撞必然失败的调用（ADR-0021）。
_Avoid_: 降级报错、隐藏工具


### 附件与会话工具域

**附件库（attachment store）**:
`~/.duo/attachments/v1` 内容寻址存储：入库规范化后以 SHA-256 硬链接去重、0400 只读、无 GC 永不自动删除；会话日志只存附件引用块不存字节；模型侧唯一写入口是 read_image（先持久化再返回引用）（ADR-0022）。
_Avoid_: 文件上传缓存、临时图片目录

**附件引用块（attachment reference block）**:
user 消息中携带的附件元数据（attachmentId / mediaType / bytes / name）——字节在附件库，日志轻量且向前兼容；Web 渲染走授权读取端点（先验证会话日志确实引用该 id 再回字节）（ADR-0022）。
_Avoid_: base64 内嵌、图片消息

**提及模式（mention mode）**:
@file 的 DSH 同构形态：@path 只是普通文本提及，系统只做补全索引与一段 system 指南（要内容调 read、未 read 不得声称已看过），文件内容永远经 read 工具进上下文——服务端零内容注入管道（ADR-0022）。
_Avoid_: 内容注入、@file 注入

**会话检索（session search）**:
会话 JSONL 的全文检索：索引内容对齐 DSH 清单（消息文本/tool 调用与结果/todo/turn 错误，reasoning 不入）；一期纯 Java 内存倒排懒构建，检索服务接口后端无关、后期转 SQLite（ADR-0022）；模型侧 session_search 工具与 Web 侧栏搜索框两层。
_Avoid_: FTS5（DSH 实现细节）、搜索引擎

### memory 域

**记忆本（memory book）**:
项目级 `.duo/MEMORY.md`（个人记忆，不入 git）承载的跨会话记忆：读路径每轮现读（用户手改/他会话写入下轮即见），内容包 `<memory>` 标签以 user 角色置于请求消息序列最前（meta_user 通道，请求视图专用不落会话日志），预算超限截尾并标注；写路径唯一入口是 `memory_write` 工具（追加式——模型无整文件覆写面，用户手改不被吞），工具调用落会话事件可回放；缺席/为空/读取异常静默降级为零注入——未启用用户零感知（ADR-0024 M25 节；工单 02/03）。
_Avoid_: 长期记忆、知识库、记忆库
