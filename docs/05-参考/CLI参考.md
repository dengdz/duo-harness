# CLI 参考

duo-harness 的命令行面速查：启动参数、REPL 键位、运行中输入行为。斜杠命令的场景讲解见[斜杠命令指南](../02-指南/斜杠命令.md)。

## 启动

fat-jar 入口（或从源码 `exec:java` 指定同一入口类）：

```bash
java -jar duo-harness-<version>.jar [装配.yml]        # 常驻双面（终端 REPL + 浏览器）
java -jar duo-harness-<version>.jar --json <任务文本>  # headless 一次性任务
```

### 启动参数

| 参数 | 说明 |
|---|---|
| `[装配.yml]`（首个位置参数） | 后缀 `.yml`/`.yaml` 且文件存在 → 识别为自定义装配文件；显式写了后缀但文件不存在 → 报错；缺省用内置 `agent-demo.yml` |
| `--json` | headless 一次性任务模式：stdout 输出 NDJSON 事件流，进程退出码即成败 |
| `--session-id <id>` | 仅 headless：续跑既有会话（事件流只推新事件；会话被占或不存在退出码 1） |
| `<任务文本...>` | 仅 headless：其余多词参数拼空格为任务文本，**必需**——缺失时打印用法说明并退出码 2 |

### 常驻模式的行序契约

自定义装配里 **web 行必须排在 cli 行之前**——cli 行的启动即进入 REPL 主循环，其后的行要等 REPL 退出才装载，web 行后置会静默缺席。两道防线兜底：boot 前预检直接点名拒绝（错误带两个行号）；漏网案例由 web 装配期 fail-fast 兜底。

## REPL 键位

| 键 | 行为 |
|---|---|
| Ctrl+C（运行中，单击） | 协作式中断当前任务——已流出内容保留，会话停在可恢复态；提示「再按一次强制退出」 |
| Ctrl+C（运行中，再按） | 强制退出进程（退出码 130） |
| Ctrl+C（空闲） | 退出进程（退出码 0，级联释放资源） |
| Ctrl+D（EOF） | 等价 `/exit`：锁释放、回答者摘除，插件树不受影响；不会腰斩执行中的任务 |
| `/stop` | 协作式暂停的命令形态——SIGINT 不可拦截的环境（如部分管道宿主）用它兜底 |

REPL 为阻塞式行读取：**无方向键历史与行编辑**。

## 运行中输入

agent 执行任务时输入不丢失，按形态分流：

| 你输入的 | 发生什么 |
|---|---|
| 普通文本 | 注入为**插队消息**（终端回显「已插队」），当前步骤边界消费——模型下一步就能看到 |
| 多条文本 | 合并为一条，当前任务收口后立即开新轮 |
| 审批/提问的应答 | 经应答闸门优先路由给等待中的卡片，不当作消息 |

## headless 事件流速查

| 消费点 | 形态 |
|---|---|
| stdout | 逐行 JSON：`session{sessionId,cwd}` 开场 → `status{phase}` 相位 → `tool_call`/`tool_result` 工具过程 → `text` 提交点全文 → `final` 无损答案（消费锚点） |
| 退出码 | 完成→0；迭代上限/异常→1；SIGTERM→0、SIGINT→130；用法错误→2 |
| 诊断 | 只走 stderr——stdout 可直接接 `jq` / `grep '"type":"final"'` 管道消费 |
| 禁交互 | 审批/提问自动拒绝 + 显式 `error` 帧，流程不挂死；超长中间帧截断带 `truncated:true`（final 永不截断） |
