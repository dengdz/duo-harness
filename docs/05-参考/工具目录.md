## 框架内置工具

### ask_user —— 向用户提问

- **来源**：`tools.AskUserTool`（演示入口经交互服务注册）
- **描述**：向用户提问并等待回答。当任务信息不足、存在多种做法需要用户拍板时调用；给出具体明确的问题，可用 options 提供预设选项（用户也可自由输入）。调用会阻塞直到用户回答。
- **参数**：`question`（必填，一句话具体明确）、`options`（可选，预设选项数组；省略表示自由文本）、`multiSelect`（可选，默认 false）
- **无人应答**：fail-closed 收敛为错误结果

### skill —— 按名加载技能指令

- **来源**：`agent.SkillTool`（SkillsPlugin 装配）
- **描述**：按名加载技能的完整指令。当任务匹配某个可用技能的描述时调用；调用后会返回该技能的指令内容，请严格遵循执行。
- **参数**：`name`（必填，技能名；可用技能见系统提示里的技能清单）

### exit_plan_mode —— 呈交计划

- **来源**：`agent.ExitPlanModeTool`（演示入口装配）
- **描述**：呈交计划等待用户批准。仅在计划模式下、完成完整设计后调用；参数 plan 为完整计划（markdown）。用户批准后立即开始执行；被要求继续时按用户反馈修改计划后再次呈交。
- **参数**：`plan`（必填，完整计划 markdown）
- **无人应答**：fail-closed——计划不批准，保持计划模式

### todo_write —— 维护任务清单

- **来源**：`agent.todo.TodoWriteTool`（呈现位装配注册，ADR-0018）
- **描述**：维护本轮任务的执行清单。每次调用发送完整清单——它整体替换上一次的清单（没有部分更新，也没有逐项编辑）。多步任务开工前先拆清单（每个具体步骤一条祈使句）；平凡的单步任务不必使用。开工即把该步标记为 in_progress（并行执行多个任务时可有多项同时进行中）；每完成一步就立即重新调用本工具、把该步标记为 completed，不要攒到最后一次性批量更新。
- **参数**：`todos`（必填，完整清单数组；每项 `content` 一句祈使句 + `status` 三态 pending / in_progress / completed）
- **回显**：计数文本（"X 待办 / Y 进行中 / Z 已完成"）——完整清单只走 `todo/write` 事件给呈现面，不回流模型
- **校验**：content trim 后非空且不重复；status 枚举外拒绝
- **执行形态**：独占工具（不进并行池）

## fs 工具族六件（fs-tools 插件）

`FsToolsPlugin` 注册的本地文件与命令工具：路径受 workspace 约束（ADR-0012），权限由三档预设裁决（read-only / workspace-write / danger-full-access，yml `mode` 配置默认档，CLI `/permission` 运行时切换）。读前写闸门：会话内 read 过的文件才允许 write/edit 覆盖（新建豁免）。

### read —— 读取文件

- **来源**：`tools.fs.FsReadTool`
- **描述**：读取文件内容（带行号）。大文件用 offset/limit 分段读取。不适用于二进制文件。
- **参数**：`path`（必填）、`offset`（起始行号，1 起始，默认 1）、`limit`（最大行数，默认 2000）
- **执行形态**：并发安全（进并行池，ADR-0018）

### write —— 写入文件

- **来源**：`tools.fs.FsWriteTool`
- **描述**：写入文件内容（覆盖已有或新建）。覆盖已有文件前须先用 read 读取（读前写闸门）。
- **参数**：`path`（必填）、`content`（必填，空串=清空文件）
- **审批**：声明需审批，按档位裁决（原子替换写入）
- **执行形态**：独占（读前写闸门的已读集合是会话级共享状态，ADR-0018）

### edit —— 精确替换

- **来源**：`tools.fs.FsEditTool`
- **描述**：精确替换文件中的字符串。old_string 必须在文件中唯一匹配（或设 replace_all 全部替换）。使用前须先用 read 读取文件。
- **参数**：`path`、`old_string`、`new_string`（均必填）、`replace_all`（默认 false）
- **审批**：声明需审批，按档位裁决
- **执行形态**：独占（读前写闸门的已读集合是会话级共享状态，ADR-0018）

### glob —— 按模式搜文件名

- **来源**：`tools.fs.FsGlobTool`
- **描述**：按 glob 模式搜索文件（如 **/*.java）。返回按修改时间倒序排列的文件列表。跳过 .git 等版本控制目录。
- **参数**：`pattern`（必填）、`path`（搜索起始目录，默认 workspace 根）
- **执行形态**：并发安全（进并行池，ADR-0018）

### grep —— 按正则搜内容

- **来源**：`tools.fs.FsGrepTool`
- **描述**：按正则表达式搜索文件内容，命中输出为 路径:行号:文本。跳过含 NUL 的二进制行与 .git 等版本控制目录。
- **参数**：`pattern`（必填）、`path`（搜索起始目录，默认 workspace 根）、`include`（文件名 glob 过滤，如 *.java）
- **执行形态**：并发安全（进并行池，ADR-0018）

### bash —— 执行命令

- **来源**：`tools.fs.FsBashTool`
- **描述**：执行 shell 命令（bash -c，每次调用全新进程，工作目录为 workspace 根）。返回输出与退出码——非零退出不算错误。timeoutMs 指定超时（默认 120s，上限 600s）。
- **参数**：`command`（必填，bash -c 语义）、`timeoutMs`（超时毫秒，默认 120000，上限 600000）
- **审批**：声明需审批，按档位裁决（非 danger 档一律 ask——bash 的写范围不受 workspace 约束）
- **输出语义**：stdout 原样、stderr 带 `[stderr]` 标题；`[exit code: N]` 标记退出码；超时终止进程树并标 `[timed out]`；单流超 100000 字符截断并报省略量（内存护栏，大而正常的输出由治理层 spill 落盘可回读）；命令退出而流仍被后台进程持有时标 `[output may be incomplete]`；stdin 接空设备（读 stdin 的命令立即 EOF，不挂到超时）

## web 工具族（web-tools 插件，M20 ADR-0021）

`WebToolsPlugin` 注册的联网工具：fetch 恒注册；config `search` 段非空且 key 有解（`apiKey` 字面量 → `TAVILY_API_KEY` 环境变量兜底）才注册 web_search——无 key 部署呈 fetch-only 形态（工具面收缩，模型永不撞必然失败的调用）。SSRF 三道防线：URL 字面预检（仅 http/https、拒内嵌账密、限长 2048）→ DNS 全地址集公网校验（任一地址非公网整体拒绝）→ 重定向同源强制且每跳重校验（上限 5 跳）。结果头行带最终 URL 与 HTTP 状态码，正文前有不可信数据声明；非 2xx 是结果不是错误。权限按网络读档位：read-only 档 ask，workspace-write / danger 档放行（ADR-0021 决策 8）。

### web_fetch —— 抓取网页

- **来源**：`tools.web.WebFetchTool`
- **描述**：抓取指定 http(s) URL 的网页内容，返回干净的 Markdown 正文（自动剔除脚本、样式等不可见部分）。用于阅读文档、文章、README 等网页；返回头行携带最终 URL 与 HTTP 状态码。仅允许公网目标，内网/回环地址与跨源重定向会被拒绝。
- **参数**：`url`（必填，公网 http(s) 地址）
- **执行形态**：并发安全（进并行池，ADR-0018）
- **边界**：仅文本/HTML/JSON/XML（PDF/图片/未知字符集拒绝）；HTML 嵌套超 512 层返回占位符；三层限额（响应体 5MB / 正文 100k 字符 / 输出 200k 字符）；超时 30s（均可配）

### web_search —— 全网搜索

- **来源**：`tools.web.WebSearchTool`（`tools.web.TavilyProvider` 后端，首发 provider）
- **描述**：用关键词搜索全网，返回标题、链接与摘要列表。用于查找资料来源、核实信息；对感兴趣的条目再用 web_fetch 抓取全文。
- **参数**：`query`（必填，搜索关键词）
- **执行形态**：并发安全（进并行池）——多路搜索由模型并行多调用
- **边界**：结果上限 8 条（可配）；空结果明示 No results found.；限流等 provider 错误原文透出

## 会话检索工具（session-query 插件，M21 ADR-0022）

`SessionQueryPlugin` 行 opt-in：行在场即发布 sessionQuery 服务（Web 侧栏搜索框数据源），tools 服务在册时注册本工具（模型侧）。内存倒排索引懒构建（首次搜索才扫会话目录 + mtime 增量刷新），启动零成本、不装零感知；检索服务接口后端无关（后期可转 SQLite）。读 harness 自身会话日志——不经 workspace 三档，不声明审批。

### session_search —— 会话历史检索

- **来源**：`sessionquery.SessionSearchTool`（session-query 插件装配）
- **描述**：按关键词搜索历史会话，返回命中的会话（标题与更新时间）及最强匹配的事件摘录。用于回答“上次讨论过 X 吗”这类对历史内容的查找；引用结果时注明会话 id。
- **参数**：`query`（必填，搜索关键词；可中英混排，多词为与关系）
- **执行形态**：并发安全（进并行池）
- **边界**：命中上限 8（插件 `maxResults` 可配）；索引内容为消息文本 / tool 调用名与参数 / tool 结果 / todo 内容项 / turn 错误——reasoning 与治理事件不入索引；子代理会话（subagents/ 子目录）不索引；snippet 命中词以【】标记；空结果明示 No results found.

## MCP 远端工具（机制说明）

MCP 远端工具以 `mcp__<server>__<tool>` 命名注册进工具域，随连接增删自动同步——挂一个 MCP 服务器连接即接入，无需注册代码。agent demo（agent-demo.yml）装配仅本机工具族（消除双写工具选型噪音）；机制演示在 demo-m2.yml（DemoMain 的 M2 段：迷你 filesystem 服务器 + 写保护治理插件——对 `mcp__files__write_file` 声明 ask、涉密文件 guard 拦截）。
