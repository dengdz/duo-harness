# 会话事件类型表

> 状态：对齐 SessionEvent / Session 源码（M8 收官版）。会话是事件溯源日志：`append` 唯一写入原语、JSONL 同步落盘、`deriveMessages` 投影多轮上下文。本文是全部事件类型的字段与投影规则速查；机制叙事见[设计主线](../04-架构/设计主线.md)。

## 字段

JSONL 每行一个事件对象（Jackson 统一读写）：

| 字段 | 类型 | 出现于 | 说明 |
|---|---|---|---|
| `type` | string | 全部 | 事件类型（见下表），必填 |
| `at` | long | 全部 | 毫秒时间戳，必填 |
| `text` | string | 全部 | 载荷文本（语义随类型而定），必填 |
| `toolCallId` | string | 工具事件 | 调用/结果关联键（协议要求回传），可空 |
| `toolName` | string | 工具与审批事件 | 工具名，可空 |
| `reasoning` | string | tool/call | 思考内容（思考模型多轮链要求回传），可空 |

## 类型表

| type | 载荷 text | 产生者 | 投影 |
|---|---|---|---|
| `user/message` | 用户输入完整文本 | agent 循环每轮入口 | ✅ 入列 USER |
| `assistant/chunk` | 流式增量片段（可空串） | LLM 适配器 | ✗ 过程细节，不入列 |
| `assistant/message` | 全部 chunk 拼接的最终文本 | agent 循环每轮收尾 | ✅ 入列 ASSISTANT |
| `tool/call` | 参数 JSON | agent 循环 | ✅ 入列 assistant.toolCalls（携 toolCallId/toolName/reasoning） |
| `tool/result` | 结果文本（失败为错误说明） | 三段管线执行回填 | ✅ 入列 tool（携 toolCallId） |
| `approval/requested` | 参数摘要 | 审计桥（审批类 ask 前置） | ✗ 审计事件 |
| `approval/decided` | `allow/deny（回答者: 来源）` | 审计桥（ask 后置） | ✗ 审计事件 |
| `plan/mode` | entered / exited | 计划模式进出 | ✗ 状态标记（续接时恢复模式） |
| `run/error` | 错误消息 | Web 面（运行异常） | ✗ **直推帧：不落会话**，仅 SSE 通道呈现 |

## 投影规则

- 入列三类：`user/message`、`assistant/message`、成对的 `tool/call` + `tool/result`（无 `toolCallId` 的旧格式工具事件跳过——向后兼容）
- 不入列：流式 chunk、审批审计、plan/mode——它们是过程与审计细节，回放时可见、进模型上下文时不可见
- 读取端：`Session.load` 重放历史（旧格式向后兼容）；`Session.events()` 返回调用时刻快照（流式追加期间并发遍历安全）

## 消费方

| 消费方 | 读什么 |
|---|---|
| 多轮记忆 | `deriveMessages()` 投影为模型上下文（含 toolCalls 与 reasoning 回传） |
| Web 页面 | SSE 实时推送 + 回放：首连全量快照，断线重连按 `Last-Event-ID` 游标只补缺失段（`replay/start` 标注模式、`replay/done` 边界帧区分回放与实时） |
| 人类排查 | JSONL 逐行可读——"消息落在哪个会话"以文件为准 |
