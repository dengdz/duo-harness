# Web 界面使用说明

浏览器呈现位（`web` 装配行启用，缺省端口 18080，只绑本机回环）的每个界面区块——是什么、怎么操作、何时出现。功能场景的步骤讲解见各[指南](../02-指南/权限与审批.md)。

## 打开页面

启动日志打印带令牌的地址，形如 `http://127.0.0.1:18080/?token=...`（缺省随机令牌鉴权，校验失败一律 403）。令牌鉴权可用 `web.auth: none` 显式关闭（页面会横幅警示）。

## 三区布局

左侧**会话侧栏**、中间**对话流**、右侧**状态面**。

## 会话侧栏

| 元素 | 说明 |
|---|---|
| 「＋ 新话题」 | 新建会话——只建内存态不发请求；发出第一条消息才落盘，之前不产生会话文件 |
| 会话列表 | 真实存在的会话（标题或 id）；当前会话高亮，标题超宽右缘渐隐、悬停走马灯滚动 |
| 状态点 | 当前会话运行中转圈；被其他进程占用的会话显示灰色「使用中」点 |
| 搜索框 | 按关键词搜历史会话（命中带【】摘录，点击直达；只搜当前工作目录的会话）——见[导出与检索](../02-指南/导出与检索.md) |
| 标签页标题 | 跟随当前会话标题（每标签绑定自己的会话） |

## 消息流

| 元素 | 说明 |
|---|---|
| 用户气泡 | 右肩圆角样式；附件（图片）以缩略呈现 |
| 打字机正文 | 回复流式逐字呈现（标题/列表/代码块边流边成形），收口后整段 Markdown 渲染 |
| 代码高亮 | 代码块按语言着色（流式期即逐步上色） |
| 工具卡 | 按工具类型分型：**终端卡**（`$ 命令` 盒，限高滚动）、**编辑卡**（行级 diff：删红增绿 + `+N -N` 徽标）、**文件卡**（类型图标 + 文件名 + 「格式 · 目录」副标题）、**技能卡**（✨ 技能名 + 参数 + 加载内容预览）；未分型工具回退通用卡（⟳ 运行中 → ✓/✗，结果可折叠） |
| 参数摘要 | 工具卡显示关键参数摘要，原文折叠可查（不再整段 JSON 铺开） |
| 思考折叠卡 | 思考模型收口后出现「💭 思考过程」（默认收起，点开全文）；流式期是吸底跟随的「💭 思考中…」实时卡 |
| 产物预览卡 | 回复定稿时自动提取产物型文件路径（md/html/office/pdf/图片/音视频等，上限 10 张）成卡——类型图标 + 复制路径按钮，挂气泡之后 |
| 附件读取卡 | `read_image` 读图后以图片部件渲染 |

## 交互卡（需要你拍板时）

| 卡片 | 出现时机 | 操作 |
|---|---|---|
| 审批卡 | 工具需要审批 | 批准 / 拒绝（可附理由）/ 总是允许（项目）/ 仅本会话——语义见[权限与审批](../02-指南/权限与审批.md) |
| 提问卡 | 模型主动提问（ask_user） | 预设选项点选（可多选）或自由输入 |
| 计划呈交卡 | 计划模式下模型交方案（exit_plan_mode） | 批准开始执行 / 打回并附反馈 |

卡片规则：谁发起谁优先作答（终端发起的审批不会跳到浏览器 Silent）；页面刷新后悬空卡片保留可答；全部页面关闭且宽限期内无人接手 = 按拒绝处理。

## 状态面

五分区可折叠（长表默认收起）：

| 分区 | 内容 |
|---|---|
| 上下文 | `N / 窗口 tokens（占比 %，压缩阈值）`——与治理判定同源，超阈值变红 |
| 插件 | 六态表（PENDING/LOADING/ACTIVE/UNLOADING/FAILED/DISPOSED）——装配行与实例状态实时核对 |
| 工具 | 本机 + MCP 远端工具清单 |
| 连接器 | MCP 连接状态（CONNECTED / BACKOFF / GAVE_UP 标红） |
| 会话 | 当前会话信息 |

## 刷新与容错

- 刷新/重连：首屏重建为最近 50 条的尾部窗口，更早历史滚动到顶向上翻页；
- 运行中点【停止】（发送按钮变身，危险色）= 协作式中断：已流出内容保留、中断标记可见，再发消息即续接；
- 执行中再输入 = 注入插队（与终端同语义，回显「已插队」）；
- 服务故障：页面顶部红色提示（5 秒自动消失），不静默。
