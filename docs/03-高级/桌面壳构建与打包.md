# 桌面壳构建与打包

> 本文对齐 1.3.0，教程体裁。读者定位：**想构建或打包 duo 桌面端（macOS）**的开发者。桌面壳的能力面与裁定见 [ADR-0039](../adr/0039-M37桌面端立项决策.md)；参考实现研究见 [DSH/ZCode 桌面端研究](../research/ZCode/呈现与UI/桌面端.md)。

## 形态一句话

Electron 壳（`desktop/`，TypeScript）承载现有 Web 呈现位：壳拉起 Java 后端 fat-jar 子进程（选空闲端口经环境变量注入、读 stdout 锚点行拿启动地址）、开窗直连本机回环地址加载 Web UI，托盘常驻 / 系统通知 / `duo://open` 深链 / 退出前探活确认 / 崩溃自动恢复。**后端与 CLI/Web 共用 `~/.duo`**（同一套装配、会话与插件），桌面是 Web 呈现位的桌面载体，不是新呈现位。

## 启动（日常使用）

```bash
cd desktop && npm install && npm start
```

一条命令完成构建并起壳（托盘常驻、关窗隐藏、深链/退出探活等全能力）。装配沿用 `~/.duo/plugins.yml`（与 CLI/Web 同一份，桌面不改装配）；cli 行在场的 REPL 会阻塞等待输入（桌面壳保持其 stdin 打开——详见[已知限制](../limitations.md)），纯桌面用户可删 cli 行。

## 构建（改码后重编译）


前提：Node 18+ 与 JDK 21（壳启动时自动探测，缺失弹指引）。

```bash
# 后端 fat-jar（壳的拉起目标；dev 态读 duo-harness-example/target/ 下最新 jar）
mvn -pl duo-harness-example -am package -DskipTests
# 壳工程依赖安装 + 构建
cd desktop && npm install && npm run build
# 开发态直起（命令行起壳 = 得到一个完整可用的 duo）
npm run dev
```

装配沿用 `~/.duo/plugins.yml`（与 CLI/Web 同一份，桌面不改装配）；cli 行在场的 REPL 会阻塞等待输入（桌面壳保持其 stdin 打开——详见[已知限制](../limitations.md)）。纯桌面用户可删 cli 行。

## 自动化验收（--smoke）

```bash
npm run smoke
```

一条命令走通全链断言：拉起 → 窗口 → 关窗拦截隐藏 → 通知桥门控双态 + 真通知 → 单实例二次启动即退 → `duo://open` 唤起 → kill 后端崩溃恢复 → 原窗重连。任一断言失败非零退出；截图落 `DUO_DESKTOP_SMOKE_OUT` 指定路径。
