# 会话尾部窗口快照与分页范式：三场景统一恢复、无刷新切换与会话标题

Status: 批准（2026-09-15，M13 grill 裁定）

0.7.0（M12）后会话体验的三处缺口：首连/刷新仍走**全量快照回放**（大传输 + 前端全量 DOM，大会话首屏慢）；切换/新建会话靠 `location.reload()` 整页重载；侧栏列表只有裸会话 id（无占用提示、无标题语义）。本决策引入 DSH journal-stream 式的尾部窗口快照范式统一三场景，并附带治理阈值 yml 化、侧栏占用标注与会话标题生成。关键事实前提：**治理四件套是纯读侧的**（只影响模型看到什么，会话 JSONL 日志永远完整）——因此分页锚点可以直接用稳定的日志事件序号，不存在"折叠改写下标"的对齐问题。

## 背景

路线图 M13（会话体验，★★）。现状盘点：① SSE 首连与游标越界走全量快照（ADR-0010 游标只覆盖断线重连的增量段），80K+ token 会话刷新的瓶颈在传输量与 DOM 节点数，不在服务端投影（`deriveMessages()` 内存投影毫秒级）；② 切换/新建的 `location.reload()` 在 app.js 两处（499/550）；③ `/api/sessions` 无占用信息，撞锁只能点了才知道；④ 侧栏显示 `20260915-174057-8567` 形态的裸 id。DSH 精查：尾部 N 条快照（`PAGE_MESSAGES=50`）+ 向上分页 + 不持久化游标，一套机制覆盖首连/刷新/切换三场景。

## 决策

1. **尾部窗口快照范式**：首连、页面刷新、切换会话三个场景统一走同一条路径——服务端投影后取**尾部 50 条消息**整窗下发（携 `hasMore`），前端整窗替换；SSE 增量回放机制（ADR-0010 的连接层游标）**原样保留**，快照截止处即游标续接点。ADR-0010 不修改，本范式以新 ADR 取代其"首连全量"语义。
2. **分页单位 = 投影后消息**：`deriveMessages()` 正向投影后取窗（每次请求全量投影，内存毫秒级——`events()` O(n) 拷贝的优化 S4 留 M14）。窗口参数 **50/50 常量起步**（快照 50、每页 50），不进 yml——页长是实现细节，进配置即承诺契约。
3. **向上加载 = 滚动到顶自动触发**：顶部占位显示"更早还有 N 条"，加载后视窗位置保持不跳屏，`hasMore=false` 后占位消失。
4. **切换/新建无刷新**：前端主动断开 SSE → 调端点换绑 → 重连 SSE 收尾部快照 → 整窗替换。`location.reload()` 删除——三场景没有特例。
5. **治理阈值 yml 化**：`web` / `cli` 插件 config 各加可选 `governance` 段（四阈值 + 保留比 + 最小折叠数，字段可省回退内置缺省）。配置跟随消费者；**双开装配两段配置的漂移是已知取舍**，以验收清单提醒兜住。独立 governance 插件行被否（配置载体不值得一个服务）。
6. **侧栏占用标注**：`/api/sessions` 逐会话探测锁状态（tryLock，列表短成本可忽略），新增 `occupied` 字段；侧栏灰显 + "使用中"角标。点击仍允许——撞锁报错的明确语义保留，标注只提供预期。
7. **会话标题（精简版）**：首条 `user/message` 落日志后异步生成一次——独立直答小请求（非流式、关 thinking、超时 + 输出上限），标题以 `title` 事件追加进会话日志（latest-wins 投影）；LLM 失败/超时降级为首条消息前 20 字截断。侧栏显示标题（无标题回退 id），同时用作浏览器标签页标题。**不做**随对话演进重生成与用户改名钉住（DSH 的 revision/supersede 并发机制是复杂度大头，后续按需加）。标题生成不走工具循环与审批，不阻塞对话。
8. **验收硬指标**：80K token 会话刷新 < 2s（防"做着做着又全量了"的回归）。

## 拒绝的选项

- **/compact 手动压缩进 M13**：compaction 是读侧重算、无持久化，手动压缩要有意义必须把折叠结果落进会话日志（新增事件类型，动事件溯源模型）或引入会话级状态——语义重量与本里程碑不匹配；其天然归宿（斜杠命令注册表）在 M16。出局，backlog 改记。
- **按原始事件分页**：省投影但要发明"从尾部倒推消息边界"的机制（半截消息问题），且事件粒度与页面形态脱节；DSH 也是消息粒度。
- **分页参数进 yml**：见决策 2。
- **独立 governance 插件行**：配置载体撑不起一个服务；web/cli 是治理的实际消费者，配置跟随消费者更直觉。
- **session-title 完整版**（演进重生成 + rename 钉住）：需要 revision + supersede 的并发防覆盖机制，M13 体量膨胀；精简版覆盖主要价值（侧栏可读）。
- **切换保留 reload 作特例**：为切换单留一套机制，三场景分叉——统一尾部快照后 reload 无存在理由。

## Consequences

- ADR-0010 保持原文不动（连接层游标仍有效）；首连语义的"全量快照"由本文取代——前端快照重建逻辑按尾部窗口改写，被截断历史由向上分页承接。
- `web` / `cli` config 增可选 `governance` 段；双开装配的两段一致性进验收清单。
- session 域新增 `title` 事件词汇（投影 latest-wins）；`/api/sessions` 新增 `occupied` 字段；会话切换由整页重载变为 SSE 重连整窗替换。
- 前端新增：向上分页 UI（滚动触发 + 位置保持）、侧栏标题与占用灰显、浏览器标签页标题。
- 已知限制（进 limitations）：① 会话标题一次生成不随对话演进，不可手动改名（后续按需）；② 分页请求的服务端投影仍为全量（S4，M14 优化）；③ 分页页长为常量不可配。
- /compact 连同"折叠持久化"语义改记 backlog，归 M16 命令注册表。
