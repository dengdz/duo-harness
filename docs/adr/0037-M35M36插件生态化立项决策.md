# M35/M36 立项决策：插件生态化——信任模型定盘与两期版图

Status: 批准（2026-10-03，/grill-with-docs 十一问逐题裁定，共识纪要经用户确认后落盘；1.0 后轻量里程碑制第三期 M35、第四期 M36）

## 背景

1.0.1 已发（M34 收口），1.0 后轻量里程碑制运转中。生态化诉求三点：Web 页面开放插件中心（安装/启停/替换第三方插件）、呈现层可被插件改写（换肤到重写页面）、槽位级替换（"哪个插件不如意就换上自己的"）。这套诉求与既有机制的差距经探底核实为四块：jar 级装载缺失（已知限制 #4 预留扩展点未启用）、运行期管理面缺失、呈现层封闭（端点与卡片渲染在内核独占面）、分发与信任机制空白。

版图对账：CHANGELOG 实发 1.0.1（tag 在）；本立项是 1.x 首批新功能期，按「新功能进次版本」承诺定 M35 = 1.1.0、M36 = 1.2.0，无错位。

排他对账（存量账随案处置）：销账两条——已知限制 #4「独立 jar 热加载不可用」（本 ADR 启用其预留的 child Classloader 扩展点）、backlog「工具名协议化渲染」（入 M36）；改写一条——已知限制 #1「运行时行级配置热重载不可用」（收窄为"配置字段热编辑仍需重启或停-改-启"）；显式续挂两条——会话事件桥（M27 论证归 1.0 后）、llm/session 服务化（决策一记案）。

事实底座：根 Context 由装配层（DuoMain）持有；`ctx.plugin()` 与作用域 dispose 是公开 API，六态容器已具备"提供方消失→依赖方回落 PENDING、服务回归→自动重载"的运行期插拔语义（ADR-0019 依赖指纹）——管理面是编排层缺口，不是容器缺口。

与 ADR-0001 的关系：装载模型自「同 classpath + 配置声明」扩为「classpath + 插件包目录」。这是启用 ADR-0001 预留、已知限制 #4 在案的扩展点，不是推翻——容器六态、服务注册表、视图接口纪律全部承袭不变。

## 决策（grill Q1-Q11，五组）

### 一、信任模型与治理边界（Q1/Q2/Q9）

自用 + 熟人圈起步：同进程加载，装前点名确认，签名/策展/兼容校验后补不堵死（Q1）。approval 策略槽位对第三方开放——风险等价用户自切全开放档，属显式选择；guard 单调否决、规则 deny 恒优先、审批 fail-closed 三道内核闸门不随槽位替换放松，文档明示风险自担（Q2）。llm 与 session 维持内核独占（装配期构造直连、不走服务注册表）：换模型主诉求 `/model` 已覆盖、llm 装饰链透传教训（M29 经验档）在前、session 与独占锁/事件流耦合深——在此显式记案防反复（Q9）。

### 二、装载与装配（Q3/Q4/Q5/Q10）

安装通道 = 目录扫描（`~/.duo/plugins/`），Web 零新增攻击面，不做上传端点（Q3）。交货格式 = 插件包（fat-jar 单文件，依赖全打入），每包独立类加载器、插件间类互不可见；卸载 = 容器拔除 + 类加载器丢弃，泄漏时页面标"需重启生效"兜底（Q4）。状态账本 = 一切操作写回 plugins.yml（装 = 新行带插件包来源字段、停 = `disabled`、卸 = 删行），单一事实源（Q5）。热重载档位 = 结构操作（装/停/卸/启用/换槽位实现）运行期热生效；配置字段编辑对无状态插件走"停→改→启"向导（受控拔了重装，六态自动善后依赖方），拔不得的插件（cli 呈现位等——apply 即 REPL 主循环，M27 实测在案）提示重启生效；已知限制 #1 按此收窄改写（Q10）。

### 三、管理面（Q6）

插件中心 = 独立插件模块（生态基建自举——它自己就是"第三方插件形态"的旗舰示范）。内核开两个受控口：①运行期行级控制（按 id 装载/拔除——六态机制现成，只开门不加机制）；②Web 端点命名空间贡献口（申请制前缀，如 `/plugins/center/**`）。CLI `/plugin` 命令本期不做，后续消费同一插件服务即可。

### 四、呈现层（Q7）

M36 做两台阶：主题 token 换肤 + 工具卡片声明式模板（销账"工具名协议化渲染"）。插件自带页面（静态资源服务、同源隔离）与整页替换（第三方呈现位身份）本期明确不做，后续期另立项。

> 勘误注（2026-10-03，ADR-0038）：M36 立项细化并扩充本节——范围并入「Web 页面全视觉 pass」（含插件中心抽屉精修），主题/卡片的开放面、交付形态与贡献通道八项裁定见 ADR-0038。

### 五、范围与版图（Q8/Q11）

会话事件桥本期不做、继续挂账——隐私声明分级（"此插件可读会话内容"类）与事件回放/背压机制值得单独一期做透。两期定盘：**M35 = 生态链路闭环**（内核两口、插件包装载器、插件中心插件、Web 内置插件中心页、tool-stats 示例插件包化改造、文档），落 1.1.0；**M36 = 呈现层**（换肤 + 卡片模板），落 1.2.0。

## 拒绝的选项

- **公开生态一步到位（签名/校验和/兼容校验/策展审核）**：工程量数倍且必须先做契约版本化；自用 + 熟人圈下装前点名已兜底告知义务，机制后补不堵死。
- **进程级隔离（插件独立进程 IPC）**：同进程插件 API 全部失效、扩展模型重写，与 ADR-0023 沙箱出栈立场相逆。
- **页面上传安装**：新增"往进程加载任意代码"的 HTTP 端点，令牌泄露或 `auth: none` 下局域网内任何人可装代码，与 M24 fail-closed 方向相逆。
- **lib 目录式依赖解析**：需版本冲突仲裁（OSGi 级复杂度）；fat-jar 重复库的内存代价在自用规模可忽略。
- **插件间类互见**：引入加载顺序与被依赖方卸载的级联问题，留作生态后期演进。
- **独立 installed.json 状态文件**：两本账的合并优先级/行序/重名全是新坑，排查要跑两个文件。
- **管理面全做进 Web 域**：绑死 Web 呈现位、CLI 面将来重写，"插件扩展 Web"架构题只是推迟。
- **内核管到底（Context/Boot 加管理 API）**：编排逻辑下沉内核，违背"内核小、编排在上"分层。
- **全量热重载（配置一改自动拔-改-装）**：机器判定"哪些插件此刻不可拔"与拔装间隙的依赖方震荡防不胜防，一期背不动。
- **插件自带页面/整页替换入本期**：资源服务、同源隔离、呈现位身份契约是独立里程碑体量。
- **会话事件桥入本期、llm 服务化**：见决策一、五。

## Consequences

- 分支 `1.1.0` 于 M35 启动（/to-spec 拆工单后）自 main 切出，开发提交不落 main（红线 7）；M36 届时切 `1.2.0`。
- 存量账处置随对应期工单同 diff 执行：已知限制 #4 销账、#1 收窄改写（M35）；backlog 协议化渲染销账（M36）。
- 文档义务两条：面向用户文档明示信任模型边界（自用 + 熟人圈，非策展分发——装插件 = 装任意代码）；approval 槽位可换的风险自担声明（对齐 ADR-0019 hooks fail-open 的文档义务先例）。
- 术语表同 diff 入册：插件包、插件中心、装前点名；内核独占面词条同步改写（端点贡献口、治理闸门、llm/session 独占显式化）。
- 扩展点清单「内核独占面」节随 M35 工单增补治理三闸门行与贡献口行。
- spec 阶段待定细节（非悬置——/to-spec 时定点处理）：插件包入口类声明方式（manifest 或 yml 字段）、装前点名的信息面（类元数据零副作用读取范围：inject / optionalInject / configType）、插件中心页面交互、Web 内置页 tab 命名。
