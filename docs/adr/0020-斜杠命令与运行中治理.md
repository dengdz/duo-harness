# 斜杠命令与运行中治理：命令注册表、呈现位亲和路由、父级 steer

Status: 批准（2026-09-19，M19 grill 八题裁定；范围预定义于 ADR-0016，本文立落地语义）

M18（0.13.0）发布后，交互债集中清账：Web 输入框不识别斜杠（M12-03 验收第 8 步事故——`/permission` 透传进模型历史）、CLI 发起的审批跳 Web 卡片终端零提示（M12-02 验收第 6 步事故）、/compact 无手动入口（M9-M11#3）、权限档切换不持久（M12#3）、标题不可改名（M13#1）、页长硬编码（M13#2）、父级运行中纠偏缺位（Web 409 单飞，与子代理 send_message 语义不对称——ADR-0016 拒绝项所记）。九件事共享一个地基：命令目前只是 CLI replLoop 里的私有 if-else，没有域级抽象。本文记录 grill 八题的落地裁定。事实基础：DSH 命令体系研究（`ctx.commands` 插件代码注册、直接作用不进模型历史、`command/run`+`command/done` 审计——研究笔记一行机制描述，API 细节未展开）、duo 现状考古（WebFace 对输入零识别、InteractionRegistry 注册序全局路由、WorkspacePolicy volatile 单口、ToolCallingAgent 循环无注入点、SessionEvent 无压缩事件、治理管线 compaction 为请求期变换且结果不落盘）。

## 决策

1. **统一命令注册表**：agent 域发布 "commands" 服务（保留裸名，与 prompts/skills 同居），插件代码注册（DSH 同款；拒绝 markdown 文件定义）。注册 API 沿仓库惯例 `register(registrant, definition)`——注册即注册方作用域 effect，插件停止自动摘除。CLI 的 /new、/permission、/plan、/exit 从 replLoop if-else 迁移为注册调用。
2. **命令形状**：name + description + 适用呈现位（ANY/CLI/WEB，缺省 ANY）+ busySafe（缺省 false，fail-closed）+ handler。handler 收统一命令上下文（参数文本、当前会话供给、回显通道、发起呈现位标记、请求结束回调），同步执行于呈现位进程内、返回文本结果；不占 agent 单飞窗口。需要退出循环的命令经上下文回调表达，不为它开特殊返回通道。
3. **入口顺序**：命令注册表 → 技能直调（指令前缀注入、进模型历史）→ 未知命令报错附可用清单。技能与命令两张表保持平行：语义分界 = 进不进模型历史（技能是"替用户说话"，命令是"操作 harness"）；术语表技能词条 Avoid"命令"的边界由此成立。
4. **busySafe 分级**：agent 执行（单飞占用）期间的输入，busySafe 命令立即执行回显（如 /permission 查看与切档——volatile 治理态读写天然并发安全，下一个工具调用即按新档判）；非 busySafe 得到明确"执行中，需等待空闲"回应（Web 409 的命令专用版）。缺省 false：说不清就别在运行中动。
5. **审计两事件 + 投影排除**：`command/run`（名 + 参数）与 `command/done`（结果）落会话日志（崩溃断口可观测，与 M16 悬空闭合同哲学）；deriveMessages 投影忽略该类型——"不进模型历史"由投影纯函数保证；Web 渲染轻量命令行（刷新/回放可见），CLI 即时回显；不参与 tool 配对算法、不占消息窗口计数——M10 游标 / M13 尾窗 / M16 闭合零牵动。
6. **/compact 持久化**：新增 `context/compacted` 事件（总结文本 + 压缩范围）；投影 = 最后压缩点之前以总结替换、之后照常（latest-wins 家族，与 todo 同款）；busySafe=false；**自动压缩同事件化**——一处语义两处触发（手动 /compact 与预算触发），消除"同一种变换两种事实地位"的分裂；刷新/回放天然恢复、不重复总结。
7. **呈现位亲和路由**：ToolExecution 新增 presenterId 只读字段（呈现位构造 agent 时注入、执行时携带）；ask 请求携发起方，InteractionRegistry 路由 = **发起方回答者优先，缺席/放弃才轮注册序**（单呈现位部署零感）；limitations 遗留"交互工具会话绑定先到先得"顺手同修——交互工具的会话供给按发起方亲和；hooks 载荷顺带可携 presenterId（M18 backlog"钩子载荷上下文透传"部分消化）。
8. **父级 steer 单一语义**：Web 移除 409——运行中用户消息进 agent 注入收件箱（并发队列），send 循环在迭代边界（一轮工具执行完、下一轮请求构造前）排干：落普通 `user/message` 再构造请求。不发明 steer 专属事件（对话流本就是用户的话，投影零特判、"说的时机"=事件位置天然可审计）；不打断飞行中工具组；多条照排；Web UI 轻提示"已注入，待当前步骤完成"。与子代理 send_message 的"下一轮生效"语义对称达成（ADR-0016 拒绝项的批评消除）。
9. **CLI 不接运行中 steer**：终端行缓冲天然排队（执行中输入在下一轮 readLine 即得），体验已够；注入收件箱做在 agent 域，CLI 未来接入是现成口（backlog 记档）。
10. **权限档持久化**：`permission/mode` 会话事件（latest-wins 投影，plan/mode 同款先例）——重开该会话恢复最后切定档位，新会话/新部署回 yml 缺省（档位跟对话走，不跨会话惊吓）。
11. **/title 改名命令**：再 append `session/title` 即改名（latest-wins 投影现成）；标题随对话自动演进不做（一次生成 + 可改名已覆盖，演进需触发器成本不成比例）。busySafe=true（纯事件写）。
12. **页长可配**：首屏/每页消息数从常量改 web 插件 config 可配，缺省 50 不变。

## 拒绝的选项

- **各呈现位各自解释斜杠**（Web 后端另写一份、CLI 维持硬编码）：两套清单两份逻辑，命令行为漂移、审计无统一落点——backlog"Web 斜杠缺口"类债务会再生。
- **命令交模型执行**（斜杠当消息发给模型靠提示词调工具）：进历史、烧 token、不可靠、审计面目全非——方向性排除。
- **技能并入命令注册表**（启动时批量注册成命令）：入口统一了，但"进不进模型历史"的分界从语义变成每条注册的标记，模型可见面易配错；两表一入口顺序已够。
- **命令上下文为纯 Runnable / 事件总线异步**：闭包捕旧会话引用的换绑坑；异步化对毫秒级本地操作是过度设计。
- **全部命令仅 idle 可执行**：实现最简，但"运行中收紧权限"恰是运行中治理的真实需求（任务跑偏时勒住）。
- **全部命令运行中可执行**：/new 运行中换会话的锁与日志混乱不可接受。
- **单条审计事件**：命令中途崩溃的断口不可见。
- **命令落日志且进投影**：命令文本进模型上下文，语义与成本双输。
- **广播式回答者路由**（全部回答者同弹、先答者胜）：两边同弹吵、双答竞态。
- **仅补终端提示不路由**（"审批已发往 Web，等待作答"一行字）：backlog 保底方案——债未清只贴条。
- **steer 双轨**（排队等结束的伪 steer + 显式注入入口）：用户要理解"这句话是等它干完才被看到还是马上被看到"，交互认知成本与实现路径双高。
- **抢占式打断**（立即中止当前步骤）：工具组半途而废的善后（日志闭合、锁）全是坑；DSH 亦 step 边界语义。
- **权限档 DuoHome 全局持久**：上一个会话切的 read-only 勒住新会话，是惊吓不是便利。
- **/model 运行时切换本期做**：LLM 配置启动期装配，运行时换 model 牵连适配器生命周期与治理计量连续性；命令注册表落地后加回是增量，推迟零 regret。
- **CLI 运行中 steer 入口**：主循环线程拆分的改动面大、行缓冲排队体验已够。
- **命令注册表立独立 Maven 模块**：四类 + 注册表的量级远不到一域一模块，agent 域同居。
- **标题随对话自动演进**：需要定时器/触发器，成本与需求不成比例；一次生成 + /title 改名已覆盖。

## Consequences

- 术语表同 diff 入册五词条：斜杠命令（slash command）、busy-safe（运行中安全）、steer（运行中注入）、亲和路由（affinity routing）、压缩点（compaction point）；会话标题词条的"不可改名"随 /title 落地同步修正（ADR-0013 的一次生成语义保留，改名能力归 ADR-0020）。
- backlog 同 diff 对账：销"审批/提问的呈现位路由""Web 面斜杠命令缺口""/compact 手动压缩命令"三条；"钩子载荷上下文透传"部分消化（presenterId）；新增"CLI 运行中 steer 入口""/model 运行时切换"两条。
- limitations 同 diff：M9-M11#3（手动压缩）、M12#3（权限持久化）、M13#1（标题改名）、M13#2（页长）四条销账；交互工具会话绑定先到先得一条销账。
- 投影语义扩展两处（command 排除、compacted 拼接）的验证义务在测试：投影纯函数单测 + M10 游标 / M13 尾窗 / M16 闭合既有算法零牵动断言。
- steer 使会话日志出现"执行中追加的 user/message"（可能连续多条）——投影与回放需断言兼容（日志本就允许多条连续 user/message，预期零特判，但要显式验证）。
- Web 409 移除后"单入口串行"语义由 steer 承接：WebFace 并发测试的 409 断言改为注入断言（同 diff 重写）。
- 命令执行于呈现位进程内：命令异常收敛为回显文本，不得影响 agent 单飞与呈现位存活。
- DSH 的 `ctx.commands` API 签名在研究笔记中未展开——实现以本文为准，不臆测 DSH 形状；`permission/mode` 与 `context/compacted` 的字段形状在 spec 定稿。
