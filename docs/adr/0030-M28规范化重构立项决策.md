# M28 规范化重构立项决策：范围档位与破坏性变更许可

Status: 批准（2026-09-28，M28 启动 grill 八问逐项裁定；细化 [ADR-0029](0029-M27至1.0版图重排第二弹.md) M28 节并勘误其两处旧口径）

## 背景

ADR-0029 将 M28（0.23.0）定为规范化重构「代码优雅化」：挂账清偿（装配参数对象化、user.dir 提取、WebFace 拆分、Data Clumps 消重）+ 全仓设计模式审查，度量轻量不引工具。M27 交付移交清单 13 条（report.md §七，按扫描册 H-01~H-16 编号）加 javadoc 出入一件，作为立项对账底座。启动 grill（2026-09-28）八问逐项裁定如下。

## 决策

### 范围档位（八件必做）

M27 移交清单收录档位裁定：

- **核心 6 条必做**：H-09 三呈现位接线三连抄（含 17/14 参装配参数对象化与模板化）、H-10 WebFace 单体拆分（实测 1812 行）、H-15 user.dir 同形 22 处提取、H-12 fileRefs 旁路服务化、H-01 类型下探×2（capability 接口化）、H-04 执行链直引功能域具体类（依赖倒挂）。
- **单列 1 条必做**：H-13 服务名撞名——`SubagentHost.SERVICE_NAME "presenter"` 改名（新名 spec 期定；内核约束为单小写词、避呈现位域字样。撞名风险：H-03 注册表化后呈现位域若发布同名服务即真冲突）。
- **零散 1 件必做**：PluginSnapshot javadoc 与实现出入——修法裁定为**改注释认事实**（name 一律为类 FQCN）；行为修正（快照 name 用 yml id）归装载域（H-08/H-16 同域，1.0 后），本期不越界。
- **评估 2 条 spec 期卡点裁定**：H-06（CLI 呈现位私有事件/工具认知）、H-07（计划模式域内嵌）——看了卡点再定修不修。
- **M28+ 2 条不进**：H-11 模块依赖逆挂、H-14 ConnectorStatusBoard 静态单例（扫描册原判 M28+，维持）。

### H-03 破坏性变更许可

呈现位常量 `PRESENTER_CLI/PRESENTER_WEB`（全仓 24 处引用 12 文件，全部内部消费，demo 插件不触碰）注册表化时**允许删常量改签名的破坏性变更，一次改齐**；扩展点清单等文档同 diff 同步。

### 设计模式审查形态

独立模式对账册先行：1 个工单扫描成册（命令分发族/provider 映射/装配层三方向加补充扫描），逐条裁定改/不改，改的编入后续工单。不重复 M27 已扫的 H-01~H-16，只补「模式形态」新视角。

### 步子大小红线（四条，全期生效）

1. 拆分只做同类职责切分（如 WebFace 按端点族/渲染/会话管理分文件），不重新设计；
2. 越界冲动记档不修——对账单外的发现一律入 backlog；
3. 9 项独占面（boundary.md）不碰——架构事实非丑代码；
4. M27 刚验收面不回炉——demo 插件「零既有行改动」接入与行序契约 fail-fast 列为不动面。

### 完成判据（五条）与度量（四项）

判据：对账单逐条销号（含记档不修的明示）+ 度量前后对照表 + 全仓 `mvn verify` 绿 + M27 基线不破 + 四轴审查/用户手动验收/发版 0.23.0。

度量（不引工具，脚本统计改前改后各一次）：①最大文件行数 top10 ②装配点参数个数 ③user.dir 同形计数 ④重复代码组计数。目标值 spec 期逐工单定。

## 拒绝的选项

- **13 条全收**：H-11/H-14 硬塞本期致「优雅化」失焦，且 H-11 接近结构调整，违背「不大拆伤稳」。
- **常量+注册表双轨并存**（H-03 保守路线）：两套身份机制并存比现状更不优雅，与本期命题相悖。
- **PluginSnapshot 改实现行为**：装载域已裁 1.0 后（H-08/H-16 同域），顺手越界破坏裁定连续性。
- **设计模式审查贯穿工单不成册**：发现散落各工单记录、易漏、无法逐条销号。
- **PMD 等度量工具进构建**：ADR-0029 已拒，维持——引依赖 + 指标易变数字游戏。

## Consequences

- ADR-0029 M28 节两处旧口径勘误（同 diff 注回原文）：装配参数实测 chatAgent 全参重载 **14 参**（立项「15 参」；全仓最大装配点为命令注册接线 17 参）、user.dir 同形 **22 处**（立项「19+ 处」）。
- backlog PluginSnapshot 条目按本文档裁定更新指向（javadoc 认事实，行为修正留装载域 1.0 后）。
- H-13 新名、H-06/H-07 卡点裁定、WebFace 拆分切法、装配参数对象形状均留 spec 期——grill 定方向与边界，spec 定方案。
- 版本分支 0.23.0 已自 main 切出（2026-09-28）。
