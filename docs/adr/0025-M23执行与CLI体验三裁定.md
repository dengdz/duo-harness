# M23 执行与 CLI 体验三裁定：事件驱动主循环、后台任务与 .gitignore 自研

Status: 批准（2026-09-21，M23 启动 grill 十二问逐题裁定；范围与依据锚 = [ADR-0024](0024-M23至1.0里程碑版图重排.md) M23 节，事实基础 = docs/research/ 两家探测文档（工单 03 本机执行工具族、05 任务管理、01 Agent循环与状态机、07 审批交互、17 终端呈现），锚点 DSH `ddefc45f` / ZCode `872ad96`）

## 背景

duo 的 CLI 主循环是 readLine 阻塞读：执行期键入的输入沉在行缓冲里，turn 结束后被静默当新输入消费——这是 ADR-0024 认定的唯一真实缺陷。围绕它，本期的能力缺口成串：bash 超时只会 120s 杀树（无后台、无输出转存）；审批是单问单答 y/n；无 headless 对外事件词汇；glob/grep 只跳 VCS 目录不认 .gitignore。M22 探测已把 ZCode（主）与 DSH（辅）的对应机制量化到码级，本期按「不做简化版」原则对齐。本 ADR 只钉三个跨工单、难逆转的架构级裁定；呈现面形态与参数数字进 spec（`.scratch/m23-cli-experience/`），spec 直接引用上述探测文档。

## 决策

### 一、CLI 事件驱动主循环与两级收件箱

- **并发底座**：虚拟线程常驻阻塞读 stdin，每行作为事件注入 agent 域收件箱；agent 循环、后台任务、完成通知各走各的虚拟线程。不引 NIO、不引 jline。
- **两级收件箱**（M19 单级收件箱升级，CLI 与 Web 双呈现位同源）：`next-step` 级在 step 边界注入当前 turn——CLI 执行期键入的默认去处，提示行回显「已插队」；`next-turn` 级在当前 turn 收口后生效——承载后台完成通知等内部事件与显式排队消息。想开全新任务先暂停再发。
- **暂停（协作式中断 + 恢复）**：运行期 Ctrl+C（SIGINT 经 `sun.misc.Signal` 拦截，不可用降级 `/stop` 行命令）触发：当前工具调用终止（复用 bash 杀树）、已流出文本打 interrupted 标记、未派发工具补合成结果——会话日志可重放无悬空 tool-call；会话停在可恢复状态，续接即继续（下一条用户消息接续）。运行期单击中断、再按退出进程；空闲单击即退出。Web 输入框旁加停止按钮。**不做原地冻结**（ADR-0024 已钉）。

### 二、后台任务注册表、输出三层与通知必达

- **显式后台化**：bash `run_in_background` 转入内存注册表（taskId），超时语义维持 120s 杀树不变；「超时自动转后台」维持拒绝（ADR-0024）。
- **模型侧工具面**：`task-output`（block/timeout/尾窗读输出）+ `task-stop` 两工具，**不加 task-list**——列表职责给 CLI 提示行与 Web 状态面（本项呈现完整性，ADR-0024）。
- **输出三层预算**（bash 前台后台共用）：inline 尾窗默认 30k 字符 / spill 落盘帽 64MiB / task-output 尾窗默认 32k，yml 可配；**超帽告警不静默**——修 DSH「超 64MiB 删 spill 不告警、SIGKILL 留残渣」两坑；spill 文件回传 spillPath 供模型回读。
- **完成通知必达**：每任务至多一条（first-wins，settle 只记首个终态）；agent idle 即开新轮消费，busy 挂收件箱 next-turn 级、turn 收口多条合并为一条注入。不设 DSH 式 wake 预算（单代理无多 owner 问题，每任务一条已天然限流）。
- **暂停不杀后台任务**：注册表独立于 turn 存活，通知照发（挂 next-turn 等续接后消费）；进程退出注册表全灭。

### 三、.gitignore 自研判定器

- **自研不捆绑**：rg 二进制分发触碰红线 4（零新 native 依赖），glob/grep 引擎的替换点（limitations M12#2）内落自研 Java 判定器。
- **语法全常用子集**：逐级堆叠 + `.git/info/exclude`；`!` 反选、`**`、`*`、`?`、`[]` 字符类、尾 `/` 目录限定、前导 `/` 锚定、`\` 转义；解析错误行静默跳过（git 同语义）。全局 `core.excludesFile` 不做。
- **判定并集**：`.gitignore` 规则 ∪ 硬编码产物目录（node_modules/target 等）∪ VCS 元数据目录——防仓库没写 .gitignore 就全量扫。
- **同口径**：glob、grep 与 @file 补全索引共用同一判定器，消灭「补全看得到、grep 看不到」的口径分裂。

## 拒绝的选项

- **NIO Selector 非阻塞**：单用户本地 CLI 无吞吐收益，复杂度与平台兼容面不成比例。
- **readLine + 后台轮询折中**：双读竞争，修不掉「输入被当新输入消费」的根因。
- **jline3 raw mode 真快捷键**：新第三方依赖触红线 4；Ctrl+C 语义 + `/stop` 兜底 + Web 按钮已覆盖暂停入口。
- **SIGINT 全时段退出 / 双击退出**：前者丢弃「在跑先停」协作语义，后者徒增按键节奏记忆（ZCode 形态对个人工具过重）。
- **task-list 第三工具**（DSH job_list 同构）：超出 ADR-0024 钉的两工具措辞；模型凭 run_in_background 返回的 taskId 操作已足。
- **busy 时完成通知走 next-step 即时注入**：打断在飞任务的收尾节奏，多任务并发时喧宾夺主。
- **捆绑 rg 换 .gitignore 能力**：红线 4；且逐级堆叠对 duo 是纯 Java 可达的净新增工作量，非必须复用 rg。
- **砍 `!`/`[]` 的更小 ignore 子集**：`!` 反选在实际仓库常见，砍了语义不完整，后补即契约变动。
- **达限放行一轮收尾**：completed 语义要区分「自然完成/强制收尾」，且模型可能学会拖到收尾轮才干活。
- **NDJSON 五类精简起步**：事件词汇是对外契约，发布后再补帧即 breaking，自动化消费方被迫跟改。

## Consequences

- backlog「CLI 运行中 steer 入口」（ADR-0020 决策 9 记档）由决策一兑现，销账于 M23 收口；`.gitignore` 条目（M12#2）随决策三落地销账。
- 术语表与本 ADR 同 diff 增改：收件箱（新）、steer（升两级语义）、暂停（新）、后台任务（新）、spill（新，区别于治理阈值同名）、审批小队列（新）、NDJSON 事件流（新）、忽略判定（新）、迭代上限（增感知提醒）、技能热加载（新）、发现根（去「不做热加载」）。
- 呈现面形态（CLI 提示行与 Web 状态面布局、审批 i/N 呈现、headless 入口形态、steer 消费点选型、spill 文件落点）与参数数字归 spec；NDJSON 七类词汇、审批 allow/deny 枚举与键位、剩 2 轮 system-reminder 提醒等本期 grill 新钉语义由 spec 承载并引用本 ADR。
- limitations 对账随实现销账：M7#2（技能热加载）、M12#2（.gitignore）、M16#1（上限感知）；CLI steer 缺口随决策一落地消除。
- 行为迁移显式化：执行期键入从「缓冲后当新输入」变为「next-step 插队」——验收必须覆盖该场景的正反两面（插队生效、开新任务走暂停）。
