# M33 立项决策：浏览器实测质量期——百例基线

Status: 批准（2026-10-02，M33 启动 grill 七问逐题裁定 + to-spec 缝裁定一问，共八问；轻量里程碑制延续后首期，活源为 1.x 质量承诺本身）

## 背景

版图对账（启动 grill 首步）：CHANGELOG 实发最新 1.0.0（2026-10-02 盖章，tag v1.0.0 在）；1.0 后无版图 ADR——M32 工单 03 已声明 1.x 策略（语义化版本、按需发版），M33 的版本号归属为全新决策，无历史错位要补。

可测面探索（子代理汇报 + 关键事实自查）：Web UI 为单页三区（会话侧栏/对话面/状态面）+ 15 种卡片分型 + 19 个 HTTP 端点（含 SSE）；仓库无任何浏览器自动化先例（历史口径「浏览器端以人工验收为准」），但有三类可复用资产——隔离 DUO_HOME + 随机端口启动法、「evaluate 原生点击」竞态规避先例、m8-web 七场景验收对照表。**注意点**：设置页不存在（1.0 后菜单第 ⑩ 条未实现），用例设计不假设它存在。

实现面 smoke 未做——本期货与环境强相关（隔离实例、浏览器驱动、三件套 fixture），比 M30 的「即跑承诺」更多一层环境依赖。按 M30 经验（定版范围关键路径先实测），smoke 前置声明为工单 01 第一动作，失败即回头改方案，不带病铺 100 例。

## 决策（八问裁定）

### 一、范围边界：纯测试 + 台账，修复另立项

只测、记档、出报告，当期不修任何缺陷。理由：测试与修复混在一期会让周期不可预估（缺陷数量未知），且「测试主管」角色定位下先拿全量事实再排修复更符合证据先行纪律；修复批以报告 P0/P1/P2 分级为入口另行立项。

### 二、覆盖面：十域全功能面 × 风险加权

高危域（实时流、会话数据、鉴权栅栏、人机协作卡、长会话容错）每域 10-12 例，纯展示类每域 3-8 例，跨域组合链 30 例（占三成）。拒绝聚焦高危四域（展示类完全裸奔）与用户旅程串（旅程盖不到安全负路径与异常注入）。

### 三、模型侧：真实模型 + 会话数据复用

对话类用例由真实模型驱动（`~/.duo/config.yml` 现有配置），判据写成行为类（该出现的出现/不该出现的没出现）而非逐字比对；纯 UI 用例复用已产出的真实会话数据省 token。拒绝假模型适配器：与纯测试不改码边界冲突，且卡片触发路径是编排出来的，真实成色下降。

### 四、环境：隔离实例 + 三件套

独立 DUO_HOME + 随机端口（先例形态，不碰日常会话与活锁）；环境三件套均为测试夹具非产品代码——微型 MCP echo server（连接器正向链路有真实数据）、vision 图片全链路（模型需支持图片输入）、真实 git 仓库工作区（文件类用例吃真实文件）。

### 五、指标：硬指标 100 例，终态三值

报告即 100/100：每例必有终态（通过 / 发现缺陷 / 阻塞 + 原因）。跑不通的如实标阻塞也算交付；素材不足的域宁可在高危域加密不注水。拒绝目标值 ≥100：收口时「到底该多少」无硬杠，抽验无据。

### 六、节奏与证据：5 批 × 20 + 抽样截图

逐批交付小节报告（中途可纠偏可叫停）；每例证据四件套（步骤/预期/实测/结论）；缺陷例必附截图 + 最小复现，通过例抽两成附图。拒绝一口气跑完（中途零纠偏点、用户零可见）与 10 批细粒度（汇报开销翻倍）。

### 七、提交落点：纯文档直落 main，不发版

红线 7 防的是未验收代码进 main；本期零代码，资产仅 spec/用例/报告/ADR/台账（纯文档），比照 M32 收尾 docs 提交直落 main 先例。不发版、不打 tag、CHANGELOG 不记账（无用户可见变更；limitations 回写收口后凭报告另行裁定）。拒绝切分支：多一道合并手续，本期无审阅增量。

### 八、测试缝：浏览器主缝 + HTTP 例外清单（to-spec 期裁定）

主缝唯一——真实浏览器对真实实例，断言主面 = 页面可见行为。仅协议负路径类（token 无效/缺失、伪造 Origin/Host、403 fail-closed，约 8 例）明示走 HTTP 通道断言——浏览器安全模型不允许页面伪造 Origin/Host 头，这类用例只有协议面可达。拒绝严格单缝（栅栏负路径大面积阻塞，高危面反而测不到）与双缝并重（偏离浏览器实测定位，且 API 面已有 10 个集成测试覆盖，重复投入）。

## 拒绝的选项

- **假模型适配器**（按剧本回话）：改码破坏纯测试边界，测不到真实模型行为。
- **聚焦高危四域**：展示类、输入辅助等面完全裸奔，基线不完整。
- **按用户旅程串**：贴近真实但旅程盖不到安全负路径与异常注入。
- **目标值 ≥100**：收口无硬杠，阻塞与注水的边界说不清。
- **一口气跑完 100 例**：中途零纠偏点，方向跑偏返工面最大。
- **测试 + 当期修复 / 全量修复**：周期不可预估，测试主管角色与修复角色混职。
- **切分支守红线 7 字面**：零代码期无审阅增量，纯增手续。
- **严格单缝 / 双缝并重**：前者栅栏负路径大面积阻塞；后者偏离定位且与既有集成测试重复。
