# 本机工具族与权限预设：workspace 绑定、三档语义与读前写闸门

Status: 批准（2026-09-15，M12 grill 裁定）

agent 的生产力缺口：目前只有 MCP 沙箱演示级 files 工具（单目录、演示目的），无法真实操作用户项目。本决策引入 workspace 绑定的本机 fs 工具族（read/write/edit/glob/grep/bash）与三档权限预设。参照系：DSH 0.1.5 fs/shell/sandbox/permission-presets 四域源码精查（read 三帽窗口、edit LF 归一匹配域、原子写协议、错误双轨哲学——见 `.scratch` 会话侦查记录）。

## 背景

工具目录对账（M2 起）显示工具域只有演示级供给；DSH 把 fs 五件套 + bash 列为默认启用的生产力核心。采纳的硬约束：零构建/最小依赖理念（不捆绑 ripgrep 等外部二进制）；个人工具场景（无多租户）；工具卡呈现已元数据驱动（新工具零呈现特化）。

## 决策

1. **workspace 绑定**：fs 工具与 bash 的路径解析基准 = 插件配置 `root`（缺省进程 cwd；DuoMain `--workspace` 参数透传）。路径包含性判定 = canonicalize（realpath）→ 词法前缀+分隔符比较；**显式声明这是可信代码内的策略检查，不是 OS 内核边界**。
2. **fs 工具族**（tools 模块 `fs` 子包，DSH 短名）：
   - `read`：三帽窗口（2000 行 / 单行 2000 字符 / 总量 50KiB，可配）+ 扫全文件取精确总行数 + footer 自描述续读指令（`Use offset=N to continue`）+ 二进制拒读（NUL 嗅探）
   - `write`：**原子替换**（同目录临时文件 + `ATOMIC_MOVE`）+ **读前写闸门**（见决策 4）
   - `edit`：`old_string` 字面匹配——LF 归一匹配域（CRLF 文件跨行替换照样命中，写回恢复行尾）；0 次命中 / 多次命中未声明 `replace_all` / 空串 / old==new 均结构化失败（错误文本内嵌补救指令，如 "provide a more specific old_string or set replace_all"）
   - `glob` / `grep`：**Java 自实现**（`Files.walk` + PathMatcher / 逐行正则），跳 VCS 元数据目录（.git/.svn/.hg 等）；截断 100 / 250 条 + "更多结果未显示"提示；无上下文行参数（引导模型对命中文件用 read）
3. **bash 工具**：每次调用全新进程（`bash -c`）；env 硬化（`NO_COLOR/TERM=dumb/PAGER=cat`）；超时 clamp（缺省 120s、上限 600s，模型可传低值）；每流输出截断（完整输出交治理 spill 兜底）；**非零退出不是错误**——文本 marker `[exit code: N]` 让模型自行判断；工作目录固定 workspace。
4. **三档权限预设**（`WorkspacePolicy` 服务，`PermissionPresetPlugin` 发布；fs/bash 工具构造注入）：
   - `read-only`：读类放行；**fs 写与 bash 一律经审批 seam ask**（终端 y/n / Web 卡片）
   - `workspace-write`（默认）：workspace 内 fs 写放行、workspace 外写与 bash ask
   - `danger-full-access`：全部放行（never）
   - 路径感知判定：解析工具参数的 `path` 字段做包含性检查（约定 fs 工具路径参数统一命名）；bash 无路径参数，按档整体 ask/放行
   - 运行时切换：REPL 内置 `/permission [档位]` 命令改**运行时态**（重启回 yml 缺省；不扩会话事件词汇——事件化留演进）
5. **读前写闸门**：`read` 登记已读文件集合（会话内存态）；`write` 覆盖已有文件与 `edit` 前校验——未读即拒（"read the file, then retry"）；新建文件豁免。防模型盲改真实事故源，成本一个 Set。
6. **错误双轨**：失败反馈 = 稳定语义 + 自纠指令（未找到带路径、多处带计数、闸门带补救动作）；bash 非零退出与策略拒绝不是 error 而是可解析 marker——只有基础设施故障才 isError。

## 拒绝的选项

- **捆绑 ripgrep**（glob/grep 用外部二进制）：性能强但破坏零依赖理念；个人项目规模下 Java 遍历足够，检索引擎保留后置替换点。
- **OS 级沙箱**（macOS Seatbelt / Linux Landlock/bwrap）：跨平台实现与测试成本对个人工具场景过重；DSH 自身也承认 fs 面 fence"是策略检查不是内核边界"。诚实声明 + 审批 ask 替代。
- **workspace-write 档放行 bash**（DSH 式"执行 + OS 拦"）：无 OS 沙箱时等于变相 danger 档；改为 ask。
- **多处匹配替换第一处**：真实事故源；严格失败 + 补救指令让模型自纠。
- **预设切换走会话事件溯源**（DSH 式 permission/preset 事件可重放）：事件词汇扩展 + 投影增量，本期运行时态够用；留演进。
- **新模块 duo-harness-workspace**：当前体量（5-6 类）撑不起独立模块，tools 模块子包足够；体量增长再升格。

## Consequences

- tools 模块新增 `fs` 子包（`FsToolsPlugin` + WorkspacePolicy 服务 + 六工具）与权限预设语义；`agent-demo.yml` 移除 MCP files 沙箱行（模型侧消除双写工具选型噪音；mcpfs 模块与 MCP 集成代码保留）；工具目录对账测试与运行Demo 同步更新。
- known 限制（进 limitations）：① bash 写范围不受 workspace 约束（无 OS 沙箱——策略语义非隔离，文档明示）；② glob/grep 不支持 .gitignore 语义（零依赖取舍）；③ 预设运行时切换重启回 yml 缺省（不持久）；④ read 的 50KiB 窗口外历史需 offset 续读。
- 呈现零特化：新工具经既有工具卡（Web）与叙述行（CLI）呈现，无前端改动。
- 计划模式硬禁工具的 limitation（M7#1）获得收敛路径：read-only 预设 + 写 ask 组合可表达"计划期只读"。
- 交互工具的会话绑定 dedup 语义（先到先得）沿袭不变——fs 工具无会话绑定（无状态、路径自含），不受该含糊影响。
