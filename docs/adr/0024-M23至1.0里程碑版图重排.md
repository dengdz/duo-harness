# M23 至 1.0 里程碑版图重排：基于参考项目深度探测的完整规划

Status: 批准（2026-09-21，M22 探测里程碑收口后的重规划 grill；同日修订：M23 增暂停、M24 增 /model 与 /effort；替代 [ADR-0023](0023-沙箱出栈与M23+里程碑规划.md) 决策三（M23+ 版图），ADR-0023 的沙箱出栈决议（决策一）、M22 改道记录（决策二）与对账原则（决策四）维持有效。事实基础 = M22 探测阶段 22 张工单产出的 44 份五段模板文档（锚点 DSH `ddefc45f` / ZCode `872ad96`）+ 一轮功能查漏）

## 背景

M22 探测里程碑完成后，duo 与两家参考项目（ZCode 主、DSH 辅）的机制级差距已全部量化。本决策不锚定任何旧版图，从探测启示的候选主题池（权限与安全 / 执行与 CLI 体验 / 上下文与记忆 / 会话数据 / 呈现与协议 / 工具与基建）重新推演 M23 至 1.0 的完整序列。两条规划原则：

1. **排序原则**：缺陷优先 → 控制面跟上能力面 → 长会话质量 → 数据完备 → 收口。
2. **深度原则**：每项能力按探测到的参考设计落地，**不做简化版**——duo 现有的简单实现（bash 超时直接杀树、内存倒排检索、AGENTS.md 拼 system、审批只有 y/n）在对应期内升级到对照形态。

## 决策

### M23（0.18.0）执行与 CLI 体验——「跑得起的命令行」

解决唯一真实缺陷（执行期输入被误当新输入消费）+ 日常高频痛点。核心工程：CLI 主循环从 readLine 阻塞改为事件驱动（一处改造喂饱全期）。

1. **bash `run_in_background`**：后台注册表 + task_output（block/timeout/尾窗）/ task_stop + 完成通知必达；bash 输出 **spill 顺路**（保尾+落盘+spillPath 回读）。超时语义维持 120s 杀树（「超时自动转后台」记后续可配项）；「用户侧后台任务可见化」（CLI 提示行 + Web 状态面）属本项呈现完整性。
2. **steer**：收件箱两级（next-turn/next-step），step 边界消费。
3. **暂停（协作式中断 + 恢复）**：主代理中断标志——当前工具调用终止（bash 杀树已有）、已流出文本保留并打 interrupted 标记、未派发工具补合成结果（会话日志可重放无悬空）；会话停在可恢复状态，续接即继续；Web 停止按钮 + CLI 快捷键。**不做原地冻结**（流与工具在飞，语义不可控）。
4. **审批小队列**：决策枚举 + Esc 兜底 deny + abort 移除。
5. **headless `--json`**：NDJSON 事件流（commit-point 投影 + final 无损豁免 + 退出码契约）。
6. **`.gitignore`**（M12#2 销账）：glob/grep 逐级堆叠 + `.git/info/exclude`，@file 索引同口径。
7. **搭车**：技能热加载（M7#2，watch+revision+digest 失效）；迭代上限感知（M16#1，接近上限提示模型收敛）。

依据：探测工单 03（本机执行工具族）、17（终端呈现）、07（审批交互）、05（任务管理）；暂停语义见 Agent循环与状态机探测文档（工单 01/03 报告引用的 DSH cancel 语义）。

### M24（0.19.0）权限与安全深化——「放得开也收得住」

M23 放开后台执行，控制面跟上。

1. **权限规则引擎**：项目（持久）/会话（内存）两级；`Bash(prefix:*)` 语义（deny 查全部命令、allow 只查非只读命令）；高危根命令排除（永不生成前缀规则）；审批卡「总是允许（项目）/仅本会话」。
2. **只读 bash 识别免审批**：解析器 + 三态策略表（首期约 30 个只读命令 + git 四件套，safeFlags 体系后置）；git 必叠 cwd `.git` 信任分类（防 `git -C` 逃逸）；`undefined`→ask；经「运行时 capability 覆盖静态 metadata」seam 接入。
3. **计划模式硬禁工具**（M7#1 销账）：plan 态只读+非破坏放行、写/执行 deny。
4. **MCP 加固**：工具名有损规范化 + 哈希后缀防坍缩；重连耗尽终态语义。
5. **Web 鉴权令牌 + bind**（fail-closed）；**标签级会话绑定最小版**（每标签持自己的 sessionId——后台任务时代多标签互踩的前置缓解；完整多会话协调仍属 1.0 后）。
6. **/model 动态切换 + /effort 思考等级**（会话控制命令面）：/model 同 provider 换模型名（跨 provider 需 yml 预声明路由）+ 切换会话事件 + resume 区分「保存意图 vs 执行绑定」；/effort 归一化档位（off/low/medium/high）→ 各 provider 参数映射（Anthropic thinking+budget、OpenAI 兼容 reasoning_effort、DeepSeek 靠切模型、GLM thinking 开关），不支持即显式降级标注；辅助性请求（标题生成等）强制降档。

依据：探测工单 08（只读命令识别）、07（审批交互）、20（存储凭据两级持久化）、14（MCP）、18（桌面端）、01（模型选择保存意图/执行绑定）、09（多 provider/reasoning 映射）。

### M25（0.20.0）上下文与记忆——「长会话记得住」

1. **memory 域最小形态**：system 规范段 + MEMORY.md 索引注入（meta_user 通道）；后台抽取子代理可配后置。
2. **microcompact 免模型本地裁剪**（保最近 N 组、媒体/错误豁免）+ 压缩熔断计数 + summary 预算隔离。
3. **cacheControl 三级断点**（身份前缀/稳定身份/动态段）+ AGENTS.md 迁 meta_user 通道 + **嵌套子目录 AGENTS.md 链**（M7#3 销账，随加载链同改）。

依据：探测工单 10（上下文工程）、11（压缩治理）。

### M26（0.21.0）会话数据与检索——「历史找得到、带得走」

1. **FTS5 迁移**（M21#1 收敛）：live+persisted 双表 UNION、模型 query 字面化防注入、cwd 授权过滤；交付声明入索引。
2. **/export 增强**：交付清单 + 变更摘要章节（流式写出借鉴）。
3. **会话文件格式版本头**：首行 version + 相邻迁移链（随本次会话数据改造一次性补上）。
4. **watermark/代际戳**：M10/M13 陈旧页与在途游标防护。

依据：探测工单 21（会话检索与导出）、01（投影恢复分页）。

### M27（1.0.0）收口

原 ADR-0016 收口内容不变：03-高级章节（技能编写/MCP 深入/多插件协同）；视觉打磨轮；release 产物分发；理解关卡补考（M3-M26，M27 前集中两场）；具名候选逐项终审——**沙箱按「已出栈（ADR-0023）」闭合**；1.x 版本策略声明（对照惯例：ZCode 主、DSH 辅）。

**1.0 判定标准**（承 ADR-0023）：具名候选全部 done 或明示出栈；CI 绿为常态且无 S 级质量债；文档三层齐备（含 03-高级）；安全基线闭合（Origin 防护 + 审批钉死 + 沙箱出栈决议）。

### 移出项（1.0 后菜单增补）

桌面壳（判据未触发：受控宿主需求不成立）、OTel 全套（至多随 M26 评估 model-attempt 级）、SDK 薄客户端、远程部署（SSH/Docker/WSL）、goal 域、cron/off-peak、PTY 持久终端、跨 harness 委派、browser-use、LSP 只读域、mailbox 信箱、**持久 shell / cd 状态延续**（Claude Code 同形态被接受，绝对路径可绕）、**会话级 rewind/checkpoint**（git 兜底文件回滚，对话回退工程量超收益）。

## 拒绝的选项

- **维持 ADR-0023 版图不动**：其 M23 五线并包权限与执行两域、且缺功能查漏增补；本轮逐块对照优化后重排更符合「按探测内容补齐简单实现」的规划原则。
- **权限群先行于执行群**：现有档位审批（非 danger ask）已兜底后台 bash，规则引擎是减打扰不是堵漏；控制面在能力面之后一期跟上即可。
- **M25/M26 合并**：上下文记忆与会话数据两域机制不相交，合并后单期过重。
- **M23 引入「超时自动转后台」**：改变用户对命令已结束的预期，首期只做显式 `run_in_background`。
- **只读识别首期对齐 safeFlags 全量体系**：ZCode 为此维护 20+ 策略文件 + 1.8MB 生成注册表，个人工具首期 30 命令 + git 四件套即可，后续按需扩。
