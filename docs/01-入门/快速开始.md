# 快速开始

这篇带你装好 duo-harness 并完成第一次对话——终端与浏览器两个界面同源可用。想先了解它是什么，看[首页](../index.md)与[架构·设计主线](../04-架构/设计主线.md)。

## 前提

JDK 21（`java -version` 核对）。

## 1. 配置 LLM

配置文件在 `~/.duo/config.yml`（没有就新建），`llm` 段填一个 OpenAI 兼容服务的地址与密钥：

```yaml
llm:
  provider: openai-compat   # 缺省；另支持 anthropic / deepseek / glm
  baseUrl: https://api.deepseek.com
  apiKey: <你的 API Key>     # 永远不要提交真实 Key 到任何仓库
  model: deepseek-chat
```

全部字段（重试、思考档位、视觉开关、多模型白名单等）见 [config.yml 全量字段参考](../05-参考/config全量字段参考.md)。

## 2. 拿到 jar

从 [GitHub Releases](https://github.com/dengdz/duo-harness/releases) 下载 fat-jar，或自己构建：

```bash
mvn -pl duo-harness-example -am package
```

产物是 `duo-harness-example/target/duo-harness-<version>.jar`。

## 3. 跑起来

```bash
java -jar duo-harness-<version>.jar
```

一次启动，两个界面同时可用：

- **终端 REPL**：直接对话，斜杠命令（`/new`、`/permission` 等，见[斜杠命令](../02-指南/斜杠命令.md)）与 `/exit` 退出；敲了不存在的命令会列出全部可用命令。
- **浏览器**：打开启动日志打印的带令牌地址（形如 `http://127.0.0.1:18080/?token=...`，缺省随机令牌、只绑本机回环）。

两面共享同一会话与审批路由：模型在终端发起的写文件审批，你在浏览器卡片上批也一样。

## 4. 试试第一句

让它干活，第一次会碰到审批：

| 你说 | 会发生 |
|---|---|
| `读一下 pom.xml 的前 30 行` | 调 `read` 工具 → 带行号输出 → 模型总结回答 |
| `新建 hello.txt，内容是测试` | 工作区内写文件免审批，直接创建 |
| `用 bash 跑 ls` | bash 命令一律先审批——终端 y/n 或浏览器卡片，批准后给结果 |
| `往 /tmp/duo-escape.txt 写点东西` | 工作区外写入，触发审批；拒绝后模型会解释 |

审批语义：一次性、无"永久放行"，你不回答一律按拒绝处理。权限预设与规则引擎见[权限与审批指南](../02-指南/权限与审批.md)。

会话自动落盘（`~/.duo/agent-sessions`），重启续接最近会话；`/new` 开新话题。会话管理与恢复见[会话管理与恢复指南](../02-指南/会话管理与恢复.md)。

## 5. 无人值守（headless）

```bash
java -jar duo-harness-<version>.jar --json "总结一下当前目录结构"
```

一次性执行任务，stdout 输出逐行 JSON 事件流，进程退出码即成败——脚本与 CI 不碰交互界面。参数、事件类型与退出码契约见 [CLI 参考](../05-参考/CLI参考.md)。

## 6. 从源码跑

不开 jar、直接跑装配好的 agent REPL：

```bash
mvn -pl duo-harness-example -am package exec:java -DskipTests \
  -Dexec.mainClass=dev.duo.harness.example.agentrepl.AgentReplMain
```

（首次构建或发布前去掉 `-DskipTests` 完整跑。想自己组装装配文件而不只是跑现成的，看[组装你的第一个 agent](../02-指南/组装你的第一个agent.md)。）

仓库另有一组内核机制演示入口（`DemoMain` 等，逐段演示插件容器、工具管线、MCP 连接的机制形态）——面向框架机制浏览，见[架构·设计主线](../04-架构/设计主线.md)；日常使用不需要它们。
