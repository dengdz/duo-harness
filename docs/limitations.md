# 已知限制

本清单是仓库已知限制的唯一权威来源（duo-doc-standards 约定）：任何"暂不可用/未接线/有意推迟"的表述以这里为准，别处不再重复维护。消除某条限制时同一 diff 内删除对应条目并记 CHANGELOG。

## 遗留（自 0.1.0，跨版本仍有效）

| # | 限制 | 说明与去向 |
|---|---|---|
| 1 | 运行时行级配置热重载不可用 | `Boot.from(yml)` 为一次性引导，改配置需重启进程；HMR 与 DSH 式 Entry.update 行对账属后续里程碑 |
| 2 | `bail` 与 `serial` 语义等价 | 同步阻塞模型下无差异（DSH 的差异源于异步监听器），bail 保留词汇（ADR-0001 决策） |
| 3 | recheck 的真并发路径未经多线程测试 | 六态迁移经 ReentrantLock 串行化 + LOADING dirty 标志兜底，单线程语义已测；跨线程同时 provide/remove/dispose 的深度竞态为已知未测区 |
| 4 | isolate 多作用域隔离不可用 | 注册表二阶键已预留，Realm/作用域注入/迁移未实现（M1 决策） |
| 5 | 独立 jar 热加载不可用 | 同 classpath + 配置声明模型（ADR-0001），child Classloader 动态加载保留为扩展点 |

## M2（0.2.0）

| # | 限制 | 说明与去向 |
|---|---|---|
| 1 | guard 的"仅作用域内调用生效"不可用 | guard 现为随注册作用域销毁摘除 + 全局生效（内核无调用方作用域概念，工单 04 决策）——内核补 ambient 作用域机制后可收敛 |
| 2 | MCP Java SDK 与 networknt 校验器版本耦合 | `mcp-json-jackson2:0.18.1` 硬依赖 networknt json-schema-validator 2.0.0；升级 SDK 时必须同步核对该版本（1.5.0 会因缺类在子进程抛 NoClassDefFoundError） |
| 3 | demo 的 MCP 子进程 classpath 依赖运行环境探测 | `subprocessClasspath` 先取 `java.class.path`（IDEA/裸 java）、再枚举 ClassRealm URL（exec:java）；非标准 classloader 下探测会失败——仅 demo 受影响，核心模块无此依赖 |

## M7（未发布）

| # | 限制 | 说明与去向 |
|---|---|---|
| 1 | 计划模式为引导式，不硬禁工具 | 激活时靠计划指导片段约束行为；写操作的真实防线是权限预设的档位审批（M12，ADR-0012——越界写与 bash 非 danger 档一律 ask）。硬禁（计划模式下工具直接不可用）仍属后续 |
| 2 | 技能无热加载 | 仅启动扫描，技能目录变更需重启进程（M9+ 候选） |
| 3 | AGENTS.md 注入为最小链 | 仅用户全局 + 项目根两文件；嵌套子目录链与 fs 操作后增量发现未做（M9+ 候选） |
| 4 | 思考内容回传的 provider 间歇校验 | 思考模型 + 多轮工具链下，provider 对 reasoning_content 回传的校验呈间歇性（诊断三连复现困难）；已按"随事件持久化、投影全量回传"根治，若再遇 400 需捕获失败请求体上报 |

## M8（未发布）

| # | 限制 | 说明与去向 |
|---|---|---|
| 1 | Web 面无鉴权 | 只绑 127.0.0.1（局域网不可访问）；token / 登录在要暴露网络时再加（M9+） |
| 2 | CLI 与 Web 并发写同一会话未协调 | 会话有独占语义（M10）：打开即取锁，后到者明确报错而非静默双写；跨进程写**协调**（多端同时写同一会话）仍属后续里程碑 |
| 3 | 界面为无构建静态单页 | 原生 JS 无框架——交互复杂度上限受控；组件化 / 构建链在界面规模化时再引入（M9+） |
| 4 | 多浏览器标签共用一个"服务端当前会话" | /new 与切换会话改的是服务端全局状态，多标签同时操作会互相改写对方的当前会话（实测确认）；单标签使用不受影响，多会话并行属后续里程碑 |

## M12（0.7.0）

| # | 限制 | 说明与去向 |
|---|---|---|
| 1 | bash 写范围不受 workspace 约束 | 路径包含性是可信代码内的策略检查，非 OS 内核边界（ADR-0012 明示）；bash 的拦截点只有审批（非 danger 档一律 ask）。OS 级沙箱（Seatbelt/Landlock/bwrap）属后续里程碑 |
| 2 | glob/grep 无 .gitignore 语义 | 仅跳 VCS 元数据目录（.git/.svn/.hg/.bzr/.jj）；.gitignore 过滤、上下文行参数（-A/-B/-C）与 ripgrep 捆绑属后续（引擎留替换点） |
| 3 | 权限预设切换不持久 | `/permission` 切运行时态，重启回 yml `mode` 缺省；切换的会话级持久化属后续 |

## M13（0.8.0）

| # | 限制 | 说明与去向 |
|---|---|---|
| 1 | 会话标题不演进、不可改名 | 首条消息后生成一次即定稿（ADR-0013 精简版裁定）；对话主题漂移后的重生成与用户改名（含 `title` 事件覆盖写）属后续里程碑 |
| 2 | 分页页长为常量不可配 | 首屏 50 / 每页 50 硬编码（`TAIL_WINDOW_MESSAGES`，ADR-0013：进配置即承诺契约）；页长配置化属后续 |
| 3 | 分页与尾部快照每次全量投影 | 每次请求对事件快照做 O(n) 三趟投影定消息边界（内存毫秒级）；增量投影 / O(n) 单趟优化属 M14 |
