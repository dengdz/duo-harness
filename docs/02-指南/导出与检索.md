# 导出与检索

这篇讲怎么把会话成果带走（`/export`）、把历史内容找回来（侧栏搜索与 `session_search`）。

## 导出：`/export`

```bash
/export            # 导出 markdown 人读记录（缺省）
/export json       # 导出日志原样副本（逐行等价的 JSONL）
```

- **终端**：文件写在当前目录，名为 `duo-session-<会话id>.md`（或 `.jsonl`）；
- **浏览器**：自动触发浏览器下载；
- 每个入口只触发一次——刷新页面或重新进入会话不会重复下载。

markdown 记录包含完整对话（角色 + 时间戳）、工具调用摘要与附件清单；json 形态是会话日志的原样副本，适合程序消费。

### 报告里的两个对账章节

导出报告携带两个互相印证的成果视角：

- **交付清单**——模型在任务收尾申报的成果文件（历史会话的声明记录）；
- **变更摘要**——系统客观视角的文件改动对账：会话首尾各拍一次 git 快照比对（文件清单 + 加减行数）；非 git 目录退化为文件工具操作记录聚合（有清单无行数）。

模型说它交付了什么，系统快照说磁盘真的变了什么——两个章节对照读，成果核验不靠信任。

## 检索：找回历史内容

两个入口，同一套索引：

- **浏览器侧栏搜索框**：输关键词回车，命中的会话列表带【】摘录标记，点击直达；
- **让模型找**：对话里问「搜一下之前哪个会话讨论过 X」，模型调 `session_search` 工具引用会话 id 与摘录回答（终端用户同样受益）。

### 检索的行为边界

| 边界 | 说明 |
|---|---|
| 引擎 | SQLite FTS5（派生只读层——JSONL 仍是唯一权威源，索引库可随时重建） |
| 懒构建 | 首次搜索才扫会话目录建索引，启动零成本；mtime/size 增量对账，新会话自动收录 |
| **授权边界** | 只返回与当前工作目录相同的会话；无目录记录的旧会话不进结果——防跨项目上下文污染 |
| 索引内容 | 消息文本、tool 调用名与参数、tool 结果、todo 内容项、turn 错误、交付声明文件路径 |
| 不入索引 | 思考内容（reasoning）与治理事件；子代理会话（`subagents/` 子目录） |
| 命中上限 | 单次 8 条（插件 `maxResults` 可配）；空结果明示 No results found. |

进行中的活跃会话也搜得到（内存实时供数），不用等落盘重建。
