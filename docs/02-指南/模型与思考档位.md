# 模型与思考档位

这篇讲怎么选模型、调思考深度，以及思考模型（thinking mode）的思考过程在哪看。涉及的命令是 `/model` 与 `/effort`，配置在 `~/.duo/config.yml` 的 `llm` 段。

## provider 声明

`llm.provider` 声明走哪套协议适配器（决定鉴权头、流式解析与参数映射），不再由 baseUrl 隐式猜测：

| provider | 协议 | 什么时候用 |
|---|---|---|
| `openai-compat`（缺省） | OpenAI 兼容 | DeepSeek、GLM、各类 OpenAI 兼容网关 |
| `anthropic` | Anthropic messages | 直连 Claude 系列 |
| `deepseek` | Anthropic 兼容网关 | DeepSeek 的 anthropic 端点 |
| `glm` | GLM 形态 | 智谱端点 |

字段全表见 [config.yml 全量字段参考](../05-参考/config全量字段参考.md)。

## `/model`：运行时切模型

```bash
/model                # 查看当前模型与可切清单
/model deepseek-chat  # 切换（下一轮请求即用新模型）
```

- **可切清单 = `llm.models` 白名单**——白名单里的模型才可切；不配白名单则 `/model` 只读不可切。
- **保存意图与执行绑定分离**：切换立即生效于后续请求（执行绑定），同时落一条会话记录（保存意图）——重启恢复该会话时会提示「这个会话上次用的是 X 模型」，但**不自动切**，防止恢复旧会话误触新请求。

## `/effort`：思考等级

```bash
/effort            # 查看当前档位
/effort high       # 切到 high（下一轮对话生效）
```

四档 `off / low / medium / high`，缺省 `medium`。档位按 provider 能力映射到原生参数：

- **anthropic**：thinking 开关 + 思考预算随档位伸缩；
- **openai-compat**：`reasoning_effort` 参数直传；
- **deepseek**：靠切换到对应思考模型表达；
- **glm**：thinking 开关。

provider 不支持的档位会**显式降级标注**（不会静默忽略）；标题生成这类辅助性请求强制低档，不烧你的思考预算。

## Web 面选择器与配置管理（M38）

不用敲命令，浏览器里直接点：

- **composer 模型/思考选择器**：输入框下方工具行右侧两枚下拉——「模型」列出 `llm.models` 白名单、「🧠 思考」四档（关闭/低/中/最高）。点选即触发与 `/model`、`/effort` 同源的命令，**下一轮对话生效**；当前值标签随会话事件实时跟随。三枚选择器菜单互斥单开，点菜单外即收起。
- **状态面板「模型配置」管理区**：查看/编辑 `llm` 段五行（provider/baseUrl/apiKey/缺省模型/可切模型白名单）——保存写回 `~/.duo/config.yml` 后**重启 duo 生效**（进行中会话不受影响）。apiKey 只显「已配置」状态不回显，留空提交 = 保留原值；非法值（provider 越界、白名单坏条目）保存被端点点名、原文件不动。

生效语义一览：选择器切换 = 下一轮；配置管理区写回 = 重启后。**切换只影响发起的呈现位**（Web 切不影响终端链，反之亦然）——多入口并行的行为口径。

## 思考过程在哪看

思考模型的推理过程完整上 Web：

- **流式期**：「💭 思考中…」实时滚动卡，边想边看；
- **收口后**：转为「💭 思考过程」折叠卡（默认收起，点开看格式化全文），挂在正文气泡前。

刷新页面与回放历史会话同样能看到（思考全文随会话日志持久）。非思考模型的会话零变化。终端不渲染思考过程，只出答案。
