# 斜杠命令

输入框里以 `/` 开头的输入不走模型，由命令注册表本地解释执行。这篇是全部命令的场景速查；每个命令的完整行为以终端 `/help` 与 [CLI 参考](../05-参考/CLI参考.md) 为准。

## 命令怎么发

- **终端**：输入行直接敲；REPL 空闲或运行中都可以敲（见下）。
- **浏览器**：聊天输入框同样识别 `/` 前缀——终端与 Web 共享同一张命令注册表，敲法一致。
- **执行中也能敲一部分**：标了「运行中可用」的命令是 busy-safe 的（纯内存或只读操作，不碰会话状态），agent 干活时敲了立即响应；其余命令在运行中会被明确回应「执行中，需等待空闲」。
- 命令执行**不进模型上下文**（落审计事件供回放），所以 `/permission` 这类操作不会污染对话。

## 会话流

| 命令 | 运行中可用 | 作用 |
|---|---|---|
| `/new` | ✗ | 换绑新会话——旧会话锁释放，标题生成与过程行重挂 |
| `/title <新标题>` | ✅ | 改会话标题，侧栏与标签页即时生效 |
| `/stop` | ✅ | 协作式中断当前任务：已流出的内容保留，会话停在可恢复状态，再发消息即续接（SIGINT 不可拦截环境下的兜底暂停入口） |
| `/exit` | ✗ | 结束终端对话：会话锁释放、回答者摘除，插件树不受影响（彻底停止进程交给 Ctrl+C） |

## 模型与思考档位

| 命令 | 运行中可用 | 作用 |
|---|---|---|
| `/model` | ✅ | 查看当前模型与可切清单；`/model <名字>` 切换（可切清单 = `llm.models` 白名单）——详见[模型与思考档位](模型与思考档位.md) |
| `/effort` | ✅ | 查看或切换思考等级：`/effort [off\|low\|medium\|high]`，下一轮对话生效 |

## 权限与计划

| 命令 | 运行中可用 | 作用 |
|---|---|---|
| `/permission` | ✅ | 查看或切换权限预设（`read-only` / `workspace-write` / `danger-full-access`）；`/permission rules list` / `rm P#|S#` 管理规则——详见[权限与审批](权限与审批.md) |
| `/plan` | ✗ | 进入计划模式（可带任务描述直接推进，如 `/plan 整理示例目录`）；`/plan off` 退出 |

## 上下文与成果

| 命令 | 运行中可用 | 作用 |
|---|---|---|
| `/compact` | ✗ | 手动压缩上下文：远端历史折叠为摘要（会话日志留压缩点，续接按其拼接）——长会话感觉变慢或逼近窗口时用 |
| `/export` | ✅ | 导出当前会话：`/export [markdown\|json]`，缺省 markdown 人读记录；CLI 写盘当前目录，Web 自动触发下载 |
| `/toolstats` | ✅ | 工具使用统计：按工具名输出调用与失败次数（安装 tool-stats 插件行后可用） |

## 技能直调与未知命令

- `/技能名`（如 `/release-notes 0.3.0`）不是注册表命令——它走技能直调：命中可用技能时把该技能的指令注入本轮，模型按技能行事；技能清单见系统提示。
- 敲了不存在的命令：注册表查不到、也不是可用技能，会报错并列出当前可用命令——不会把「/typo」当普通消息发给模型。
